# 二维浅水流模型：东湖水流、菌团覆盖与投放点入门

## 1. 先用一句话理解它

这个项目回答两个问题：

1. 工程菌从无人机投下去后，会被东湖的风生流带到哪里？
2. 在给定时间和“有效浓度”要求下，一次投放能覆盖多大范围，应该从哪里投？

它不是一个预测藻毒素浓度的机器学习模型，而是一个“物理流场 + 粒子输运 + 投放优化”的仿真模块。它在系统中的位置是：

```text
风险监测/预警 ──> 风险斑块
                    │
东湖边界 + 水深 + 风场 ──> 二维水流 ──> 菌团粒子漂移/扩散
                                      │
                                      └──> 覆盖面积、最优投放点
```

## 2. 这个模型的输入和输出

### 输入

- 东湖水面边界：OSM 水多边形；
- 水深：当前没有完整实测等深网格，因此由岸线距离和论文给出的平均/最大水深重建；
- 风：Open-Meteo 风速和风向，或预设的东南风、北风、西风场景；
- 无人机投放点和投放误差：默认菌团初始标准差 `σ0=25 m`；
- 粒子扩散系数、模拟时长、覆盖阈值等参数；
- 需要保护的藻华风险斑块。

### 输出

- 网格上的水流速度 `(u,v)` 和水面变化 `η`；
- 每个粒子的最终位置和轨迹；
- 菌团浓度/面积密度场；
- 有效覆盖面积、质心漂移、散布椭圆方向；
- 各候选投放点在多个风况下的保护比例，以及 Top-K 投放点。

## 3. 整体计算链

```text
OSM 边界 + 水深
      ↓
50 m 栅格计算域
      ↓
半隐式二维浅水方程求风生流
      ↓
粒子群 RK4 平流 + 随机游走
      ↓
粒子直方图 + 高斯平滑 = 菌团密度场
      ↓
与风险斑块叠加，计算覆盖面积/保护比例
      ↓
候选点 × 风况系综，选择稳健投放点
```

对应代码为：

| 文件 | 初学者可以把它理解成 |
|---|---|
| `src/swflow/domain.py` | 画出“湖在哪里、每个格子多深” |
| `src/swflow/swe_si.py` | 计算风吹后水怎样流动的生产求解器 |
| `src/swflow/swe.py` | 显式方法参考实现，用来展示稳定性问题 |
| `src/swflow/particles.py` | 让一群虚拟菌粒子随流漂移 |
| `src/swflow/deployment.py` | 计算覆盖并比较投放点 |
| `src/swflow/viz.py` | 速度换算和绘图辅助 |

## 4. 第一层：计算东湖水流

### 4.1 为什么用二维浅水方程

东湖总体较浅，风混合较强，项目第一版关注的是平面内的漂移方向和覆盖范围，而不是垂向分层。因此采用深度平均的二维浅水方程，而不是计算量更大的三维模型。

方程可以用直觉理解：

- 连续性方程保证水不会凭空产生或消失；
- 风应力把风的动量传给水，是流场的主要驱动力；
- 水面坡度产生压力梯度；
- Manning 底摩阻、涡黏和科氏力会改变速度和方向；
- 平流项描述水流自身搬运动量的过程。

### 4.2 交错网格

计算域被切成 50 m × 50 m 的网格。水面高度放在格子中心，东西向速度放在东西边，南北向速度放在南北边，这叫 Arakawa C 网格。这样做的好处是：相邻格子的进出流量天然对齐，连续性方程更容易保持体积守恒。

### 4.3 为什么生产代码使用半隐式方法

最初的 `swe.py` 用显式时间推进，直观但受到重力波 CFL 条件限制：时间步稍大就会发散。生产求解器 `swe_si.py` 把最容易造成发散的自由面压力项隐式化：

1. 先显式计算风、科氏力、平流、扩散等项，得到中间速度；
2. 把压力项和连续性方程联立，形成一个对称正定的五点线性系统；
3. 用共轭梯度法求新水面高度；
4. 再由水面梯度修正速度，并施加底摩阻。

这样可以把时间步从约 1–2 秒提高到默认约 20 秒，36 小时自旋的计算量大幅降低，同时保留物理守恒检查。

## 5. 第二层：把菌团当作粒子

投放物不是均匀铺在整个网格上的浓度，而是一小团有空间范围的菌液。因此 `particles.py` 使用 Lagrangian 粒子法：一颗虚拟粒子代表菌团中的一小份物质。

每个 5 秒子步做三件事：

1. 用双线性插值读取粒子位置处的格心流速；
2. 用 RK4 积分粒子沿流线移动；
3. 加入 `sqrt(2DΔt)` 量级的高斯随机游走，表示网格没有解析出的湍流扩散。

粒子跑到岸上时，代码沿原位移方向回溯，尝试把它放回最后一个水上位置；反复失败才留在原地。这种处理比让粒子穿过陆地更符合当前模型的目标。

最后把粒子位置按网格计数，再用高斯核平滑，得到归一化的面密度场。它更像“单位总剂量在湖面上的分布”，不是已经完成生物降解后的真实 MC-LR 浓度。

## 6. 第三层：什么叫“有效覆盖”

模型用一个相对阈值定义覆盖区域：

```text
有效覆盖 = { 网格点 | 终态密度 ≥ thr_rel × 初始峰值密度 }
```

当前演示默认 `thr_rel=5%`。这样可以回答“哪里仍有足够菌团剂量”，但 5% 不是经过降解动力学正式标定的生物学阈值。未来应由 MC-LR 降解模型反推出 `C_req`，再把它转换为这里的有效剂量阈值。

覆盖面积对阈值非常敏感：阈值从 1% 提高到 5% 或 20%，面积会显著缩小。因此报告中的单次覆盖面积首先应被看作比较不同风况/投放点的演示量，而不是现场保证值。

## 7. 第四层：怎样寻找投放点

`deployment.py` 对每个候选点执行投放仿真，并计算它覆盖目标风险斑块的比例：

```text
score(p) = Σ_w  风况概率(w) × 覆盖(p,w) 与风险斑块的交集比例
```

候选点通常是湿润网格中每 200 m 取一个点。程序在多个风况成员上分别运行粒子仿真，再取期望保护比例并观察成员间的波动。

最优点常常不是风险斑块几何中心，而是**中心的上风侧**：菌团会顺流漂移，优化器会自动“提前放在上游”。这就是水流模型对无人机决策最直接的价值。

为节省时间，`batch_sim_drops()` 把多个候选点的粒子群拼成一个大数组同时积分，再按候选点切分统计；它没有把风场线性缩放当成最终结果，存在真实流场文件时会优先使用各成员的真实求解结果。

## 8. 当前结果和可信边界

按照目录 README 的最新口径，当前基线包括：

- OSM 掩膜面积约 31.2 km²，与官方 31.75 km² 相差约 2%；
- 当前水深场按 MIKE21 论文平均/最大值标定，平均约 2.21 m、最大约 4.75 m；
- 典型风况下风生流峰值约 0.066–0.072 m/s；
- 在 `σ0=25 m`、2 小时、5% 相对阈值的演示条件下，单次有效覆盖约 0.038–0.080 km²；
- 最优点表现为风险斑块上风侧的漂移预补偿；多点投放比单点更适合较大的风险斑块。

模型做了几类验证：驻波周期与解析解误差约 0.16%、体积守恒达到机器精度、时间步收敛测试通过、流速量级与浅湖风生流范围相符。

但它还不能证明“东湖实测流速已经被准确复现”：

- 水深是形态学重建，不是实测等深网格；
- 缺少东湖现场流速对照；
- 粒子扩散系数、投放初始半径和覆盖阈值仍需实验标定；
- 二维深度平均模型看不到蓝藻升沉、表层与底层流速差等垂向过程。

## 9. 如何复现

在 `model_Two-dimensional_water_flow/` 目录下，典型顺序是：

```bash
python src/swflow/domain.py
python scripts/02_run_circulation.py
python scripts/03_run_particles.py
python scripts/04_run_optimization.py
python scripts/05_run_sensitivity.py
```

主要中间结果在 `data/processed/`，图件在 `figures/`。先读 `README.md` 了解当前结果，再读 `TEACHING_GUIDE.md` 了解方程和代码；如果要审查数值可信度，再看 `REVIEW_REPORT.md` 和 `report/实验记录_EXPERIMENTS.md`。
