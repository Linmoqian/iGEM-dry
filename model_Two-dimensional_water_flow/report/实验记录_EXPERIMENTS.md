## E0：东湖水深场的实测点标定（文献：刘惠 2019；郭雪蕊 2018；王红 2004；GLOBathy 2022）

### E0-a：42 个实测水深点的数字化与验证（脚本 `12_validate_bathymetry.py`）
**动机**：本模块的水深是"形态学指数重建"（零实测约束）。刘惠 et al. (2019) 表 1 给出 **42 个东湖实测水深点**（2017-07-23，水位 19.18 m 吴淞，手持 GPS+重锤皮尺），表 2 给出同一批点校正到成像日（+0.12 m，水位 19.30 m）的水深——这是目前唯一可获得的公开实测水深集。

**方法**：从 PDF 中数字化全部 42 点（排版为双栏交错，按"点号-经度6位-纬度6位-水深"逐条解析）；**内部校验**：表1水深+0.12 == 表2 水深，42/42 完全一致（转录无错）。将坐标投影到模型网格（等距投影，LON0=114.3956, LAT0=30.5566）取所在湿格的水深做对比。

**结果**：
```
内部校验: 42/42 OK
实测:      mean=3.07  min=1.98  max=3.72 m
模型(现):  mean=2.83  min=0.80  max=4.63 m
bias=-0.241 m   RMSE=1.015 m   MAE=0.899 m   R=0.764   相对误差均值=30.8%
浅点子集(实测<3.17): bias=-0.694 RMSE=1.145 (n=21)
深点子集(实测>=3.17): bias=+0.211 RMSE=0.865 (n=21)
```

**结论（诚实）**：现重建场与实测**空间模式中度相关（R=0.76）但单点误差大（RMSE 1.02 m ≈ 均深的 45%）**；系统性形态错误＝**浅处（近岸/北西侧）低估、湖心高估**——指数剖面把水深过度集中在"几何中心"，而实际东湖是"岸陡-中途平台-中心谷"的形态。同时提示：①实测点横贯郭郑湖-团湖，偏向深水航段（样本均值 3.07 > 湖均值 2.2–2.5）；②测量水深含淤泥层（刘惠：淤泥平均厚 1.06 m），对"硬底地形"有 0.5–1 m 级不确定性（记录为不确定度来源，不追溯为模型误差）。

### E0-b：四种候选水深场对比（脚本 `13_bathy_rbf.py`）
**动机**：原指数式只有 1 个自由参数（L）。按文献形态选候选：
- A 现状：d = Dmax·(1−exp(−dist/L))，Dmax=4.75、L 由均值 2.21 反解（现域 L=381）；
- B 自由幂指数：d = Dmax·(1−exp(−(dist/L)^p))，自由拟合 42 点；
- B2 固定 Dmax=4.66（刘惠公布值）拟合 (L,p)；
- **B3 固定 Dmax=4.66 + 湖均值约束 2.48（刘惠：33.2 km²/1.24 亿 m³）**——生产候选；
- C GLOBathy 线性：d = Dmax·(dist/Lmax)（Hollister & Milstead 距离法原式）；
- D A+残差 RBF（薄板样条，42 残差+岸线 0 锚点，LOOCV）。

**结果**：
```
A  指数(现状)          : RMSE=1.015  bias=-0.241  R=0.764
B  自由幂指数           : Dmax=3.68 L=69.2 p=0.41 → RMSE=0.324  LOOCV=0.349  场均值2.87（违背已知湖均值）
B2 固定Dmax=4.66        : L=247.8 p=0.25       → RMSE=0.327  场均值2.88
B3 固定Dmax+均值2.48    : L=440.0 p=0.39       → RMSE=0.489  LOOCV=0.478  场均值2.48 max=3.71
C  GLOBathy线性         : RMSE=1.780  bias=-1.492  场均值1.01（严重偏浅）
D  A+RBF残差            : RMSE=0.824  LOOCV=0.760  场均值2.21 max=4.35
```
（图 `figures/fig07_bathy_validation.png`）

**结论**：
1. **B3（幂指数 + 文档锚点）胜出**：实测点 RMSE 1.02→0.49 m（−52%），LOOCV 0.478 与样本内 0.489 一致（无过拟合），且保持"实测均值 2.48/最大 4.66"的物理锚定；形态为"近岸陡升 + 平台化湖盆"，与刘惠的定性描述（最深在郭郑湖/团湖/后湖中心、小湖汊<2 m）一致。
2. **B（无约束自由拟合）否定**：拟合出的 Dmax=3.68/均值 2.87 与公开湖体统计（4.66/2.48）冲突——42 点样本不是面积代表性的（偏向深水航段），**不能用样本均值当湖均值**；约束必须来自湖体统计。
3. **C（GLOBathy 线性距离法）否定**：RMSE 1.78、场均值仅 1.01 m——**GLOBathy 的线性形式直接用于东湖不可行**；叠加上 HydroLAKES 对东湖记录 Depth_avg=5.8 m（Vol_src=3，估算值）与实测 2.2–2.5 m 矛盾，**东湖不采用 HydroLAKES/GLOBathy 水深**（K1 评估结论）。
4. **D（残差 RBF）可行但不如 B3**：修正后的 RMSE 0.82（LOOCV 0.76）优于 A 但劣于 B3，且不显式保留均值/最大约束；**保留为"未来有更多实测点时"的升级路径**。

### E0-c：水深改造对环流与覆盖的影响（脚本 `14_bathy_circulation_effect.py`）
**动机**：水深变了，流场会变——必须量化"换水深模型"的代价。
**方法**：同一配置（n=0.0238、Smagorinsky、SE 2.5 m/s、24 h 自旋、dt=20 s）在 A 与 B3 上分别跑，再做同一投放测试（(−1300,−200)，2 h，σ0=25 m，thr=5%，n=2500）。

**结果**：
```
A 水深(均2.21/max4.64): |u|max=0.0618 mean=0.0158  覆盖=0.0625 km² 质心(-1267,-257)
B3水深(均2.48/max3.70): |u|max=0.0495 mean=0.0108  覆盖=0.0625 km² 质心(-1258,-255)
流场差: rms 0.0062 m/s（相对基均值 39%），局部最大 0.029
```
（图 `figures/fig08_bathyB3_circulation_effect.png`）

**结论**：① 水深形态变化（消除中部深坑）使 **峰值/均值流速下降 20–32%**——"更真实的水深更缓"；② 但**单次投放覆盖面积几乎不变（0.0625 vs 0.0625 km²）**——覆盖对水深在 ±0.5 m 尺度的变化不敏感（扩散主导 + 阈值归一化）；③ 因此**采用 B3 的收益（可信度）远大于代价（流速幅值下修）**；④ 流速幅值与 MIKE21/郭雪蕊的对照（见 E7/优化方案）在 B3 下更接近真实。

### E0 汇总建议
- **采用 B3 水深公式**（Dmax=4.66, L=440, p=0.39）作为生产水深；域均值锚 2.48、最大 3.71（渐近目标 4.66 在湖内打不到，口径写"标定目标 4.66/实测场最大≈3.7"）。
- 子湖级标定（郭雪蕊表 2-1 逐子湖容积→平均水深）**暂不可行**：当前 OSM 数据仅剩 3 个多边形（子湖环未保留）——记为数据缺口（需子湖多边形，见优化方案）。
- 淤泥层（1.06 m 平均）→ 水深定义口径（"水底=硬底 or 含淤"）需在文档中声明，否则 0.5–1 m 级偏差会混入标定。

## E1：风拖曳系数参数化（文献：Zhang, Chen & Brett 2024 WRR；Wu 1980；Bolmen 2021）

### E1-v1（失败尝试，如实记录）：Eq.11 直接应用 + SMB 均衡波
**方法**：完全实现 WRR 2024 Eq.11（Cd = 1.956·α·(U10/u*)^−1.996·Fr_H^0.213·Re_H^0.298，α=0.02·β*^0.5），波要素用 **SMB 风浪公式 + 沿上风向射线 fetch**（50 m 网格逐格）计算。
**结果**：
```
SE_2.5: Cd 场 mean=1.43e-4（min 1.40e-4, max 4.82e-4）；Hs 均值 0.019 m、Ts 0.52 s
        → |u|mean=0.0045（vs 常数 Cd 的 0.0158）——流速反而低了 3.5 倍
N_3.0:  Cd mean=1.66e-4；W_2.0: Cd mean=1.22e-4（同类坍缩）
```
**失败根因（分析与文献核查）**：① SMB 给的是**充分发展波**（β* = cp/u* ≈ 7–22）；而 Zhang 公式的标定域是**物理水池的年轻风浪**（其实验波龄参数范围对应 β*≈1–3）——公式在此回归下与 SMB 波组分耦合时出现**固定点坍缩**（(U/u*)^{−1.996} ≈ Cd^{0.998} 使方程退化，平衡解要求 α·Fr^0.213·Re^0.298 ≈ 0.51，SMB 均衡波组分只给出 ~0.18）；② 论文自身提示：弱风/年轻波（Lake Balaton、Lake George）下 Cd 高（负 Cd–β* 相关），恰恰是我们 2–3 m/s 场景的形态——**把海洋/均衡波参数化直接外推到湖泊弱风会得到反物理结果**。**教训：参数化的"标定域"比公式本身更重要；跨域迁移必须做量级自检。**

### E1-v2（推荐的简化湖面 Cd 方案，脚本按此实现）
**方法**：取论文 Fig. 4b 正分支（1.6 < U10 ≤ 3.0，r²=0.901）两端点拟合 Cd(U) = 1.32e-3 + 1.27e-3·(U−1.6)（端点来自箱均值带 1.32–3.22e-3），并叠加**温和的 fetch 空间调制**（应力随开阔度 ±17.5%），模拟论文 UKL 应用中的"空间非均匀风应力场"特征；同配置另跑常数 Cd=1.3e-3 与 Wu(1980) 作对照。24 h 自旋，dt=20 s，n=0.0238，Smagorinsky。

**结果（最终）**：
```
                        lake-Cd                const 1.3e-3        Wu(1980)
SE_2.5  Cd mean=2.05e-3 (2.03–2.89e-3)  |u|max/mean = 0.0763/0.0201  0.0618/0.0158  0.0540/0.0134
N_3.0   Cd mean=2.59e-3 (2.56–3.64e-3)  |u|max/mean = 0.0926/0.0274  0.0659/0.0192  0.0576/0.0167
W_2.0   Cd mean=1.53e-3 (1.51–2.15e-3)  |u|max/mean = 0.0472/0.0127  0.0433/0.0116  0.0366/0.0097
fetch: 站点均 65–70 m、最大 2400–2900 m（东湖开阔区 3 km 量级，合理）
投放对照(SE, (-1300,-200), 2h, 5%):  const 0.0650 km²/漂移(+24,-73)   lake-Cd 0.0650 km²/漂移(+40,-83)
```
（图 `figures/fig09_wave_dependent_cd.png`：3 场景 Cd 场 + 速度比场；流场 `flow_*_cdlake.npz`）

**结论**：① 湖面 Cd 方案给出 **Cd 1.5–2.6e-3（按风速 1.5–3.2e-3），正是 Zhang 实测频带（1.2–3.7e-3）与 Delft3D（0.0025）/MIKE21（0.0016–0.0026）区间**——推翻常数 1.3e-3；② 流速随之 **+27%（SE）/ +43%（N）/ +9%（W）**（对比 Wu(1980) 则高 50%+），与论文 UKL 的 +57–90% 同向（数值略低，因我们的风小、摩擦非线性）；③ 但**单点 2 h 覆盖面积与漂移几乎不变**（0.0650 / (+40,−83)）——与 E3 一致：**面积对动量输入不敏感，位置轻微**；④ 该修正的主要意义在于**流场物理正确性**（与 MIKE21/Delft3D 口径一致）与**长时漂移**（6 h+ 尺度的位置差异会显著），以及作为"对比 MIKE21 量级"的正确基准（E7）。
**采用建议**：`SweConfigSI.c_d_wind` 默认改为 `cd_lake(U)`（脚本 15 之曲线；2–3 m/s 场景覆盖）；`wind_stress` 保留 'constant'/'wu' 作对照。

## E2：湖陆风/逐时风（文献：胡辉 2018；A4 Podsetchine 1999；本模块 Open-Meteo 数据）脚本 `16_hourly_summer.py`

**动机**：胡辉（东湖岸边全年观测）称湖风 07–08 时开始、夏季持续 13 h、平均风速为陆风 2 倍+；本模块场景库是**定常风**。检验：(a) 自家数据里昼夜信号有多强；(b) 时变风下流场与覆盖变化多大。

**结果-A：JJA（2023-06~08 + 2024-06~08）昼夜气候**（站 30.5448N/114.3529E，17,544 h）：
```
hour:   0    3    6    9   12   15   18   21
speed: 2.41 2.27 2.40 3.07 3.52 3.32 2.54 2.35   m/s
dir  : 133  125  109  144  177  212  135  129   (circ-mean, deg)
白天(08-19时): 3.11 m/s @ 173°；夜间(20-07时): 2.40 m/s @ 123°
```
→ **显著的昼夜信号**：日振幅 ~0.7–1.2 m/s、方向摆动 ±50°（清晨 SE→午后 S-SW→夜间 SE），峰值 13–14 时——与胡辉的"湖风日变化"定性一致（幅度低于其岸站观测，说明区域风为主、湖陆风为叠加扰动）。

**结果-B：2023-07-15→18 的 72 h 逐时风驱动 + 时变流场粒子输运（dt=40 s）**：
```
72h 窗口: 平均 2.02 m/s（偏静），max 3.42
控制(定常 SE2.5, 24h): |u|max=0.0619 mean=0.0158
逐时风分段均值: |u|mean 0.0033–0.0094（随风情起伏 3 倍）
投放(2h, 5%阈值, (-1300,-200)):
  逐时风 释放@01:00(7-15) : 0.0575 km² 质心(-1311,-214)
  逐时风 释放@07:00(7-16) : 0.0600 km² 质心(-1310,-164)
  逐时风 释放@07:00(7-17) : 0.0600 km² 质心(-1264,-155)
  定常 SE2.5            : 0.0625 km² 质心(-1262,-258)
```
（图 `figures/fig10_hourly_wind_summer.png`；也生成 `flow_2023jul_hourly72.npz`）

**结论**：① **覆盖面积对"定常 vs 逐时"不敏感（±4–8%）**——单次投放指标稳健，"定常场景库"设计成立；② 但**流场幅度对时变风敏感（3 倍起伏）**——流场量（|u|max/mean）只能按"情景统计"引用，不能当定值；③ 增加"非稳态风"选项（E2 脚本）作为**敏感性与不确定性评估**而非生产取代；④ 局限性：单个 72h 窗口（偏静 2.02 m/s）、单个投放点——多窗口验证列入后续。

## E3：表层风漂移（windage）灵敏度（文献：Fenocchi 2016【2D 低估表层】；Wang 2017【风应力→表层聚集】；油污 windage 惯例 1–4%）脚本 `17_windage.py`

**方法**：粒子平流叠加 α_w·W_10 项（方向=风矢量，2 h 输运，SE 2.5，σ0=25 m，thr=5%）取 α_w ∈ {0, 1%, 2%, 3%, 5%}。

**结果**：
```
windage 0%: area=0.0650 km²  漂移(+25,-73) m
windage 1%: area=0.0625 km²  漂移(-101,+58) m
windage 2%: area=0.0650 km²  漂移(-224,+195) m
windage 3%: area=0.0625 km²  漂移(-346,+336) m
windage 5%: area=0.0625 km²  漂移(-596,+618) m
```
（注：2% windage ≈ 0.05 m/s，约等于深度平均流速的 3–4 倍——正是"表层漂移 > 深均流"的量级关系。）

**结论（重要且反直觉）**：① **覆盖面积对 windage 完全不敏感（0.0625–0.065 恒定）**——面积指标由扩散+阈值归一化主导，平移不改变面积；② **覆盖区域的位置对 windage 极敏感**（5% 时偏移 850 m，远超单点 6 ha 覆盖的尺度）——**"保护哪个斑块"的结论会被 windage 实质改变**；③ 建议：模型默认加入 **α_w=2%**（有文献支撑的下限，油污/微囊藻/2D 低估三者共识），风+流联合漂移作为投放决策的标准口径；这也意味着**上游风场预报误差会线性传导到投放点**（风误差 1 m/s → 2% → 0.03 m/s ≈ 2 h 漂 200 m——与优化 Top-5 间距 200 m 同量级，**不可忽略**，进入不确定性预算）。

## E4：与降解动力学（下游）的接口：C_req ⟷ thr_rel（文献：降解模块 v1.1 机理；五模型报告 05 的"联标最高优先"）脚本 `18_thr_rel_calibration.py`

**动机**：水流模型覆盖率阈值默认 thr_rel=5%（演示值），但降解模型给出**物理的 C_req（最小有效菌密度）**；两者的换算直接决定"一次投放还能不能算覆盖"。

**方法**（采用降解模块原型 v1 的机理与参数）：-dC/dt = k·D·C（m6 当量菌密度 D，k=0.25 h⁻¹@30°C/pH7），达标时间 t = ln(C0/C_goal)/(k·D)，C_goal=1 µg/L；温度修正用其 m6 实测点（20°C=0.50×、25°C≈0.71×、30°C=1.0×、37°C=0.60×）；东湖典型 C0 包络 0.25–2.85 µg/L。thr_rel = D_req/B_peak0，B_peak0 = 单架次投放后菌浓度峰值（=M 倍参考密度）。

**结果**：
```
D_req（达标所需最小菌密度，m6 当量）:
  C0=2.85µg/L: 12h→0.35(30°C)/0.49(25°C)；24h→0.18/0.25；48h→0.09/0.12
  （C0≤1.0µg/L 时无需治理）
thr_rel = D_req/M：
  M=1（投放到就及参考密度）: 12h→0.49, 24h→0.25, 48h→0.12
  M=2:                        12h→0.25, 24h→0.12, 48h→0.06
  M=5:                        12h→0.10, 24h→0.05, 48h→0.02
面积-阈值响应（锚点 0.0650 km²@5%）: 0.02→0.094, 0.10→0.029, 0.20→0.010, 0.50→0.0013 km²
```

**结论（本轮最重要的工程结论之一）**：① 以 25–30 °C、12–24 h 达标为目标，**物理 thr_rel ≈ 0.18–0.49，是演示值 5% 的 4–10 倍**；② 在此阈值下**单架次有效覆盖从 0.065 km² 坍缩到 0.001–0.01 km²（缩小 6–60 倍）**——"一架次覆盖一个大斑块"的叙事在物理阈值下**不成立**；③ 补偿路径：加大单架次剂量（M=5：thr≈0.10 → ~0.03 km²）或**多点多架次**（与 E4/路径规划接口联动）；④ 5% 只能作为"阈值敏感性演示"，**所有面积数字在联标前必须标注为演示值**（这句已有，现在有了量化依据）；⑤ 建议管线接口：降解模块输出 `C_req` → 换算 thr_rel 表（输入：水温、目标时间、C0、单架次剂量 M）→ 水流模块按（M, thr）双维度输出覆盖。

## E5：与路径规划（上游-下游接口）的多航次异构无人机投递模拟（文献：Jiang 2025 MV-VRP-MHD；Kumar & Kumar 2023 覆盖综述；路径规划模块航机规格）脚本 `19_interface_mv_vrp.py`

**动机**：水流模型给出 Top-K 投放点+评分；但"每个点需几架次、几架无人机、怎么排序"的决策属于路径规划模块。验证"覆盖感知排序+多机协同"比"单机顺序"的量化收益，并给出接口契约示例。

**方法**：opt_result.npz 取 Top-8（评分 0.0508–0.0533）→ 风险比例需求（1–3 个载荷单元，共 17 单元）→ 坐标换算到路径规划模块框架 → 其 3 无人机（载 4/4/6 kg、续航 28/28/34 min、速 15/15/13 m/s）→ 风修正非对称 T 矩阵（SE 2.5 m/s，其 wind_time_matrix 公式）→ 列表调度（风险优先序 + 每架次 NN+2-opt、容量/续航约束）→ 对比单机串行。

**结果**：
```
单机(cap 6):   makespan 48.2 min, 3 架次
三机协同:      drone0: 2 架次 5 单元 31.4 min; drone1: 2 架次 5 单元 29.4 min;
               drone2: 2 架次 7 单元 36.2 min  → makespan 36.2 min
加速比 1.33×；单位时间评分交付量 0.0533 vs 0.0401（+33%）
调度瓶颈=drone2 的续航 34 min（到达间隔 ~8 min/程）
```

**结论**：① 接口契约可运行：水流模型（点、评分）→ 需求生成（评分∝剂量）→ 飞行时间矩阵（风修正、非对称）→ 多航次多机调度；② **三机协同收益 +33%**（时间/评分），瓶颈在续航→**换大电池/充电站比加飞机更有效**（敏感性方向）；③ 覆盖-时间权衡（评分加权 vs 最快完成）是**水管线与路径规划之间的真正优化目标**——建议路径规划模块把"风险权重小时窗"改为"评分权重 + 窗由 t_safe 反推"（降解模块 t_safe 分位已给出）；④ 简化说明：本实验用风险比例需求=线性模型，真实剂量由 E4 的 (C0,t_safe) 决定——**需求生成函数是下一个接口待办**。

## E7（补充对照）：与 MIKE21/郭雪蕊模型的量级对照（数据：A1/A6 文献+已有产物）

**动机**：验证 B3+湖面 Cd 之后的流场量级是否落入两篇东湖模型的范围。
**方法**：文献数值 vs 本模块两种配置的 |u| 统计：
- 郭雪蕊 2018（MIKE21, n=0.032, 月均真实风, 无外调水）：湖均 0.0023–0.0028 m/s；子湖 0.001–0.005；
- 郭雪蕊 2018 工况2（引江 10–30 m³/s 外调水）：湖均 0.0234–0.0236；局部最高 0.087（水果湖）；
- MIKE21 2020（Li 等）：新沟渠站验证流速误差 <25%（量级与时段相关）；
- 本模块（n=0.0238, 定常 SE2.5/N3.0/W2.0, 无外调水, 24h）：mean 0.0108（B3 水深）/0.0171（现水深，36h 出厂值 max 0.0662）；
- 本模块（n=0.022+Smag, 现生产 02 配置, 36h）：SE2.5 mean 0.0171/max 0.0662；N3.0 0.0207/0.0718；W2.0 0.0127/0.0487。

**初步结论**：本模块风生流均值（~0.011–0.019）比郭雪蕊"无外调水"（~0.0025）**高 4–8 倍**。可能的解释：① 定常风 vs 月均真实风（真实风含大量弱风+变向，均值流低）；② n=0.0238 vs 0.032（摩擦差 1.8×）；③ 我们的"纯风生"与他们的"风+调蓄"综合。**建议（若追求与既有东湖模型一致）：① 将糙率上调至 n≈0.028–0.032 并做敏感性（脚本 05 已有 Manning 敏感性框架）；② 场景改为"月均风"口径时采用定常中位风（E6 的 p50）而不是极值**；③ 两者最终都要以"是否有东湖实测流速"来仲裁——目前没有任何公开实测流速序列，**我们的量级验证只能到"同量级、近似倍率"层级**（诚实声明）。
