# E11：物理阈值（thr_rel 联标）下的投放点优化对照实验

日期：2026-08-24 ｜ 脚本：`scripts/04_run_optimization.py`（未改动）｜ 产物：`data/processed/opt_result_thr005_v2.npz`、`opt_result_thrphys_v2.npz`

## 动机

E4/A4（见 `report/优化方案与不足_OPTIMIZATION_PLAN.md` §A4）指出：演示口径 `thr_rel=5%` 只是物理需求 C_req 的 **1/4–1/10**（物理值 0.18–0.49），导致"单点覆盖面积"叙事失真(±6–60×)。本轮代码已落地三处与覆盖判定直接相关的改动（B3 幂指数水深、`cd_mode='lake'`、粒子 windage α_w=0.02），且 `deployment.physical_thr_rel()` 已实现——但 04 优化在模块优化后尚未用物理阈值重跑。

本实验在新基线上做**单变量对照**（仅 thr_rel 不同，系综/候选/粒子随机种子全同）：演示阈值 vs 物理阈值各跑一遍 5 成员系综 × 792 候选，回答两个问题：
1. 期望保护分数下降多少；
2. 最优投放点是否移动、排名是否重排（若重排，下游路径规划/调度接口必须按物理口径传递分数）。

## 方法

- **阈值**：
  - run A（demo）：`--thr 0.05` → thr_rel = 0.0500（旧基线沿用值）
  - run B（physical）：`--physical --C0 2.85 --t_ok 24 --T_water 25 --M 1`
    - C_GOAL=1.0 µg/L（WHO 限值）；k_eff(25°C)=0.1770 h⁻¹（`_K_T_ANCHOR={20:1.67, 30:3.33, ...}` 插值）；D_req=ln(2.85/1.0)/(0.1770×24)=**0.2465**；thr_rel=D_req/M=**0.2465**（M=1，即以 m6 参考密度等价的初始峰值）
    - 物理阈值为演示值的 **4.93×**，与 E4 预估区间（4–10×）一致
- **系综**：5 个真实流场成员 m0/SE_2p5/m1/m2/m3 = (2.0,120°)/(2.5,135°)/(3.0,150°)/(2.0,150°)/(3.0,120°)（`data/processed/flow_*.npz`，SE 风基线扰动；均带 wind_mps/wind_dir，故 windage α_w=0.02 生效；流场本身由 B3 水深 + cd_mode='lake' 预报）
- **目标斑块**：郭郑湖西侧椭圆 (-1300,-200)，rx=900 m，ry=500 m，θ=20°，面积 1.41 km²
- **候选**：湿格每 4 格（200 m）取点，共 792；T_h=1.5 h、dt=10 s、D=0.3、n=600、σ0=25 m、rng_seed=7
- **分数**：覆盖区 C ≥ thr_rel×max(C) 与斑块交集面积 / 斑块面积（5 成员平均）
- **对照有效性**：两跑仅 thr_rel 不同；cands 数组逐元素全同（np.array_equal=True）

## 结论

**改动有效，且投放点决策必须改用物理口径**，数字依据：

1. **分数标定**：thr_rel 0.05 → 0.2465（4.93×）时，期望保护分数 top5 由 0.051–0.054 降至 0.016–0.017（−3.2×），全体候选均值 −3.4×。面积叙事按 A4 要求改写为物理口径：单架次 1.5 h 只能期望保护斑块的 ~1.6–1.7%（vs 演示口径 ~5.2%），支持"多点+多架次+加大剂量（M）"路线。
2. **排名重排**：top5 完全不相交、A-best 掉到物理口径第 24 名、B-best 在 demo 口径仅第 23 名；但 top20 重合 15/20 且 ρ_s=0.92——**"大偏好区没变、精确最优点移动 1.0 km"**：物理阈值下羽流"核心区"（≥24.6% 峰值）必须落在斑块上，最优点从斑块下游侧（距中心 407 m）移到上游东南侧（距中心 781 m，SE 风来向侧），即投放点向上风侧补偿漂移。
3. **接口影响**：04 输出已带 `thr_rel`/`thr_kind` 字段（A 为 'demo'，B 为 'physical'）；下游（路径规划、调度）应消费 physical 口径分数并保留 thr_kind 标注。M=2（双倍初始峰密度）时 thr_rel=0.1232，分数将介于两跑之间——剂量-覆盖敏感性可作 E 系列后续实验。

局限（沿用 A4 已列）：均匀风假设、椭圆斑块假设、单点单剂量（未含多点协同）；本实验只对照阈值单变量，系综内种子固定（rng_seed=7），逐成员差异见上表 member_scores。
