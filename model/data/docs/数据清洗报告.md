## 二、清洗操作详述

### 2.1 旧金山河口 (sf_estuary)

**原始问题**: 478行×49列
- UTF-8 BOM 字符
- 最后一行为 FieldCont 质量控制样本
- DWR_Site 和 EMP_Site 两套站点编码并存
- field.NTU 有 7 条负值 (-0.8 ~ -0.1)
- towNet 系列 5 列缺失率 58-77%
- dwr.MIC_totbvL 极端值 (0 ~ 7.36×10^11)

**清洗操作**:
- `utf-8-sig` 编码读取，自动剥离 BOM
- 移除 40 条 FieldCont 质控行 → 438 行
- 合并 DWR_Site + EMP_Site → Site 列
- field.NTU 负值 → NaN (7 条)
- 删除 5 个高缺失列 (towNet.Pheo.corrected, field.Chla, towNet.Chla.corrected, towNet.Pheo.uncorrected, towNet.Chla.ave.ugL)
- IQR 标记 dwr.MIC_totbvL 极端值 51 处 (不删除)

**清洗后缺失率** (主要列):
- bryte.Calcium.mgL: 45.21%, bryte.total.kjeldahl.n.mgL: 44.98%
- field.DO.perc: 46.58%, field.Secchi: 45.21%, field.Fluor: 45.66%
- 大部分 bryte.* 化学指标: <1%, ucd.qpcr.* 毒素基因: <3%

---

### 2.2 欧洲EMLS (emls_europe)

**原始问题**: 369行×43列
- 国家名拼写错误: FR (应为 France), Lithouania (应为 Lithuania)
- 叶绿素a极端值 (最高 932 ug/L)
- 营养盐缺失 14-36%

**清洗操作**:
- FR → France (2 条), Lithouania → Lithuania (15 条)
- IQR 标记 Chlorophylla_ugL 极端值 16 处 (>114.00)
- 营养盐缺失保留，标注于报告

**清洗后缺失率** (主要列):
- MeanDepth_m: 35.23%, NO3NO2_mgL: 35.5%, ThermoclineDepth_m: 31.98%
- TP_mgL: 19.51%, TN_mgL: 14.09%
- 微囊藻毒素各变体: 4.6-5.2%

### 2.5 Lake Erie 全湖采样 (v2_lake_erie)

**原始问题**: 3,074行×44列
- 9 个 Unnamed 全空列 + Light attenuation 列 98% 缺失
- Total Microcystins 有 364 条 `< 0.15` / `<0.15` 检测限标记
- Extracellular Microcystin 有 129 条 `<` 检测限标记
- Program 名拼写不一致 (SL Bouy → SL Buoy, HABsGrab → HABs Grab)

**清洗操作**:
- 删除 10 个空列/高缺失列 → 34 列
- `< 0.15` → 0.075 (半检测限，统计学惯例)，`<0.15` 同理
- Program 名标准化: SL Bouy (3条), HABsGrab (170条)

**清洗后缺失率** (主要列):
- Extracellular Microcystin: 83.96%, Urea-N: 87.12%, TSS/NVSS/AFDW: ~70%
- Total Microcystins: 13.5%, Chlorophyll: 2.7%
- 营养盐 (Nitrate+NO2, Ammonium, TP 等): 1-5%

**已知遗留问题**: Total Microcystins、Extracellular Microcystin、Secchi、TN:TP 列仍为 object 类型，部分值可能未被检测限函数捕获。建议后续建模前执行 `pd.to_numeric(errors='coerce')`。

### 2.10 Erie 汇总数据 (v2_erie_summary) — 最复杂数据集

- 检测限标记统一 → NaN
- 带问号可疑值正则清理
- 数据类型转为 float64

**已知遗留问题**: 合并后部分列名较长或含合并分隔符 (如 "Station - Depth m - mg/L - mg/L - mg/L - µgChl-A/L")，col_24 ~ col_46 为原始 CSV 中无法有效命名的列。后续使用时需参考原始元数据映射列名。

## 三、清洗策略总结

| 策略 | 适用场景 | 处理方式 |
|------|---------|---------|
| 检测限半值替换 | `< 0.15`, `<0.15` | → 数值/2 (统计学惯例) |
| 检测限 → NaN | `bdl`, `nd`, `ns`, `<LLOD`, `nq` | → NaN |
| 哨兵值 → NaN | -1000 | → NaN |
| 负值 → NaN | field.NTU 负值 | → NaN |
| 极端值标记 | IQR 3倍以上 | 新增 _outlier 布尔列，不删除 |
| 质控行移除 | FieldCont 等 | 整行删除 |
| 拼写修正 | 国名/Program名 | 替换为正确值 |
| 高缺失列删除 | ≥55% 缺失 | 整列删除 |
| 有序分类 | toxin_level (1-4) | pd.Categorical(ordered=True) |
