## 0. 这个模型是干什么的？

### 0.1 一句话

**已知水体里 MC-LR 浓度超标（例如 20 μg/L，WHO 安全线是 1 μg/L），我们用数学模型推演：往水里投放多少降解菌、等多久，浓度才能降回安全线。**

### 0.2 它在整个项目里的位置

项目是一条闭环链路（见 `docs/Introduction/IGEM项目简介.md`）：

```
检测菌感应 MC-LR → 荧光信号 → 预警（≥1 μg/L 触发）
    → 无人机投放降解菌（携带 mlr 酶基因簇）
    → 降解菌把 MC-LR 切成无毒小分子
    → 光控自杀模块清理残留菌
```

本模型负责的是中间两个环节的**数学推演**：

- **投放多少（剂量 D）**：菌少了达不到 1 μg/L，菌多了浪费、还有生态扰动；
- **治理多久（时间 t）**：中控要告诉调度系统"几点可以宣布安全""什么时候需要二次投放"。

所以模型的输出不是一条漂亮的曲线，而是一张**决策卡**：

| 输出 | 含义 |
|---|---|
| 推荐剂量 D\* | 在时限内达标的**最小**剂量（含离散档位，按无人机载荷单元取整） |
| 预计治理时间 t\* | 中位数 + 区间（比如"13 h，90% 区间 7–24 h"） |
| 关键影响因素 | 当前水温/pH 偏离最适值带来的惩罚、最大不确定性来源 |
| 二次投放建议 | 若光控自杀导致菌的"有效窗口"不够长，提示需要补投 |

### 0.3 模型的输入

| 输入 | 谁提供 |
|---|---|
| C₀：初始 MC-LR 浓度 + 不确定度 | 上游"浓度校准"模块（双荧光标准曲线反演，见 docs/Introduction 数据讨论） |
| T(t)、pH(t)、DO(t)、光强 I(t) | 检测节点传感器 + 历史数据（模拟区域：武汉东湖） |
| 菌株属性（mlr 表达强度、光死曲线等） | 本队湿实验 + 文献 |
| 目标与约束（C_target=1 μg/L、时限 T_limit、置信度 α） | 管理需求 |

## 1. 先建立心智模型：为什么不是"一个 k"？

初学者最容易想到的方案：**"MC-LR 的降解就是一级反应 C(t) = C₀·e^(−kt)，拟合出一个 k 就完事了。"**

这个方案在真实世界里会撞上三堵墙：

1. **速率常数跨体系差 3 个数量级。** 同样是"生物降解 MC-LR"：CQ5 菌株 k=0.015 h⁻¹，MlrA 粗酶伪一级最高 9.36 h⁻¹，伊利湖原位菌群 8.8–10 d⁻¹（≈0.4 h⁻¹）。哪一个 k 给我们的工程菌用？没有一个是"我们的"。**参数必须按菌株/体系分层**，而不能取一个全局常数。
2. **k 和剂量没有关系。** 单参数 k 无法回答"投放剂量 D"——k 的物理来源是菌量×酶活性，不把菌量和酶放进模型，就永远算不出剂量。
3. **环境不是恒定的。** 温度 20℃ 和 30℃ 的降解速率差一倍；pH、溶解氧、光照（触发自杀开关）都会改变速率。治理决策必须绑定现场条件。

这三堵墙直接决定了模型的总体形态（见 §2 的架构图）：

> **机理方程提供"骨架"（物理上必然成立的部分），统计校准提供"血肉"（数值上可信的部分），决策层把两者翻译成工程语言（剂量与时间）。**

## 2. 总体架构：四层灰箱

![图1 总体架构](../figures/fig1_overall_architecture.png)

### 2.1 为什么叫"灰箱"？

- **白箱** = 纯机理模型：每个参数都有物理/生物含义，可解释、可外推；但参数值不可信（没人测过我们这株菌的 kcat）。
- **黑箱** = 纯数据驱动（GBDT/LSTM）：拟合能力强；但本项目全球可用的降解曲线只有几十条，深度模型需要几千条起步，训练不动；而且 iGEM 评审要"工程闭环"，黑箱讲不清机理。
- **灰箱** = 机理结构 + 数据校准参数：数据需求量最小（湿实验 6–12 条曲线即可用）、每个数字都有生物学出处、还能显式输出不确定性。**这是数据稀缺场景下唯一能落地的选择。**

### 2.2 四层各自干什么（从上往下是数据流）

```
L1 数据与知识层 —— 原料
    ├─ 文献参数库（k、半衰期、酶活，来自 12 篇 OA 论文全文）
    ├─ 环境时序（水温、pH、DO、光强）
    ├─ 分子序列（mlrA 同源性 → 株系先验）
    └─ 湿实验数据（未来的主校准源）

L2 机理内核 —— 骨架（常微分方程 ODE）
    C(环状毒素) → L(开环产物) → P(四肽) → X(无毒小分子)
    B(菌量)：生长/光死开关；E(酶量)：诱导表达
    环境修正 f_T·f_pH·f_DO 乘进速率

L3 校准层 —— 血肉
    层次贝叶斯：文献先验 + 株间随机效应 → 后验分布
    （可选）ML 代理：把"秒级求解"交给离线训练的 GBDT

L4 决策层 —— 输出
    反问题：min 剂量 s.t. 达标时间 ≤ 时限（带置信度约束）
    → 决策卡（D*, t*, 不确定性来源, 二次投放建议）
```

## 3. 机理内核：状态方程逐项讲解

### 3.1 状态变量（模型里"活着"的量）

| 符号 | 含义 | 为什么需要 |
|---|---|---|
| C | 环状 MC-LR（毒物本体） | **必选**，决策目标就是它降到 1 μg/L |
| L | 线性化 MC-LR（开环产物，毒力大降但非零） | 回答"总毒性什么时候真正消失"，而非只看环状体 |
| P / X | 四肽 → Adda/小分子（无毒末端） | 质量守恒校验；P/X 可合并 |
| B | 活菌密度 | **必选**——剂量 D 就是 B 的初值，光控自杀会让 B 衰减 |
| E | 活性酶当量（MlrA 等） | mlr 基因被毒素诱导上调（首小时 25 倍），酶量是时变的 |
| C_intra（可选） | 胞内/藻细胞结合态毒素 | 杀藻后胞内毒素释放会造成"反冲峰"，治理不是单调下降 |
| C_ads（可选） | 沉积物/颗粒物吸附态 | 吸附是竞争性汇，忽略会把生物降解速率高估 |

### 3.2 主方程：每一步为什么这么写

**第一步（限速步）：MlrA 开环**

$$
v_A = \frac{k_{cat,A}\, E(t)\; C}{K_{m,A} + C}\cdot \psi(T,pH,DO)
$$

- **分子 `E·C`**：反应速率正比于酶量 × 底物浓度——质量作用定律的基本形式；
- **分母 `Km + C`**：Michaelis-Menten 饱和项。当 C ≪ Km（环境浓度段，≤50 μg/L）时退化为 `(kcat/Km)·E·C`，即**一级反应**——这就是文献里观察到的"近似一级"的数学来源；当 C 很大（mg/L 级）时速率封顶为 kcat·E，**自动防爆**；
- **`ψ = f_T·f_pH·f_DO`**：环境修正乘子（§4 详解），把"30℃ 最优、pH7 最优"的实测形状挂进速率。

**第二步起（合并为"后续步骤"）：MlrB → MlrC**

$$
\frac{dL}{dt} = v_A - v_B,\quad v_B = \frac{k_{cat,B}\, E_B\, L}{K_{m,B}+L}\cdot\psi,\quad \frac{dP}{dt}=v_B-v_C,\quad \frac{dX}{dt}=v_C
$$

- **为什么是级联而不是"一步到位"**：m6 的产物谱显示"开环很快、产物残留慢"——MlrA 开环是限速/最显著步骤，MlrB/C 更慢。只设一个状态 C 会漏掉"环状体没了但毒性中间体还在"的阶段。为控制参数数量，默认把 B/C 合并成"慢速后续"（Km 取大、kcat 取小）。

**菌量 B：本项目独有的"窗口"约束**

$$
\frac{dB}{dt} = \underbrace{\mu_{\max}\frac{S}{K_s+S}B}_{\text{生长项（可关）}} - \underbrace{\delta(I(t))\,B}_{\text{光控自杀/自然死亡}} - \kappa B_{\text{稀释冲刷}}
$$

- **生长项是"开关"**：CQ5 类菌株以 MC-LR 为碳氮源（μ>0，菌越用越多）；本项目工程菌大概率不代谢 MC（μ≈0，菌只衰减）。**这个开关必须在配置里显式声明**——它决定菌量是增是减，直接影响剂量曲线形状（差数倍）。
- **光控自杀 δ(I) 是本项目的安全设计带来的硬约束**：YF1-FixJ 模块在自然光（蓝光）下切断 DAP 合成 → 菌死亡。也就是说**露天湖水里菌的"有效降解窗口"可能只有几小时**。模型把这个窗口显式化：窗口 < 所需治理时间 → 自动输出"需要二次投放/载体避光缓释"的工程建议。这是"安全设计"与"治理可行性"的接口。

**酶量 E：诱导动力学**

$$
\frac{dE}{dt} = \alpha\,B\left(1 + \eta_{\text{ind}}\frac{C^n}{K_{\text{ind}}^n + C^n}\right) - \beta E
$$

- m6 实验：接触 MC-LR 后 **mlrA 首小时上调 25 倍**（mlrD 最少也有 18 倍），2–6 h 回落到 1 倍。所以酶不是"投放即满血"，而是有一个**启动爬坡期**——忽略它会把首 1–2 小时的降解速率低估；
- Hill 项 `C^n/(K_ind^n + C^n)`：毒素浓度越高诱导越强，饱和后封顶 `(1+η_ind)`；`β·E` 是酶失活/降解。

### 3.3 数值求解的工程细节（为什么这么设置）

- 求解器：`scipy.integrate.solve_ivp`，方法 `LSODA/BDF`——因为方程组**刚性**（酶促反应分钟级、菌群衰减小时级，时间尺度差千倍），普通 RK45 会步长爆炸；
- 单位制：内部统一 **μg/L 与 h**。mg/L 文献值（m6 高浓度实验、Klebsiella）换算时保留"原始值+换算因子"两列——单位错误是动力学建模第一高危事故；
- 无量纲化：时间 τ=t/t_ref、浓度 C/Km——避免量级差 1e4+ 导致雅可比病态。

> ⚠️ **诚实声明（教学要点）**：以上 6–9 状态完整方程组是**设计规格（v1.1）**。当前可运行原型 `prototype_v1.py` 只实现了 2 状态版（C、L）+ 指数衰减菌量 + 旧版环境修正函数，用于生成示意图。规格与代码之间的差距已列入 v1.2 里程碑。读图时请把图当"方向示意"，不要当"数值承诺"。

## 4. 环境修正模块：f_T、f_pH 从哪来、怎么选型

### 4.1 形式：乘性因子

$$
\psi(T,pH,DO) = f_T(T)\cdot f_{pH}(pH)\cdot f_{DO}(DO)
$$

乘法结构的理由：物理上"温度影响酶活"与"pH 影响酶活"机制独立，乘起来是合理近似；且每个因子保持单变量可解释（评审时能一句话说清）。代价是忽略交互项（见 §4.4 的适用域限制）。

### 4.2 f_T：CTMI 温型模型（v1.1 选型）

$$
f_T(T) = \frac{\mu_{opt}\,(T-T_{max})(T-T_{min})^2}{(T_{opt}-T_{min})\left[(T_{opt}-T_{min})(T-T_{opt})-(T_{opt}-T_{max})(T_{opt}+T_{min}-2T)\right]}
$$

（Rosso et al. 1995 的 Cardinal Temperature Model with Inflection，用于描述微生物生长/活性的标准温型曲线。）

用 m6 的四个实测点（20℃/30℃/37℃/40℃）拟合得到：**T_min=7.97℃、T_opt=30.68℃、T_max=40.00℃**。

**选 CTMI 而非对称高斯的理由**：
1. 高斯无法同时还原"37℃ 仍有 0.6× 活性"和"40℃ 活性归零"——这两个点之间要一个**陡肩**，高斯做不到（R² 只有 0.855）；
2. CTMI 的参数**有物理意义**：T_min（最低生长温度）、T_opt、T_max——这使"株间随机效应"可以落在物理量上（不同菌株的 T_opt 不同），而不是落在抽象系数上；
3. T > T_max 时函数**自动归零**（天然物理边界），省掉 v1.0 时代"T<38 硬截断"这种拍脑袋补丁。

> 🧭 **批判性阅读提示**：4 个数据点 + 4 个参数 = **恰好确定的插值问题**，R²=1.0000 是"过拟合的必然"，不是"模型很准"的证据。更严格的做法是留一交叉验证（4 个点轮流拿一个当验证）或用 3 参数约束型。选 CTMI 的真正理由是**形状物理性**（尖峰+归零边界），R² 只是附带品。——此点已写入审查结论，供学习"如何不被 R² 骗"。

### 4.3 f_pH：非对称高斯

$$
f_{pH}(pH) = \exp\left(-\frac12\left(\frac{pH-pH_{opt}}{w}\right)^2\right),\quad w = \begin{cases} w_L & pH < pH_{opt} \\ w_R & pH \geq pH_{opt} \end{cases}
$$

m6 五点拟合：**pH_opt=6.30、w_L=1.00、w_R=2.31（R²=0.9927）**。

**为什么要非对称**：实测 pH3=0.19 μg/L/h（峰值的 5.7%）说明**酸性侧塌得极快**；对称高斯会把 pH3 低估 3 倍（预测 0.57×）。酸侧/碱侧各一个宽度参数就能修好。

**株间差异的证据**（这是 v1.1 最重要的新发现之一）：Klebsiella TA13/14/19 在 pH 6–10 区间速率几乎平坦（max/min 仅 1.17–1.35），而 m6 是强钟形。**同一个 f_pH 函数族，参数必须按菌株分层**——这就是层次贝叶斯（§5）存在的物理理由。

### 4.4 交互项与适用域（模型敢不敢外推的边界）

- YF1 的 Box-Behnken 响应面数据（17 组）复算：全二次模型 R²=0.9888，纯乘性模型 R²=0.9002，**交互项增益 ΔR²≈0.089**。也就是说在 **μg/mL 级高浓度**下，T×pH×C 的交互不可忽略；
- 结论：**浓度 ≤50 μg/L（环境浓度带）用乘性近似 + 显式域检查；超出就拒绝出答案**（输出 "out of domain" 而不是瞎编一个数）。这是"宁可拒答不可乱答"的工程伦理。
- 适用域（SLOV 域）的硬边界：T≤40℃（CTMI 自动归零）、pH 在实验覆盖范围、浓度 ≤50 μg/L 等。第 14 轮迭代专门加了"外域拦截"。

### 4.5 f_DO 与其他因子

- f_DO = DO/(K_DO+DO)：饱和型，缺氧时降解显著变慢（菌是异养需氧）；
- 浊度/营养盐不作为乘性因子，而是作为**背景降解 k_bg 和诱导项的协变量**（文献：mlr 基因表达受碳源浓度调控，低碳诱导上调）。

## 5. 校准层：层次贝叶斯——"借用别人的数据"

### 5.1 问题：我们的工程菌没有数据

工程菌（E. coli + mlr 基因簇 + Adda 转氨酶）谁也没测过降解速率。而文献里有十几株天然菌的速率，跨 3 个数量级。怎么"借"？

### 5.2 核心结构：株间随机效应

$$
\log k_{i,j} \sim \mathcal{N}(\mu + \mathbf{x}_j'\boldsymbol\beta + u_j,\ \sigma^2),\qquad u_j \sim \mathcal{N}(0,\tau^2)
$$

- **i**：观测点；**j**：菌株/体系（m6、YF1、CQ5、Klebsiella、MlrA 粗酶、原位菌群……）；
- **u_j（随机效应）**：每个菌株相对"平均水平"的偏移——**这就是吸收 3 个数量级离散的机制**：不同株的快慢被建模为同一个正态分布族的抽样；
- **协变量 x_j**：mlr 类型（mlr⁺/mlr⁻）、表达宿主（纯酶/整细胞）、是否以 MC 为碳源、底物特异性类别（Adda-Arg 位可水解=LR/YR/RR 类）——这些"标签"决定一株新菌该从先验的哪个位置出发；
- **v1.1 扩展**：不只 k 分层——**T_opt、pH_opt、w_L/w_R 也分层**（温带型 m6：T_opt≈30℃、强钟形 vs 热适应型 Klebsiella：T_opt≥40℃、pH 平坦）。当序列比对（D5 fasta 数据）提示我们工程菌的 mlrA 与某族同源，就切换到该族先验。

### 5.3 为什么是贝叶斯而不是最小二乘？

1. **小样本**：湿实验只有 6–12 条曲线，最小二乘会过拟合；贝叶斯用文献先验"垫底"，数据少时退化为先验传播，数据多时逐渐被数据主导；
2. **输出天然是分布**：决策层要的是"90% 概率达标"，只有后验分布能直接算 `P[t_safe ≤ T_limit]`；
3. **重尾观测模型（Student-t，ν≈4）**：防止 CQ5 这种慢 16 倍的"离群体系"被快速体系带偏——它不应该被当噪声丢掉，它代表"另一类菌"的真实存在。

### 5.4 可辨识性管理（小数据配大模型的必修课）

自由参数约 **11 个**（kcat,A、Km,A、α、η_ind、K_ind、δ_max、K_I、T_opt、w_T、pH_opt、w_pH、σ……），小数据下必然共线。对策：

1. **合并**：MlrB/C 合并成单步；固定 K_d（浊度外生）；固定 k_bg（文献先验）；
2. **组合参数化**：kcat 与 Km 强相关 → 改用 kcat/Km 一个组合参数；
3. **Profile likelihood / Fisher 谱**：先算"哪些方向弱"，再决定固定谁；
4. **实验设计前置**（干实验反哺湿实验的落点）：用 D-最优设计在**做实验之前**模拟选点，保证 (a) 1 h 内采样（抓诱导项）、(b) 高低浓度跨 Km（抓饱和项）、(c) 温/pH 覆盖（抓修正函数）。

### 5.5 ML 组件（可插拔，当前未训练）

| 组件 | 干什么 | 启用条件 |
|---|---|---|
| 仿真代理（GBDT/GP） | 把 10⁴–10⁵ 次 ODE 求解替换成秒级查询 | 决策层上线时；训练数据=机理模型仿真 5×10⁴ 样本 |
| 残差学习 | 学"机理模型的系统性偏差" | 湿实验 ≥300 点，需独立验证集 |
| 迁移学习 | 文献株参数 → 工程菌 | 序列相似度作为先验缩放 |
| PINN/神经 ODE | 端到端机理+数据融合 | 数据 >1000 点（远期） |

> 选 GBDT 做代理的理由很实际：与项目既有技术栈一致（`model/` 已用 XGBoost+LightGBM），部署链路、SHAP 解释、团队经验全部复用。

## 6. 决策层：把曲线翻译成"剂量-时间"

### 6.1 反问题

$$
D^* = \arg\min_D \text{cost}(D)\quad \text{s.t.}\quad \mathbb{P}[\,t_{safe}(C_0,D,T,pH,\dots) \le T_{limit}\,] \ge 1-\alpha
$$

- **t_safe**：C(t) 首次 ≤1 μg/L 的时刻；
- **为什么用概率约束（机会约束）而不是期望值**：k 的分布右偏（对数正态），"平均达标时间 13 h"完全可能伴随"5% 概率 24 h 不达标"。用期望值做剂量会**系统性低估**——这是图 6 的核心教训（90% 区间横跨 7–24 h）；
- **cost(D)** 三部分：① 剂量成本（菌液制备/载荷）② 超时惩罚 ③ **环境残留惩罚**（剂量过高→生态扰动；这是安全评审的加分项：模型只输出"最小有效剂量"）；
- **上界约束** D ≤ D_max：无人机载荷、监管红线，避免优化器给出不现实的剂量。

### 6.2 决策卡长什么样

```
场景：C0=20 μg/L，水温 30℃，pH 7
→ 推荐剂量：D = 1.0×（m6 当量）
→ 预计达标：13 h（90% 区间 7–24 h）
→ 主要风险：温度偏离最适 5℃ 会使达标时间 +30~100%
→ 光死窗口检查：δ 标定后若窗口 < 13 h → 建议二次投放
```

### 6.3 剂量-时间等值线图：模型的"使用手册"

![图5 剂量-时间等值线](../figures/fig5_dose_time_contour.png)

读图方法：横轴 C₀（现场测到的初始浓度），纵轴 D（投放剂量），颜色/黑线=达标时间(h)。**白色区域 = 72 h 内无法达标**。

- **这条"不可行域"边界本身就是最有价值的工程输出**：提前告知中控"菌液治理解决不了这个浓度，需要升级处置"（物理打捞/氧化应急）；
- **等值线族直接用作飞行调度表**：给定 C₀ 和时效要求，反查所需剂量档位。

### 6.4 边际收益递减（模拟结论）

剂量每翻倍，达标时间近似**对数**缩短（不是线性！）。所以决策层输出"有效剂量带"而非单一最优值——D=2× 和 D=3× 可能几乎一样快，省下的一倍菌就是省下的成本与环境风险。

## 7. 不确定性：为什么所有输出都带区间

### 7.1 蒙特卡洛传播示意（图 6）

![图6 不确定性传播](../figures/fig6_uncertainty_band.png)

采样 k~LogN(0.25, σ=0.35)、T~N(28.5, 1.8)、pH~N(7.2, 0.5)，每条曲线一个样本，画出 50%/90% 分位带：

- 中位达标 ≈13 h，90% 区间 7–24 h 以上；
- **5% 分位路径 24 h 后仍未降到 1 μg/L**——如果管理层要的是"90% 把握在时限内达标"，所需剂量必须显著上调。这就是"点估计必然失手"的量化证据。

### 7.2 三层不确定性来源

1. **参数不确定性**（后验传播）——本模型的主输出；
2. **输入不确定性**：C₀ 本身是荧光反演结果（带 σ₀），模型把 σ₀ 一起传进来（上游校准模块的 σ 直接影响剂量修正）；
3. **结构不确定性**：机理方程本身的简化误差——用残差学习（§5.5）在数据充足后吸收。

### 7.3 灵敏度分析

Sobol' 总效应排序回答"哪一个参数最值得测准"——预计第一名是 k（剂量直接乘它），其次 T_opt。**灵敏度排序会直接写进湿实验优先级**：预算有限时先测对决策影响最大的量。

## 8. 与外系统接口（模型不是孤岛）

| 方向 | 接谁 | 接口 |
|---|---|---|
| 上游 | 浓度校准模块 | 输入 C₀ ± σ（多时间点标准曲线反演结果） |
| 上游 | 浓度预测模型（model/ 的 XGBoost+LightGBM 集成） | 预警触发后传入预测场景 C₀ |

**分工边界（明确不做）**：不模拟藻华产生（上游模型的事）；不做大面积 2D 扩散（水流模型的事）；不做毒理分级（预警模块的事）。模型边界清晰是模块能并行开发的保证。

## 10. 一条完整数据流的走查（综合例题）

**场景**：东湖某点，检测节点报 C₀=20 μg/L（荧光标准曲线反演，σ₀=±15%），水温 30℃，pH 7.2，上午 10 点（自然光强，光死开关活跃）。目标 24 h 内降到 1 μg/L，置信度 90%。

1. **L1 收数据**：C₀、T/pH/光强时序；工程菌 mlrA 与 m6 同源（序列比对）→ 选用"温带型"先验族；
2. **L2 跑机理**：ODE 求解 C(t)——酶诱导 1 h 内爬坡、光死使菌量小时级衰减、T/pH 修正乘子生效；
3. **L3 传播不确定性**：后验采样 400 条轨迹 → t_safe 分布 = 中位 13 h、90% 区间 7–24 h+；
4. **L4 做决策**：机会约束检查"24 h 内 90% 概率达标"→ 若 5% 分位路径不达标，剂量上调至满足约束的最小值 D\*；光死窗口检查 → 窗口够则单次投放，不够则输出"二次投放时间窗"；
5. **输出决策卡** → JSON → 无人机调度系统装载 D\* 当量菌液，投放后实测 C(t) 回灌 L1（在线更新参数）；
6. **治理结束**：C ≤1 μg/L，光控自杀清除残留菌，节点持续监测以防"胞内释放反冲峰"。

## 11. 模块选型理由一览表（面试/评审速答版）

| 决策点 | 候选方案 | 选了谁 | 一句话理由 |
|---|---|---|---|
| 模型大类 | 纯机理 / 纯 ML / RSM | **灰箱混合** | 数据太少喂不动 ML；纯机理参数不可信；灰箱是数据效率×可解释×可外推的最优平衡 |
| 速率定律 | 一级 / Monod / 底物抑制 | **Monod（含退化）** | 低浓度自动退化一级（匹配观测），高浓度自动饱和（防爆）；Haldane 抑制项默认关 |
| 菌量 | 常数 / 动态 B(t) | **动态 B(t)** | 光控自杀与生长耦合决定"有效窗口"，常数假设会系统性高估 |
| 环境修正 | 乘因子 / RSM 二次型 | **乘因子+分层校准** | 可解释；交互项经 YF1 验证仅在 μg/mL 带显著，环境浓度带用乘性+域检查 |
| f_T | 高斯 / Arrhenius / CTMI | **CTMI 四参数** | 参数有物理意义、自带 T_max 归零边界；温型肩部高斯拟合不了 |
| f_pH | 对称高斯 / 非对称高斯 | **非对称高斯** | 酸性尾实测塌得快，对称型低估 3 倍 |
| 参数估计 | 最小二乘 / MLE / 层次贝叶斯 | **层次贝叶斯** | 跨株随机效应吸收 3 个数量级离散；小样本强先验；输出分布直接支撑概率约束 |
| 观测误差 | 正态 / Student-t | **Student-t（ν≈4）** | 防止 CQ5 慢速体系被当离群点丢/带偏 |
| 决策 | 期望值反解 / 机会约束 | **机会约束 P≥1−α** | k 右偏，期望值会系统性低估剂量 |
| 部署代理 | 查表 / GP / GBDT | **GBDT+XGBoost** | 与项目既有模型栈一致；秒级查询；SHAP 解释 |
