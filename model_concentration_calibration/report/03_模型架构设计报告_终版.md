## 1. 任务定义与信号链

把装置光电读数 y 映射为 MC-LR 浓度估计、置信区间与 1 μg/L 预警等级。全链路：

```
C(MC-LR) →[START核糖开关+适配体]→ [LuxI/LuxR 群体感应放大] → sfGFP/TurboRFP 比值荧光 Q(t)
→[LED激发+滤光片+光电二极管+TIA+ΔΣADC]→ 装置计数 y → [本模型] → ĉ, CI, P(C≥1μg/L) → 预警等级
```

![架构总览](figures/fig1_architecture.png)

## 2. 数据现实与约束（决定架构的三个事实）

**事实 1（小样本）**：湿实验数据为 8 浓度 × 8–9 时间 × 3 重复 × 8 trigger，约 1700 条双通道记录；强相关协变量（C 与 t 高度耦合），且缺 OD600/独立生物重复。→ 排除数据饥渴模型（深度网络、大集成）。
**事实 2（弱信号）**：正响应 trigger 实测折合比幅度 0.09–0.29，RFP 内参 CV 3–7%。→ 在相对噪声 3–9% 下，单点 LOD 位于 1.5–3 μg/L；阈值判别的信息量远大于连续定量。
**事实 3（异质构型）**：trigger 间基线、幅度、峰值时间、符号都不同；部分非单调（trigger5 高浓度回落、trigger4 尖峰）。→ 必须以构型为单位建模并声明可辨识域。

## 3. 模型架构

### 3.1 第一级：生物传感前向模型（每 trigger 一个）

折合比（归一化剂量-响应）：Fold(C,t) = Q(C,t)/Q(0,t) = 1 + A(t)·Hill(C; K(t), n(t))；
A(t)=Amax·(1-e^(-t/τA))·e^(-t/τD)（幅度先升后衰）；K(t)=Kf+(K0-Kf)·e^(-t/τK)（EC50 随放大下降）；n(t)=n0+n1·(1-e^(-t/τN))（超灵敏上升）；σ²(F)=(a_rel·F)²+s_floor²。基线 Q(0,t) 由同板 0 μg/L 实测锚定；负响应构型用符号类 amp_sign=-1。
![剂量响应族](figures/fig2_family.png)

### 3.2 第二级：参数后验（MAP + Laplace）

对数后验 = 逐点似然 + 11 参数先验（量级来自机理文献）；L-BFGS-B 多起点；数值 Hessian → 高斯近似 → 后验采样（500–1500 条）。
### 3.3 第三级：浓度反演 + 多时间点融合 + 决策

p(C|data) ∝ Σ_θ p(θ|D)·Π_i N(y_i; Fold(C,t_i;θ), σ²_i)·p_env(C)，在 log10(C)∈[-2.5,2.0] 网格（231 点）上积分；p_env 为环境先验（默认对数正态，可被 redo_v2 风险图替换）。输出：中位数、90% 区间、P(C≥1 μg/L)。预警：期望成本最小化（漏报:误报=10:1 → 阈值 P≥1/11≈0.09）；三级输出+质量旗标。
![多时间融合](figures/fig4_fusion.png)

### 3.4 光电读出链（装置级校准）

r = a·Q + b + dark(T)（暗电流等效偏置，每 +10°C 翻倍；每周期先测暗基线可扣除）；4 标准点仿射标定 + RFP 单色标样 + 荧光珠哨兵；双 LED 方案需光通量监视或改单 LED+双发射滤波。
![装置链](figures/fig6_device.png)

### 3.5 边缘部署

参数 JSON（<20 浮点）+ 单调反演查找表（每时间节点 32–64 点，实测 LUT 往返 log10 误差中位 0.0026、最大 0.0085）+ 解析反演校验（C=K·[u/(1-u)]^(1/n)）。
### 3.6 验证体系

批次数目不足时 leave-one-rep-out + 孔级 bootstrap；log10 MAE/RMSLE、90% 覆盖率、阈值 AUC、可靠性曲线、Brier、LOD/LOQ(3σ/10σ)。
## 4. 组件选择理由（终选表）

| 组件 | 候选 | 终选 | 理由 |
|---|---|---|---|
| 响应函数 | 时变 4PL / 时变 Hill / GP / GBDT-MLP / ODE | 时变 Hill（等价 4PL 形式） | 机理可解释、11 参数可辨识、解析可逆、边缘可部署；GP/MLP 在 <1500 行数据下外推与可解释均差；ODE 参数过多不可辨识 |
| 时间处理 | 每时间点独立标准曲线 / 时间协变量 / 函数型 PCA | 时间协变量+多时间点似然融合 | 化解选哪条曲线的争议；合成实证：真值 1.0 μg/L，t=2h 单独 P≥1=0.92、t=4h 0.19、融合 0.50 且中位 1.01 |
| 参数推断 | 极大似然 / MAP+Laplace / HMC-NUTS | MAP+Laplace + 网格 C 后验 | 小样本稳定、可复现；HMC 列为未尝试 |
| 浓度先验 | 无（平先验）/ 环境对数正态 | 环境对数正态（可替换为 redo_v2 风险图） | 平先验在平台区导致后验冲向高 C |
| 反演 | 解析反函数 / 牛顿 / 网格积分 | 网格积分（在线）；解析+LUT（边缘） | 非对称、可能双峰的后验只有积分形式可靠 |
| trigger 处理 | 全局模型 / 随机效应 / 逐 trigger 独立 | 逐 trigger 独立（含符号类） | 构型间基线/符号/峰值异质；随机效应会收缩掉性质差异 |
| 装置迁移 | 固定全局标定 / 每台仿射 / 仿射+串扰+温度 | 仿射+暗电流校正+串扰矩阵（协议化） | 跨 CMOS/PCB 差异实测显著；双 LED 共模风险 |
| 目标函数 | 纯回归 / 直接分类 | 回归+贝叶斯阈值决策（分类器仅交叉验证） | 连续 CI+外推；10:1 成本阈值贴合漏报风险 |

## 5. 验证结果

### 5.1 合成数据参数恢复（seed=42）

trigger1: Amax 0.42→0.40、K0 3.5→5.1、n0 1.1→1.3、τA 3.3h→4.2h（主要参数良好）；trigger5: 0.75→0.78、2.5→2.4、1.0→1.1、1.5h→1.5h（优秀）；trigger6: 0.60→0.47、1.4→2.1、1.2→1.3、2.0h→1.7h（良好）；trigger7(负): −0.12→−0.15、K 弱可辨识。
### 5.2 合成数据 LOD/LOQ 与阈值判别（t=6h）

trigger1: LOD 1.34 μg/L、LOQ 不可达、AUC 0.981；trigger5: 0.38 μg/L、不可达、0.979；trigger6: 0.28 μg/L、不可达、0.875；trigger7: 负响应作阴性对照。LOBO（n=81/trigger）：MAE(log10) 0.368/0.320/0.456，覆盖率 65%/61%/54%（低于名义 90%，高斯近似+未建模相关性的代价），平先验 MAE 0.434/0.392/0.607。
### 5.3 装置级（仿真，v2 修复后）

无标定 Q 中位相对误差 3.0%；25°C 4 点仿射标定 1.44%；漂移到 45°C 未扣暗基线 1.66%（暗电流偏置+温度敏感）；45°C 但每周期扣暗基线 1.42%（与 25°C 持平）——证明「先测暗基线再扣除」协议有效（fig6 三个对比臂）。

### 5.4 多时间点融合实证（合成）

trigger5 真值 1.0 μg/L：t=2h 单独 P≥1=0.919（偏高）；t=4h 单独 0.19（偏低，非单调时间）；2+4+6h 融合 → 中位 1.01、CI[0.70,1.58]、P≥1=0.50——决定性证据，多时间点融合成为核心组件。

## 6. 尚未尝试的方案（诚实清单）

1. 完整贝叶斯抽样（HMC/NUTS，PyMC/Stan）——改进 54–65% 覆盖率的直接路径；2. 孔内时间自相关（well 随机效应+AR(1)）与函数型特征化（0–6h AUC、斜率、峰时）；3. Student-t（ν≈5）稳健似然；4. GP 残差项（真实数据 >300 行/trigger 时启用）；5. 直接阈值分类器交叉验证；6. 逐浓度异方差/OD 协变量；7. 浊度协变量（需硬件）；8. 分子缓冲器/浓度先验联合优化；9. 多节点 fuse() 接口（07 报告 §2B 已规划）。

## 7. 优点与局限

优点：可解释（参数有生物学语义）；小样本友好（11 参数+机理先验）；不确定性完整；直接解决多时间点争议；可部署（LUT+解析反演）；面向任务（成本化阈值决策）。
局限：1. 弱信号上限——真实数据下正响应单点 3σ 检出 1 μg/L 不可靠，预警级输出须依赖多通道融合；2. 群体平均抹平单细胞差异；双稳态/滞后未建模；3. 单批次技术重复——一切指标为批次条件化；4. 覆盖率 54–65% 不足；5. 装置端仍为仿真（域迁移待实物验证）；6. 行位混杂未修复前定量结论需谨慎（附录 C）；7. 非单调构型可辨识域受限。

## 8. 未来推进方向

数据：按契约采集（板位随机化+生物重复+OD600+10 μg/L）；装置-酶标仪同步标准品；redo_v2 东湖风险图替换 p_env；数字化更多文献校准曲线。模型：HMC+AR(1)；峰区二分模型；跨 trigger 分层收缩；置信化判别器；多节点融合 fuse()。训练：合成→真实先验再校准；主动学习选标定浓度；设备哨兵在线更新 affine。硬件/系统：单 LED+双发射滤波；外置 ΔΣ ADC；浊度通道；双层旗标；本模型输出直接接入流场/降解/路径接口（07 报告）。

## 附录 C：真实数据审计发现（2026-08-23）

**C1 行位混杂**：浓度按行固定排布；0h RFP 随行 +25%（4.94→6.15）而 GFP 平坦——行效应（光路/加样/系统误差）污染 Q 与 fold。修复：板位随机化+多位置对照（优先级最高）。
**C2 归一化路径差异**：docs 的 DoubleNorm=[Q(c,t)/Q(0,t)]/[Q(c,0)/Q(0,0)]，其中 0h 因子含行梯度（本例约 0.8 量级），会把 1.0 的 fold 放大为 1.2–1.3——trigger1 的 24h 峰很可能主要来自 0h 归一化因子。模型采用逐时间 fold，结论更保守；建议湿实验统一 per-time fold，DoubleNorm 仅作诊断。
**C3 技术重复≠独立**：√3 增益为上限；真实提升靠跨天生物重复与多节点空间重复。
