## 3. 发现的问题清单

### P0（会误导使用者，必须修）

**P0-1. README 复现入口之一崩溃。** `scripts/_run3.py` 对 `lod_loq` 返回的 `None`（LOQ 量程内不可达）直接做浮点格式化，脚本中断。修复在 `_run4.py` 里已经存在（`fmt` lambda），但 `_run3.py` 没有同步。→ 建议：把 `_run4.py` 的 None 安全格式化回填 `_run3.py`，或从 README 复现清单中移除 `_run3.py`。

**P0-2. 装置温度漂移实验是"空演示"。** 报告 §5.4 声称"未补偿 +20°C 温漂时 Q 中位相对误差回到 1.5%（暗电流偏置主导）"。但 `device.py::readout()` 中暗电流**只进入一个噪声附加项**（系数 0.004，量级约 10⁻⁵，比 device_noise=0.02 低 3 个数量级），**从未作为偏置加到输出上**。我实测 25°C vs 45°C 的读数均值差为 **-3.6×10⁻⁷**（噪声 std 为 2.4×10⁻²）——温度对模拟输出零影响，_fig6.py 的"+20°C 漂移"箱线图与"已标定"箱线图相同是构造使然，而非验证了任何结论。括号里"暗电流偏置主导"的说法与代码行为相反。→ 建议：`readout()` 改为 `r_base = a*Q + b_off + I_dark(T)·gain/V_ref_norm`（把暗电流作为偏置项加入），再重跑 fig6，此时"每周期先测暗基线（LED 关）补偿"的协议才有真实价值可以展示。

**P0-3. `evaluate.py` 与 `synth.py` 接口不一致。** `synth.gen_dataset()` 返回键为 `fold`，而 `evaluate.lobo_cv()` 读取 `data['Q']` —— 任何人按模块说明调用 `lobo_cv(gen_dataset())` 会直接 KeyError。实际 LOBO 实验是在 `_run5.py` 里内联手写的，`evaluate.py` 从未被真正使用。→ 建议：统一键名（如 `fold`），让 `lobo_cv` 可独立运行，并补一条冒烟测试。
