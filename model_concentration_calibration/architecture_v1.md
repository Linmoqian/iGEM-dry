# 浓度标定模型架构设计 v1（待外部审查）

## 0. 任务定义

将工程菌检测节点的光信号（sfGFP/TurboRFP 双荧光）转换为 MC-LR 浓度估计及其不确定度，并给出 1 μg/L（WHO 红线）预警分级决策。信号链：

```
C(MC-LR) → [START核糖开关+适配体] → [LuxI/LuxR QS放大] → G,R(荧光RFU) → [激发LED+滤光片+光电二极管+TI放大器] → y(ADC计数) → [本模型] → ĉ, CI, P(C>1μg/L) → 预警等级
```

## 1. 已知约束与数据现状（来自 docs/Introduction）

- 浓度梯度：0, 0.05, 0.1, 0.25, 0.5, 1, 2, 5, 10 μg/L；时间点 0,0.5,1,1.5,2,2.5,3,4,5,6,9,24,33h（不同批次不完全一致）；每浓度 3 重复；多 trigger 构型（trigger0-7，其中 trigger1/6/5 为优先候选）。
- 读数：GFP/RFP 比值 Q(t)，双归一化 DoubleNorm = [Q(c,t)/Q(0,t)] / [Q(c,0)/Q(0,0)]；RFP 内参 CV 中位数 3.21%，但 trigger4/7 早期或后期 CV 可达 12%。
- 已知现象：响应非单调（如 trigger5 高浓度回落，trigger4 在1μg/L尖峰）、trigger7 负响应、6h 后部分曲线下降（GFP 衰减或 RFP 积累超过 GFP）、不同 trigger 基线信号不同。
- 训练数据量级：约 8-13 trigger × 8-13 浓度 × 8-13 时间 × 3 重复 ≈ 数百到一千余行——属于小样本；且尚未有装置端（光电二极管/ADC）的成对标定数据。

## 2. 模型设计（v1 决策）

### 2.1 总体结构：两级混合模型（信息型参数化 + 层次贝叶斯）

第一级：生物-光学前向模型 F(C, t; θ)：
  Q(C,t) = 基线(t) + 幅值(t) × Hill(C; K(t), n(t))
其中 {基线, 幅值, K, n} 随 t 变化，用低维光滑函数（指数/幂律）描述：例如 K(t) = K∞·(1 - (1-K0/K∞)·exp(-t/τK))，幅值 A(t) = A∞·(1-exp(-t/τA))·衰减因子；这保留 4PL 的可解释性，同时把“时间”从离散标准曲线族 T_i(X) 变成连续协变量。

备选（v2 候选）：用简化的 QS 常微分方程（dAHL/dt = kI·N·σ(C) - d·AHL；dG/dt = kG·Hill(AHL) - λG·G；dR/dt = kR - λR·R；含 sfGFP/TurboRFP 成熟延迟）替换解析 Hill。ODE 版可解释双稳态/正反馈时间动态，但参数更多、可辨识性更差，需要更多数据或强先验。

第二级：校准反演。给定观测比值 q_obs（可由任意时间点 t 或时间序列 Q(t) 整条曲线），求后验 p(C | data)：
  - 单时间点：利用同一根 S 曲线数值反演（一维 Newton/bisection），结合参数后验做不确定度传播（Laplace 近似 + MC 采样）。
  - 多时间点：多时间点似然乘积（数据融合），一举解决“哪个时间点标准曲线最好”的争议——每个时间点只是似然的冗余证据，由数据自动加权，无需人为选时间。
- 参数不确定性：层次贝叶斯。批次/设备随机效应（batch→plate→well），每个量测 y ~ N(F(θ_batch), σ²(C,t))，σ² 用异方差模型（相对误差 + 底噪），先验来自文献（Kd、Hill n、LOD 量级）与合成模拟（ODE QS 模型生成先验）。拟合：MAP + Laplace；小数据时用强正则先验 + 经验贝叶斯。

### 2.2 光电读出链建模

y = g·[T(λ)·Φ_fluor + Φ_bg] + b + ε；Φ_fluor ∝ 荧光强度；暗电流 I_dark(T) 随温度指数增长；噪声 = 光子散粒噪声 ⊕ 暗电流噪声 ⊕ 读出噪声 ⊕ ADC 量化。每台设备用少量标定点（3-4 个标准浓度）拟合 g,b（外加温度校正项），把不同 PCB/LED/探测器差异压缩为仿射转移——参考 Scentinel 手机生物传感器论文的“板载校准”思想。

### 2.3 阈值预警与指标

- 决策：P(C ≥ 1 μg/L | data) 与 成本加权的贝叶斯决策（漏报代价 > 误报代价，例如 10:1）；输出三级（安全/关注/预警）。
- 指标：LOD/LOQ(IUPAC 3σ/10σ)、EC50、Hill n、动态范围；校准质量：log-空间 MAE、90% 区间覆盖率、偏差曲线；阈值性能：AUC、平衡准确率、决策成本。

### 2.4 小样本对策

1) 文献先验：从已下载论文中整理 Kd/EC50/LOD/线性范围（literature_calibration_data.csv）→ 参数先验区间；2) 机理先验：ODE QS 模拟生成合成剂量-时间曲面，作为前拟合（pretrain/先验）数据；3) 数据增强：加入 trigger 随机效应与菌龄效应；4) LOBO(leave-one-batch-out) 交叉验证；5) 若数据超过 ~300 行再考虑 GP 残差项。

### 2.5 部署（ESP32 MCU）

- 推理面：4PL/Hill 参数（<20 个浮点数）+ 预计算的单调反演查找表（32-64 个节点的一维样条）+ 设备仿射参数（2-4 个）；无需迭代根求解。
- 输出：ĉ、区间、预警等级；固件单次推理微秒级。

## 3. 候选方案与淘汰理由

| 方案 | 优点 | 缺点/淘汰理由 |
|---|---|---|
| 纯 4PL（每时间点一条曲线） | 简单、GraphPad 标准 | 时间碎片化、需人工选时间点、小样本下过拟合 |
| 纯机器学习（XGBoost/小MLP） | 灵活 | 数据量不足（<2000 样本且强相关性）、缺乏物理约束、外推差、不可解释 |
| 纯 ODE 机理模型 | 生物机制清楚 | 参数过多、可辨识性差、与光电链耦合困难 |
| GP（高斯过程）回归 | 非参数、自带不确定度 | 小样本外推差、不保证单调、EDGE 部署重 |
| 混合方案（本方案） | 物理可解释 + 贝叶斯不确定度 + 可部署 | 参数化假设可能失配（用残差诊断与 GP 残差兜底） |

Q1. Hill 随 t 变化 vs QS-ODE：哪个在 100-1000 样本内更稳？
Q2. 非单调/负响应（trigger7）如何处理：单独 trigger 建模 vs 全局分层？trigger 是否作为随机效应？

Q5. 阈值 1 μg/L 的预警决策：回归+贝叶斯 vs 直接分类器，哪个更稳？
