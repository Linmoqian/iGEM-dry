# 当前关键数据缺口与搜索 Agent 提示词

## 缺口优先级

1. **东湖/武汉本地域毒素真值（最高优先）**：当前有中国水质与遥感协变量，但几乎没有东湖同日配对的 total MC 或 MC-LR 水体浓度。没有本地域标签，任何“东湖精准模型”只能做外域迁移，无法证明本地准确性。
2. **采样日动态气象和水文**：CHELSA 是静态常年值；需要降水、风速/风向、太阳辐射、气温、湿度、水位、流量及前 1/3/7/14/30 天累计/均值。GLAST 只到 2020。
3. **中国湖泊毒素 + 完整水质配对**：需要太湖、巢湖、滇池、洱海、东湖等具备日期、站点、坐标、MC/MC-LR、TN、TP、温度、DO、pH、浊度、Chla 的同一样本表。
4. **方法与删失元数据**：不少来源缺 LOD/LOQ、检测方法、样品组分（总/溶解/颗粒/胞内/胞外）或单位确认，限制跨来源校准。
5. **高浓度与水华峰值样本**：数据分布中低浓度与未检出多；需要有设计地覆盖峰值、暴发前后和极端气象过程，否则高风险召回率不稳定。
6. **工程菌传感器湿实验标定**：最终部署若预测 GFP/RFP 或传感器响应，必须获得标准 MC-LR 梯度、温度/pH/离子强度干扰、响应时间、批次与重复实验数据。环境模型不能替代传感器标定。

## 可直接交给数据搜索 Agent 的主提示词

```text
你是一名严谨的数据获取与湖泊水华建模专家。请在不删除、不覆盖任何现有文件的前提下，为“武汉东湖/中国湖泊微囊藻毒素精准预测模型”开展定向数据扩张。工作目录为本仓库，下载目标为 model_redo/data/external_raw，临时代码只能放在 model_redo/data/tmp_code，新建数据集必须各自拥有独立目录和 README.md。

目标优先级：
P0：武汉东湖或武汉城市湖泊的水体 total microcystins/MICX 或 MC-LR 实测浓度，必须尽可能包含真实采样日期、站点/湖区、经纬度、样品深度、单位、方法、LOD/LOQ；优先原始表而非论文图。
P1：中国太湖、巢湖、滇池、洱海、东湖、鄱阳湖及长江中下游湖泊中“毒素与同一样本水质配对”的数据：水温、DO、pH、浊度、电导率、TN、TP、NH4-N、NO3-N、Chla、Secchi、蓝藻密度/藻蓝蛋白。
P2：上述湖泊或已有毒素观测点的采样日动态外部数据：ERA5-Land/站点气象的降水、风、辐射、气温、湿度；湖面温度；水位/流量。需要支持前 1/3/7/14/30 天特征。优先 2000 年至今，重点 2021 年以后。
P3：工程菌 MC-LR 生物传感器标定原始数据：标准浓度梯度、响应曲线、GFP/RFP/荧光或电信号、响应时间、温度/pH/盐度干扰、重复与批次。

搜索范围必须包括但不限于：国家科技资源共享服务平台、国家地球系统科学数据中心、国家青藏高原科学数据中心、中国科学数据、Science Data Bank、国家生态科学数据中心、湖泊与环境国家重点实验室/中科院水生所数据仓库、政府开放数据、高校机构库，以及 Zenodo、Figshare、Dryad、PANGAEA、DataONE、EPA/USGS/NOAA、Copernicus CDS、Google Dataset Search。对网页附件、补充材料、API、FTP、对象存储和仓库 release 逐项核查。

严格纳入规则：
1. 标签必须明确分析物：total MC、MC-LR 或其他异构体分别保存，禁止混写。
2. 水体 µg/L、组织 µg/g、细胞配额、SPATT 通量、qPCR 拷贝数必须分任务保存。
3. 不得把 Chla、藻蓝蛋白、CyAN 指数、风险等级或旧模型预测冒充毒素真值。
4. 必须保留原始未检出表示、LOD、LOQ、qualifier、方法和样品组分；不得把 ND 直接改为 0。
5. 不得伪造日期、坐标、单位或站点；只能由同一来源的站点表做可追溯连接。
6. 下载前以 DOI、文件哈希、标题、行数和关键列检查重复；与现有文件重复时只登记，不重复下载。
7. 优先公开许可、可复现、机器可读的原始 CSV/XLSX/NetCDF/GeoTIFF/Shapefile；仅有论文图或汇总均值时标记为“不可训练”。

每个数据集 README.md 必须用中文写明：正式标题、作者/机构、URL/DOI、许可、下载日期、文件清单与 SHA-256、时间/空间范围、样本量、每个字段和符号含义、量纲、分析物和样品组分、检测方法、LOD/LOQ、缺失/未检出编码、与现有数据的重复关系、适用任务、0–10 建模适用度及扣分原因。

下载结束后生成：
- model_redo/data/data_search_manifest.csv：一行一个候选/已下载数据集，含状态、拒绝原因、URL、DOI、许可、文件大小、哈希、目标类型、样本量、日期/坐标/水质完整率。
- model_redo/data/data_gap_coverage_report.md：按 P0–P3 报告新增有效记录数、仍未解决的缺口和下一步建议。
- 所有下载/解压/校验脚本保存在 model_redo/data/tmp_code；运行应可续传、幂等，并对压缩包做路径穿越与完整性检查。

“找到网页”不算完成；只有实际下载、校验、阅读字段、确认单位和目标定义、写完 README 与清单后才算完成。若数据受登录、申请、验证码或许可限制，不得绕过；记录准确入口、所需申请步骤、联系人和推荐申请文本。
```

## 给湿实验/传感器数据 Agent 的补充提示词

```text
重点搜寻公开的微囊藻毒素/MC-LR 工程菌或细胞生物传感器原始标定数据，而不是只搜论文。要求每条记录至少包含标准浓度、响应值、响应时间和重复编号；优先同时包含温度、pH、盐度/离子强度、其他毒素交叉反应、批次和空白对照。将 dose-response、interference、time-course、batch/QC 分成独立 CSV，统一浓度到 µg/L，但保留原始值和单位。若只有图，寻找补充表、论文仓库或联系作者的数据声明；禁止从低分辨率图像臆造数字。输出可直接用于层级剂量响应模型和传感器不确定度传播的字段字典、质量标志及推荐训练/验证切分。
```
