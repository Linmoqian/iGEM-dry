## 2. total MC 的能力

### 2.1 优点

- 动态表有 20,852 条记录、16 个来源、3,467 个有名称水体，时间覆盖 2007-05-08 至 2024-10-22。
- pH、TN、TP、浊度、Chla 等核心变量覆盖度较高。
- 约 54% 动态表记录为删失，足以研究检出过程和浓度分布，而不必只做“检出后回归”。
- 来源包含全国概率调查、单湖连续监测、河流与农塘等生态类型，可用于真正的来源外测试。

### 2.2 限制

- 20,750/20,852 条动态记录来自美国，102 条来自加拿大；不能据此直接证明中国迁移效果。
- 同日 LSWT 仅 1,219 条，湖泊面积/深度约 8,619 条，WorldCover 约 3,631 条；外部特征面板不可假定全覆盖。
- 很多站点只有一次观测，适合横截面泛化但不适合直接训练序列预测模型。
- 标签中位数约 0.075 µg/L、95 分位约 2.88 µg/L、最大值 743.75 µg/L，长尾明显；均方误差会被极端值主导。
- 来源检测方法、LOD、样品组分和采样设计不同，`dataset_id` 与方法差异可能形成伪规律。

判断：**可以支撑高质量 total MC 概率模型研究，不能单独支撑东湖本地结论。**

## 3. MC-LR 的能力

### 3.1 标签总量不等于有效动态样本量

`mc_lr_enriched_all.csv` 有 20,828 行，但主要来源结构为：

- WQP MC-LR：13,776 行，许多记录缺少同日水质；
- USGS Sacramento Delta：3,551 行；
- Uruguay Río de la Plata：2,404 行；
- EMLS：369 行；
- 其余来源规模较小。

动态可用表只有 2,837 行，其中 Uruguay 占 2,393 行（约 84%）。如果直接随机切分，这一来源会决定模型并产生虚假的稳定性。

### 3.2 删失选择偏差

- 静态可用 MC-LR 表 6,409 行，其中删失 3,417 行，占约 53%。
- 动态可用 MC-LR 表 2,837 行却全部是检出值。

因此，“在 dynamic-ready 上做普通回归”实际是在估计 `Y | detected, dynamic_features_available`，不是总体 `Y | X`。它会高估浓度、低估未检出概率，并且无法校准低风险区域。

### 3.3 质量问题

- `target_model_ug_l` 中有 12 个负值，均已标为 `negative_excluded`，训练时必须按质量标志隔离。
- 浓度最大值为 26,105.59 µg/L，必须回查单位、样品组分和方法；不能仅因数值大就删除，也不能未经核验进入损失函数。
- 现有动态 MC-LR 特征几乎没有 DOC、TOC、硝酸盐和 WorldCover；模型之间的比较必须使用相同可用特征白名单。
- 跨 30 个国家的表面覆盖主要由 EMLS 小样本提供，不能与“每个国家均有充分样本”混同。

判断：**可以支撑受约束的 MC-LR 删失模型、迁移学习和不确定度研究；不足以单靠一个动态表训练全球通用或东湖精准模型。**

## 4. 中国与太湖数据的正确使用

中国协变量表有非常大的样本量和良好的常规水质覆盖，但没有 toxin label。推荐用途：

1. 只在共同特征空间训练“训练域 vs 中国域”分类器，估计 OOD 和密度比。
2. 建立中国水质变量的插补器和缺失模式模型，但插补器必须在训练折内拟合。
3. 对 TabM/MLP 做掩码重建等无监督预训练，然后用有标签毒素数据微调；是否有效由消融实验决定。
4. 用太湖多模态数据设计未来滞后特征和遥感特征接口。
5. 评估训练数据在东湖候选输入范围上的覆盖度，指导主动采样。

禁止用途：把中国水质记录复制一个毒素值、用 Chla/TSI 替代 MC、按最近美国湖泊伪标注，或只做协变量对齐就宣称中国准确。

## 5. 数据利用策略

### 5.1 多面板而不是全量完整案例删除

为了充分利用数据，建立四个受控训练面板：

- `core_dynamic`：有标签且至少有预注册数量的现场动态变量；主生态模型。
- `static_context`：有标签、日期/地点和静态环境；估计背景风险和删失机制。
- `bloom_augmented`：在 core 上增加 Chla/蓝藻代理；只测增量价值。
- `label_only_prior`：缺少有效环境变量但标签和检测限可信；只估计来源/时间分层先验、尾部分布或校准，不训练部署预测器。

这样既不把所有稀疏行扔掉，也不会让“只有标签”的记录通过来源 ID 泄漏进入部署模型。

### 5.2 标签区间优先

- 训练数据保留 `lower_bound_ug_l` 与 `upper_bound_ug_l`。
- 精确值上下界相等；未检出上界为 LOD/LOQ；边界未知的 ND 只进入检出任务或敏感性分析。
- `target_model_ug_l` 的半限值表示可用于复现旧方案，但不作为默认真实浓度。

### 5.3 来源层次与采样权重

- 使用 `dataset_id → waterbody/site → time block` 的层次分组。
- 训练批次对来源做均衡采样，避免样本量最大的 WQP、NARS 或 Uruguay 完全支配梯度。
- 报告按记录加权和按来源宏平均两套结果。
- 同来源重复/近重复记录必须保持在同一外层折。

## 6. 决定架构的七项约束

1. **高删失率**：需要区间似然、hurdle 或 AFT/Tobit 类模型。
2. **标签长尾**：需要 log 分布、分位数或混合分布，而不是只优化原尺度 MSE。
3. **缺失模式结构化**：树模型和显式缺失掩码很重要。
4. **来源不均衡**：需要来源宏平均、worst-group 选择和 GroupDRO/加权敏感性。
5. **任务异构**：total MC 与 MC-LR 只能共享表示或先验，不能共享标签定义。
6. **中国无标签**：域适配主要用于 OOD、重加权和主动采样，不能替代本地验证。
7. **缺少密集序列**：当前优先表格模型；TFT/LSTM/时空 GNN 暂不进入主架构。

## 7. 训练前仍需冻结的事项

- 逐来源生成精确的 `lower/upper` 浓度边界和“边界未知”标志。
- 核验 MC-LR 极端值、12 个负值、样品矩阵和单位。
- 对所有同步 bloom proxy 标注真实部署时可用时间。
- 确认 `dataset_id`、方法和地理字段的用途：分组/校准/解释，而非默认预测变量。
- 为每个特征面板生成不可变白名单、单位、有效范围和缺失规则。
- 在任何模型调参前生成并冻结 outer split 清单和 locked test 哈希。
