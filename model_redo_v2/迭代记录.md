## 0. 当前基线与问题定义

当前基线为 stacking v2：XGBoost AFT、CatBoost quantile、TabM-inspired censored MiniEnsemble，经来源一致的 OOF 非负 stacking、CQR 和 Mahalanobis OOD 组成。

| 任务 | v2 test `log1p MAE` | Spearman | R² | 关键问题 |
|---|---:|---:|---:|---|
| total MC core / source OOD | 0.3488 | 0.3190 | -0.0107 | 99.3% OOD；高值严重低估 |
| MC-LR static / source OOD | 0.1318 | 0.0831 | -3.0590 | 只有 134 条精确测试标签；100% OOD；几乎无排序能力 |
| MC-LR core / waterbody OOD | 0.2972 | 0.5091 | -0.0045 | 少数极端值使 MAE 达 32.07 µg/L |

事后误差诊断进一步显示：

- total MC 测试 top 1%（19 条）真实浓度中位区域远高于模型预测，其 MAE 为 60.14 µg/L、`log1p MAE` 为 3.61；
- MC-LR core 的 7,700、3,700、3,291、2,066 µg/L 样本分别只预测约 0.94、0.59、10.42、14.32 µg/L；
- 这些 MC-LR 极端样本多数没有被特征 OOD 检出，说明主要问题是条件尾部/概念不足，而非单纯边缘特征距离；
- 在完整动态表精确标签中，Chla 与 total MC 的 Spearman 约 0.44，蓝藻细胞数与 MC-LR 的 Spearman 约 0.60；高值组的 Chla/蓝藻量显著更高。

## 1. 改进优先级判断

### 1.1 第一优先级：评价协议与数据表征

改进点：

1. 保留历史 test，不再根据它直接选择超参数；建立 repeated source/waterbody OOD 开发评价。
2. 将误差按来源、标签分位区间、删失状态和 OOD 分解，新增 tail 指标。
3. 将 `core_field` 与可部署的 `bloom_augmented` 分开建模，禁止用同步 bloom proxy 的提升冒充 core 模型提升。
4. 核验极端 MC-LR 的单位、样品矩阵、方法和重复关系；核验前不自动删除，也不把其主导的原尺度指标隐藏掉。

判断：当前瓶颈首先是域偏移、标签尾部和有效信号面板，不是 GPU 或网络容量。数据与评价的投入优先级高于更大的 Transformer。

### 1.2 第二优先级：尾部感知且删失一致的专家

计划改进点：

1. 增加 XGBoost quantile 专家，与 AFT 的固定分布尾部形成互补；
2. 研究三状态模型：未检出/普通浓度/高浓度，使用训练折定义尾阈值；
3. 高值专家只由训练折精确高值训练，以概率 gate 融合，避免全局抬高低浓度预测；
4. stacking 升级为带正则的 simplex 优化，并增加删失区间损失/尾部损失消融；
5. 对 AFT 分布与 scale 做内部折选择，不继续固定单一 normal-scale=1。

### 1.3 第三优先级：域稳健和迁移

计划改进点：

1. repeated source folds 下比较来源均衡、GroupDRO 和稳健最差组目标；
2. 使用中国无标签协变量训练域分类器和可解释 OOD，而不是生成伪标签；
3. total MC 预训练→MC-LR 微调仅作为消融，必须同时改善 MC-LR 平均和最差来源；
4. 有东湖标签后再做本地校准和 weighted/Mondrian conformal。

## 2. 迭代 I0：同步藻华面板诊断

### 方案

不修改模型，仅把面板从 `core_field` 改为 `bloom_augmented`，增加 `chlorophyll_a_ug_l` 与 `cyanobacteria_cells_ml`，保持原 v2 切分、三个专家、训练预算和 stacking 规则不变。目的不是直接替换 core，而是判断尾部识别是否缺少藻华状态信号。

### total MC 结果

服务器运行：`runs/total_mc_bloom_augmented_v2/`。

| 指标 | core v2 | bloom I0 | 变化 |
|---|---:|---:|---:|
| test `log1p MAE` | 0.3488 | 0.3549 | 退化 0.0061 |
| Spearman | 0.3190 | 0.3963 | 改善 0.0773 |
| factor-of-2 | 0.3811 | 0.3412 | 退化 |
| 区间距离 MAE (µg/L) | 0.5988 | 0.6015 | 近似持平、略退化 |
| 95% 高值组 Spearman | 0.2366 | 0.3630 | 明显改善 |
| OOD 比例 | 0.9930 | 1.0000 | 退化 |

stacking 权重由 `(XGB=0, Cat=0.8304, TabM=0.1696)` 变为 `(0, 0.6457, 0.3543)`。

### 反思

藻华代理提高了整体和高值组排序，但没有提高浓度幅度，说明新增特征包含尾部识别信号，而当前中位损失、删失中点 stacking 和全局专家组合没有把该信号转化成足够高的尾部预测。`bloom_augmented` 不应直接替代 core；下一轮应增加 tail-aware objective/gate，并对缺失模式引起的 OOD 上升进行处理。
