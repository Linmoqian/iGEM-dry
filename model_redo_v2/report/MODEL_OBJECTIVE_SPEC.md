# MC-LR / total microcystins 模型目标说明书

版本：v2.0-design  
冻结日期：2026-08-10  
适用目录：`model_redo_v2/`

## 1. 系统使命

构建一个可复现、可审计、可量化不确定性的微囊藻毒素风险模型，为无人机投放的工程菌检测节点和水体监测平台提供以下能力：

1. 根据采样时可获得的水质、时间、空间、气象、水文和遥感信息，估计水体中微囊藻毒素浓度的概率分布。
2. 分别输出 total microcystins 与 MC-LR 的结果，绝不把总 MC 当作 MC-LR 真值。
3. 给出检出概率、可配置阈值的超限概率、预测区间、模型域外程度和数据质量标志，而不只给单点数值。
4. 最终在武汉东湖完成本地校准，并与工程菌传感器的剂量—响应模型衔接。

“精准”在本项目中指经锁定外部测试、跨来源测试和东湖前瞻验证证明的性能；在取得东湖毒素真值之前，不允许宣称模型已经达到东湖精准预测。

## 2. 应用问题拆分

### 2.1 任务 A：total microcystins 当前状态估计（主训练骨干）

- 标签：明确标为 total microcystins 的水体浓度，统一为 µg/L。
- 目标：学习环境条件与总 MC 风险之间的广覆盖关系。
- 现有基础：约 2.1 万条可训练记录，来源和水质特征相对丰富。
- 用途：生态风险骨干、特征效应发现、迁移前训练；不能直接改名为 MC-LR 模型。

### 2.2 任务 B：MC-LR 当前状态估计（最终分析物任务）

- 标签：明确由来源标为 microcystin-LR 的水体浓度，统一为 µg/L。
- 目标：输出 MC-LR 的浓度分布和风险概率。
- 现有基础：标签总量较大，但环境特征稀疏、来源极不均衡；动态特征完整子集仅约 2,837 条。
- 用途：MC-LR 专属模型、total MC 迁移收益检验、未来东湖校准。

### 2.3 任务 C：毒素检出与阈值风险（辅助决策任务）

- 检出任务：预测潜在浓度是否高于来源对应检测限。
- 超限任务：从预测分布计算 `P(Y > τ | X)`；阈值 `τ` 由带版本的配置提供。
- 分类不能取代连续浓度任务；同一阈值在法规或使用场景变化时无需重新训练浓度模型。

### 2.4 任务 D：中国/东湖域适配

- 当前 42.5 万条中国水质记录和太湖多模态表没有合格毒素真值。
- 只能用于协变量分布估计、无监督表征、缺失模式建模、域外检测和密度比估计。
- 不得把 Chla、藻蓝蛋白、TSI、CyAN 指数或旧模型预测当作毒素标签。

### 2.5 任务 E：工程菌传感器标定（独立下游模块）

- 输入：标准 MC-LR 浓度、温度、pH、离子强度、干扰物、响应时间、批次和重复。
- 输出：传感器信号条件分布或由信号反演的 MC-LR 浓度分布。
- 环境模型与传感器模型分开训练，通过概率分布和不确定度传播连接，不能互相冒充真值。

## 3. 当前能力边界：估计不等于预报

现有大多数标签和水质特征来自同一次采样或同一天，因此第一版模型回答：

> “给定当前或已知时刻的环境观测，该时刻的毒素浓度与风险是多少？”

它属于 nowcast/状态估计。真正的 `t+h` 未来预报必须满足：所有特征的时间戳不晚于预测起点 `t`，并存在足够的站点连续序列。计划预报时距为 1、3、7 天，但只有下列数据补齐后才启用：

- 采样日前 1/3/7/14/30 天的降水、气温、风、辐射、湿度；
- 同期水位、流量和湖表温度；
- 历史毒素或可靠的在线传感器序列；
- 明确的发布时间与可用性，避免把未来信息混入特征。

## 4. 形式化标签表达

令潜在真实浓度为 `Y ≥ 0`，模型不把所有标签都强制转为单点：

- 精确检出值 `y`：观测区间 `[y, y]`；
- 未检出 `< LOD`：观测区间 `[0, LOD]`；
- 定量限以下 `< LOQ`：依据来源元数据保存相应上界；
- 区间报告：保存 `[L, U]`；
- 只有“ND”且没有任何限值：可用于检出分类；连续浓度似然中标为边界未知，不得擅自填 0；
- 负浓度或单位/矩阵不明：进入隔离表，不用于训练。

推荐在潜变量空间使用 `Z = log(Y + c)`，其中常数 `c` 只能由训练折的测量分辨率规则确定并写入配置。删失样本贡献区间概率，精确样本贡献密度；半检测限只作为敏感性对照，不作为默认真值。

## 5. 输入特征面板

模型必须显式选择面板，不能将 138 列全部自动输入。

| 面板 | 内容 | 部署含义 | 角色 |
|---|---|---|---|
| P0 `core_field` | 水温、DO、pH、浊度、电导率、TN、TP、氮形态、DOC/TSS、Secchi、水深、季节 | 常规现场或实验室水质 | 默认主模型 |
| P1 `bloom_proxy` | Chla、蓝藻密度、藻蓝蛋白、合法的历史遥感指标 | 同期藻华代理，可能很强但有可用性/泄漏风险 | 独立增量实验 |
| P2 `static_context` | 湖泊形态、流域、土地覆盖、常年气候、经纬度 | 只依赖地点的先验 | 静态基线与域适配 |
| P3 `lagged_dynamic` | 严格滞后的天气、水文、LSWT、遥感 | 真正未来预报所需 | 数据补齐后启用 |
| P4 `sensor` | 工程菌荧光/电信号、响应时间、批次、干扰条件 | 传感器标定 | 独立模块 |

禁止预测变量包括：`target_*`、`detected`、`is_censored`、LOD/LOQ/qualifier、由目标产生的风险等级、同一样本其他毒素之和、记录 ID、源行号以及任何在预测时不可获得的字段。`dataset_id` 和检测方法可用于分组、校准或随机效应分析，默认不作为部署特征。

## 6. 模型输出契约

每次预测至少返回：

| 字段 | 含义 |
|---|---|
| `target_kind` | `total_microcystins` 或 `mc_lr` |
| `prediction_time` / `horizon` | 状态估计时刻或预报时距 |
| `median_ug_l` | 中位浓度，µg/L |
| `q10_ug_l`, `q90_ug_l` | 80% 预测区间；另可提供 50/90/95% 区间 |
| `p_detected` | 相对指定测量限的检出概率 |
| `p_exceedance` | 对每个配置阈值的超限概率 |
| `ood_score` | 与训练域的距离/域外风险 |
| `feature_panel` | 实际使用的特征面板和缺失情况 |
| `model_version`, `data_version` | 可追溯版本 |

当关键输入超出训练范围、`ood_score` 过高或预测区间过宽时，应输出“建议采样/不可可靠判定”，而不是强行给出确定结论。

## 7. 评价矩阵

不能用单一 R² 选择模型。每个分析物、特征面板和外层切分都报告：

- 浓度点预测：log 空间 MAE/RMSE、原尺度 MAE/MedianAE、R²、Spearman、factor-of-2；
- 删失与概率预测：区间负对数似然、pinball loss、CRPS（可计算时）；
- 不确定度：50/80/90/95% 覆盖率、平均区间宽度、分来源覆盖率；
- 风险：PR-AUC、召回率、特异度、Brier score、ECE、阈值决策曲线；
- 极端事件：训练折定义的高浓度分位区间召回率和条件 MAE；
- 泛化：各来源宏平均、最差来源指标、未见湖泊、未来年份和跨国家表现；
- 工程指标：推理时间、内存、失败率、模型许可和可解释性。

## 8. 主要验收门槛

最终模型只有同时满足以下门槛才可进入部署候选：

1. 在预先锁定的来源、湖泊和时间外测试上稳定优于 Dummy、线性模型和强树模型基线；不能只在随机 IID 划分获胜。
2. 删失样本没有被删除，标签区间和检测方法审计通过。
3. 至少一个 90% 预测区间在总体和主要来源上的覆盖率达到预注册容差；覆盖率与宽度同时报告。
4. 高风险召回和最差来源性能没有因总体均值改善而显著恶化。
5. core-only 模型单独合格；加入 bloom proxy 的增益和部署可得性明确，不以同步代理掩盖基础模型能力。
6. 所有集成权重只由训练/验证折的折外预测学习，locked test 只使用一次。
7. 东湖模型必须经过本地带毒素真值的前瞻或时间后验验证；在此之前只能标记为“外域估计候选”。
8. 训练数据、代码、配置、随机种子、模型权重、指标和许可证均可追溯。

## 9. 明确不做的事

- 不用 total MC 标签直接训练并命名为 MC-LR 模型。
- 不把 ND 全部改为 0，也不删除未检出行来制造更高 R²。
- 不以随机拆分结果代表跨湖泊、跨国家或未来泛化。
- 不在稀疏横截面表上强行使用 LSTM/TFT/时空 GNN 并称为预测架构。
- 不承诺“完美模型”；本项目追求可证实、可校准、可拒绝不可靠输入的最佳模型。
