# iGEM Dry Lab — 蓝藻水华智能监测系统

构建无人机投放工程菌检测节点的闭环系统，实时监测与预警水体藻毒素风险。

## 项目结构

| 目录 | 说明 |
|------|------|
| `web/` | 前端 — Vite + React 18 + Tailwind CSS 4，浅色青蓝水体实验风 |
| `models/` | 数学建模 — 按新模块划分（占位，待迁移实现） |
| `docs/` | 项目文档、开发规范与会议记录 |

`models/` 规划中的四个模块：

1. `1.model_浓度标定` — 工程菌光信号至 MC-LR 浓度的标定模型
2. `2.model_风险评估` — 藻毒素风险评估
3. `3.model_平层热力` — 平层热力分析
4. `4.model_投放策略` — 无人机投放策略

## 快速启动

```bash
# 前端
cd web && npm install && npm run dev    # localhost:5173
```
