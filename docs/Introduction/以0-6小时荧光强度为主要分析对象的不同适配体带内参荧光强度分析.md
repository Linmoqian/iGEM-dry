# 以0\-6小时荧光强度为主要分析对象的不同适配体带内参荧光强度分析

# 内参 GFP/RFP 数据分析报告

## 公式选择

项目简介明确采用 sfGFP/TurboRFP 双色比例荧光进行定量。TurboRFP 是基因组整合的组成型内参，主要用于抵消菌量、表达背景、光路和读数波动；sfGFP 是 MC\-LR 触发后的工作监测信号。因此本轮分析不把 GFP 原始值作为主指标，而以 GFP/RFP 比值为基础。

记同一编号、同一 MCLR 浓度、同一时间、同一重复的读数为 `G(c,t,r)` 和 `R(c,t,r)`：

- 基础内参校正：`Q(c,t,r) = G(c,t,r) / R(c,t,r)`。

- 同时间背景校正：`DoseFold(c,t,r) = Q(c,t,r) / Q(0,t,r)`，用于去掉同一时间 0 ug/L 背景。

- 起点校正：`TimeFold(c,t,r) = Q(c,t,r) / Q(c,0,r)`，用于观察相同浓度随时间变化。

- 主响应指标：`DoubleNorm(c,t,r) = [Q(c,t,r) / Q(0,t,r)] / [Q(c,0,r) / Q(0,0,r)]`。

`DoubleNorm` 同时校正 0 ug/L 时间背景和 0h 起始孔位差异，适合作为当前这批 8 浓度、8 时间点、三重复数据的主比较指标。由于本项目面向实时预测和预警，评价顺序改为：前 6 小时为主要依据，9h 作为次要确认，24h 仅作为持久性参考；若 24h 强但 0\-6h 弱，不应作为优先候选。

## 数据概况

- 主实验包含 8 个编号（0\-7）、8 个 MCLR 浓度（0\-5 ug/L）、8 个时间点（0/2/3/4/5/6/9/24h）、每个编号 3 个重复。

- RFP 内参重复间 CV：中位数 3\.21%，95 分位 11\.56%。

## 缩写解释

|缩写|全称/含义|在本报告中的用途|
|---|---|---|
|RFU|Relative Fluorescence Unit，相对荧光单位|酶标仪输出的原始荧光强度单位|
|SD|Standard Deviation，标准差|衡量三重复之间的离散程度|
|CV|Coefficient of Variation，变异系数，通常为 SD/均值|衡量重复稳定性；RFP CV 越低，内参越稳定|
|AUC|Area Under the Curve，曲线下面积|衡量一段时间内响应的累积强度；本报告主看 0\-6h AUC|
|4PL|Four\-Parameter Logistic regression，四参数逻辑回归|常用于剂量响应曲线拟合，判断是否适合建立标准曲线|
|EC50|Half maximal effective concentration，半最大效应浓度|4PL 拟合参数，表示达到一半最大响应所需浓度|
|LOD|Limit of Detection，检测限|粗略表示能从空白背景中区分出来的最低浓度|
|DoubleNorm|Double\-normalized response，双归一化响应|本报告的主响应指标，同时校正 0 ug/L 背景和 0h 起点差异|

## 图像综合判断（预测导向）

综合时间曲线、热图、剂量响应、RFP CV 和 0\-6h AUC，本批数据建议按以下优先级推进：

1. 编号 1：0\-6h AUC 最高、趋势最平滑，最适合做稳健预测模型和标准曲线候选。

2. 编号 5：6h 单点响应最高，适合做快速报警候选；需要复测确认高浓度回落是否稳定存在。

3. 编号 4：1 ug/L 响应强且可延续到 24h，但早期 RFP CV 偏高；作为高潜力复测候选，而不是直接定稿。

4. 编号 0、2、6：早期响应弱到中等，可暂列观察组。

5. 编号 3、7：不建议作为本轮主要候选。

## 4PL 拟合参考（6h 主窗口，排除 0 ug/L）

预测场景下，4PL 不再以 24h 为主，而优先检查 6h 能否形成可拟合的剂量响应。9h/24h 只用于判断同一编号的剂量趋势是否延续。注意：当前每个浓度只有三重复，且多个编号存在非单调响应，因此 4PL 仅作为探索性参考。

从拟合角度看，编号 1 在 6h 的 R2 最高，并且 9h/24h 也保持较好拟合，是标准曲线优先候选。编号 5 和编号 4 虽然早期响应强，但 6h 剂量曲线 R2 较低，更适合作为阈值报警或复测候选，而不是直接作为定量标准曲线。

## LOD 粗估

这里用空白比值均值 \+ 3SD 作为粗略阈值，寻找首个超过阈值的 MCLR 浓度。预测场景下优先看 6h，其次 9h，24h 仅作补充。由于每组只有三重复，且部分响应非单调，该 LOD 只能作为探索性参考，正式申报应增加重复并结合 4PL 标准曲线。

## 注意事项

- `DoubleNorm` 的 0 ug/L 理论上固定为 1，因此它适合做响应比较，不适合直接用自身估计空白 SD；LOD 仍基于原始 `Q = GFP/RFP` 计算。

- 当前数据没有 1h 时间点，预测窗口实际由 0/2/3/4/5/6h 构成；后续若要做更可靠的早期预测，建议增加 0\.5h 和 1h。

- 24h 与早期时间跨度较大，本轮不再用 24h 作为主排序依据，只用于判断响应是否持久。

- 如果后续要做正式标准曲线，建议增加 10 ug/L 浓度点并增加生物重复，再用 4PL 报告 EC50、动态范围和 LOD/LOQ。
