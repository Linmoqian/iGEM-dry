# pmcy-GFP 响应 MCLR 的统计分析报告

## 1. 实验目的

本实验将 GFP 连接在微囊藻毒素合成相关启动子 **pmcy** 后方，考察不同 MCLR 浓度处理后 GFP 荧光信号是否发生可检测变化，从而评估该体系作为 MCLR 生物检测方案的可行性。

实验设置：

- 启动子：pmcy
- 报告基因：GFP
- MCLR 浓度：0、0.05、0.1、0.25、0.5、1、2、5 μg/L
- 时间点：0h、1h、2h、3h、4h、5h、6h、12h
- 每个浓度重复数：3 个技术重复
- 主要分析指标：`ΔGFP = 当前时间点 GFP - 同浓度同重复 0h GFP`

## 2. 数据处理方法

原始酶标仪图片已整理为 Excel 表格，并按时间点、MCLR 浓度和重复编号转成长表格式。由于 0h 各浓度的初始 GFP 读数存在差异，直接比较原始 GFP 容易受到初始状态影响，因此本报告将 **0h 校正后的 ΔGFP** 作为主要响应指标。

分析中保留了原始 GFP，用于辅助判断整体荧光变化趋势；但可行性结论主要基于 ΔGFP。

## 3. 统计学方法

由于同一组样品在多个时间点连续读数，理想情况下应使用：

```text
线性混合效应模型：
ΔGFP ~ MCLR浓度 × 时间 + 随机效应(重复/孔位)
```

在当前分析中，先采用以下方法进行初步判断：

- 双因素 ANOVA：检验 MCLR 浓度、时间、浓度×时间交互对 ΔGFP 的影响
- 各时间点 one-way ANOVA：判断每个时间点不同浓度之间是否存在差异
- Welch t 检验：每个时间点各浓度与 0 μg/L 对照比较
- BH 校正：控制同一时间点内多重比较的假阳性
- 剂量趋势分析：用 `log10(MCLR + 0.01)` 拟合浓度趋势

需要注意：当前每组只有 3 个技术重复，缺少独立生物学重复，因此统计结果应作为初步证据，而不是最终定量结论。

## 4. 主要统计结果

### 4.1 双因素 ANOVA

以 ΔGFP 为响应变量时：

| 来源 | F 值 | P 值 | 结论 |
|---|---:|---:|---|
| MCLR 浓度 | 7.689 | 1.43e-7 | 显著 |
| 时间 | 111.636 | < 1e-12 | 显著 |
| MCLR 浓度 × 时间 | 2.133 | 8.61e-4 | 显著 |

说明 pmcy-GFP 的响应不仅随时间变化，也受到 MCLR 浓度影响；同时，浓度效应会随时间点改变。

### 4.2 各时间点浓度差异

| 时间点 | one-way ANOVA P 值 | 结论 |
|---|---:|---|
| 1h | 0.071 | 不显著 |
| 2h | 0.651 | 不显著 |
| 3h | 0.999 | 不显著 |
| 4h | 0.00165 | 显著 |
| 5h | 0.000321 | 显著 |
| 6h | 0.00108 | 显著 |
| 12h | 0.00496 | 显著 |

结果显示，MCLR 处理带来的组间差异主要从 **4h 之后** 开始出现，5h、6h 和 12h 最明显。

## 5. 图像解读

### Figure 1. pmcy-GFP 的 0h 校正响应

![Fig1](figures_pmcy_GFP/Fig1_pmcy_GFP_delta_response.png)

#### 图 1a：时间响应曲线

图 1a 展示不同 MCLR 浓度下 ΔGFP 随时间变化的趋势。每个点为均值，误差线为 SEM，n=3。

主要观察：

- 1h 时各组普遍低于 0h 基线，说明早期读数可能受到适应期或测量波动影响。
- 2h、3h 时不同浓度之间差异不明显。
- 4h 之后不同浓度曲线开始分开。
- 0 μg/L 对照在 5h、6h、12h 出现明显 GFP 上升。
- 多数 MCLR 处理组在后期也有上升，但相对 0 μg/L 对照更低。

因此，当前数据更支持 **MCLR 改变了 pmcy-GFP 的时间动态**，而不是简单地诱导 GFP 随浓度升高而增强。

#### 图 1b：12h 终点剂量响应

图 1b 显示 12h 时各 MCLR 浓度的 ΔGFP 分布。散点表示 3 个重复，黑线和误差线表示均值 ± SEM。

主要观察：

- 0 μg/L 对照的 ΔGFP 最高。
- MCLR 处理组整体低于 0 μg/L 对照。
- 不同 MCLR 浓度之间没有形成清晰、单调的剂量递增或剂量递减曲线。
- 5 μg/L 组并没有表现为最强响应。

这说明 12h 虽然能区分处理组和对照，但目前还不能支持稳定的 MCLR 浓度定量检测。

#### 图 1c：各浓度相对 0 μg/L 对照的显著性热图

图 1c 显示每个时间点、每个非零 MCLR 浓度相对 0 μg/L 对照的显著性。颜色为 `-log10(BH校正q值)`，星号表示校正后显著。

主要观察：

- 5h、6h、12h 出现较多显著差异。
- 6h 时 0.1、0.25、0.5 μg/L 与对照差异较强。
- 12h 时多个浓度与对照显著不同。
- 这些显著差异的方向主要是 **处理组低于 0 μg/L 对照**。

因此，图 1c 的显著性不能解释为 “MCLR 诱导 pmcy-GFP 增强”，更准确的说法是 “MCLR 处理改变或削弱了后期 GFP 增长”。

![FigS1](figures_pmcy_GFP/FigS1_pmcy_GFP_heatmaps.png)

#### 图 S1a：0h 校正后的 ΔGFP 热图

图 S1a 展示每个 MCLR 浓度和时间点的平均 ΔGFP。

主要观察：

- 1h 多数组为负值，提示早期信号相对 0h 下降。
- 3h 附近多数处理组略有恢复。
- 6h 和 12h 大多数组为正值，说明整体 GFP 随时间增加。
- 0 μg/L 对照在 6h 和 12h 的 ΔGFP 最大。

这张图说明响应具有明显时间依赖性，但浓度梯度并不呈现理想的连续变化。

图 S1b 展示未经 0h 校正的原始 GFP 均值。

主要观察：

- 原始 GFP 在不同浓度的 0h 就存在差异。
- 后期原始 GFP 整体升高，尤其 0 μg/L 对照明显升高。
- 如果只看原始 GFP，容易把初始差异和时间增长误判为 MCLR 响应。

因此，本实验更适合使用 ΔGFP 或 GFP/OD 归一化值，而不是直接使用原始 GFP。

## 6. 对 pmcy-GFP 检测 MCLR 可行性的判断

### 6.1 有利证据

当前数据支持 pmcy-GFP 对 MCLR 处理具有一定响应：

- 浓度主效应显著。
- 时间主效应显著。
- 浓度×时间交互显著。
- 4h 之后不同浓度组之间出现统计学差异。
- 5h、6h、12h 多个处理组与 0 μg/L 对照显著不同。

这些结果说明该体系不是完全无响应，具备进一步优化的价值。

### 6.2 主要问题

但作为 MCLR 检测方案，目前存在几个关键问题：

1. 响应方向与预期不完全一致  
   如果预期 MCLR 激活 pmcy 并增强 GFP，那么当前数据并不支持这一点。后期显著差异主要表现为处理组低于 0 μg/L 对照。

2. 缺乏清晰剂量依赖关系  
   不同 MCLR 浓度之间没有形成稳定单调曲线，因此难以建立标准曲线。

3. 0 μg/L 对照后期 GFP 增长过强  
   对照组自身变化过大，会降低处理组相对响应的可解释性。

4. 当前重复数有限  
   每组为 3 个技术重复，尚不能替代独立生物学重复。

5. 尚未进行 OD 或细胞量归一化  
   GFP 读数可能受到细胞密度、生长状态、背景荧光和孔位效应影响。

### 6.3 总体结论

综合判断：

```text
pmcy-GFP 对 MCLR 处理有响应迹象；
但当前响应不具备理想的单调剂量关系，
也不表现为明确的 MCLR 诱导型 GFP 增强。
因此，该方案目前适合作为候选响应系统继续优化，
但暂不适合作为成熟的 MCLR 定量检测体系。
```

更稳妥的表述是：

> The pmcy-GFP reporter showed a time-dependent response to MCLR exposure, but the current dataset does not yet support a robust monotonic dose-response suitable for quantitative MCLR detection.

## 7. 后续优化建议

### 7.1 实验设计优化

- 增加独立生物学重复，建议至少 3 批独立培养。
- 每个浓度保留 3 个技术重复。
- 加入空白孔，用于扣除培养基和板背景。
- 同步测 OD600 或细胞密度，用 `GFP/OD600` 作为主指标。
- 保留 0h 读数，用于计算 ΔGFP 或 fold change。

### 7.2 浓度和时间优化

建议下一轮浓度梯度：

```text
0, 0.01, 0.05, 0.1, 0.5, 1, 5, 10 μg/L
```

建议重点采样时间：

```text
4h, 5h, 6h, 8h, 12h
```

当前数据提示 5h、6h、12h 是较有信息量的窗口，但 12h 可能受到细胞生长状态影响，建议增加 8h 作为中间点。

### 7.3 统计分析优化

后续建议使用：

- 混合效应模型：处理重复孔位和时间依赖
- Dunnett 检验：每个浓度与 0 μg/L 对照比较
- 4PL 或线性区间拟合：评估是否能建立标准曲线
- LOD/LOQ 计算：评估检测限和定量限
- 残差分析：判断模型是否适合用于浓度预测
