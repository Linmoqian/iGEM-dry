# IGEM项目简介

## **超级mini版**

该项目面向蓝藻水华引发的微囊藻毒素 MC\-LR 污染问题，构建“实时监测—预警—精准降解”的智能治理系统。项目利用工程化大肠杆菌作为检测菌，通过 START 核糖开关识别 MC\-LR，再借助 LuxI/LuxR 群体感应回路放大信号，并用 sfGFP/TurboRFP 双荧光比值实现定量检测。当毒素浓度接近 1 μg/L 预警阈值时，漂浮式装置将信号传至中控系统，由无人机投放降解菌。降解菌携带 mlr 酶基因簇，可将 MC\-LR 分解为低毒或无毒产物。系统还设计了滤膜隔离、DAP 营养缺陷和 YF1\-FixJ 光控自杀模块，降低工程菌泄漏风险，实现安全、自动化的水体毒素治理。

# 微藻毒素智能生物监测降解系统

## 一、项目背景与意义



### 1\.1 问题根源：水体富营养化与蓝藻水华



随着全球气候变暖与人类活动加剧，大量富含氮、磷的生活污水和工农业废水排入水体，导致湖泊、水库等水体的**富营养化**问题日益严重，由此引发的**蓝藻水华**现象日趋严重。蓝藻水华不仅散发难闻气味、导致水生生物死亡、破坏水生生态系统，还因藻细胞产生并释放多种**藻毒素**而对人和动物安全构成严重威胁。



### 1\.2 核心威胁：微囊藻毒素（MCs）



在蓝藻水华产生的多种藻毒素中，**微囊藻毒素（Microcystins, MCs）** 是检出率最高、产生量最大、危害最严重的一类。



- **化学结构：** MCs是一类环状七肽化合物，通式为 cyclo\-\(D\-Ala\-L\-X\-D\-MeAsp\-L\-Z\-Adda\-D\-Glu\-Mdha\)，X和Z为两个可变的L\-氨基酸。MC\-LR中X=亮氨酸\(Leucine\)、Z=精氨酸\(Arginine\)，核心致毒基团为 **Adda**。

- **化学稳定性：** 环状结构使其极难被物理、化学和生物降解，自然水体中半衰期可达数周甚至数月。

- **致毒机理：** 特异性抑制细胞内的蛋白磷酸酶PP1和PP2A的活性，导致细胞内蛋白质过度磷酸化，进而破坏细胞信号转导、骨架结构和代谢平衡。

- **典型代表：** 目前已发现90多种MCs异构体，其中 **MC\-LR** 是产生量最大、分布最广泛、毒性最强烈的典型代表，是水体毒素污染防控的首要靶标。

    

### 1\.3 危害链



形成"**富营养化 → 水华 → 毒素释放 → 生物多样性下降 → 自净能力减弱 → 富营养化加剧**"的恶性循环。



**对农业的威胁：**

- 抑制萌发：水稻、番茄等作物种子萌发受抑，主根伸长受阻

- 光合破坏：叶绿素含量骤降，光合系统II活性受损

- 氧化应激：导致膜脂过氧化，细胞死亡

- 食品安全风险：毒素累积，通过膳食进入人体

    

**对人体的毒性：**

- 强效肝毒性：急性肝炎，强力促进肝癌

- 多器官损伤：肾毒性、神经毒性、生殖与发育毒性

- 免疫抑制：降低机体抵抗力，具有跨代遗传效应

- 肠毒性：破坏肠道屏障，与结直肠癌发病率升高相关

    

**WHO标准：** 饮用水和休闲用水中MC\-LR浓度不得高于 **1 μg/L**。



### 1\.4 当前技术瓶颈



1. **难以实现快速、高效的实时监测：** 传统检测方法（HPLC、LC\-MS/MS、ELISA）虽灵敏准确，但设备昂贵、操作复杂、分析耗时长，无法满足突发性藻华事件的现场快速预警需求。

2. **缺乏高效、彻底的降解手段：** 传统物理化学方法易产生二次污染且难以将毒素完全降解；天然微生物降解效率低、不稳定。

    

### 1\.5 项目目标



构建一套\*\*"监测预警 \+ 精准降解"\*\*两级联动的微囊藻毒素治理方案：以合成生物学手段设计全细胞生物传感器，搭载于漂浮式检测装置中实时监测水体MC\-LR；一旦检出毒素接近WHO阈值（1 μg/L），通过无人机投放降解菌，实现快速响应与精准治理。

## 二、系统总体架构



本系统由两个独立菌株协同工作，形成"检测→预警→投放→降解→回收"闭环：



```Plain Text
┌─────────────────────────────────┐      ┌─────────────────────────────┐
│       检测系统（本项目核心）      │      │        降解执行系统           │
│                                 │      │                             │
│  检测菌 + 漂浮检测装置           │ ──→  │  无人机投放降解菌            │
│  （浮于水面，定时采样）           │ 预警 │  （精准投放，高效降解）        │
│                                 │      │                             │
│  · START双质粒核糖开关感应       │      │  · mlr酶基因簇              │
│  · LuxI/LuxR群体感应放大        │      │  · Adda转氨酶基因           │
│  · sfGFP/TurboRFP比例荧光       │      │  · YF1-FixJ光控自杀模块      │
│  · YF1-FixJ光控自杀模块         │      │                             │
└─────────────────────────────────┘      └─────────────────────────────┘
```



**工作流程：**



1. **定时采样** — 漂浮检测装置定时抽取水样进入反应舱，检测菌在舱内接触水体（滤膜防泄漏）

2. **毒素感应** — MC\-LR激活START核糖开关，启动初级信号

3. **信号放大** — LuxI/LuxR群体感应正反馈回路将初级信号指数级放大

4. **荧光报警** — sfGFP/turboRFP比例荧光超过阈值，装置发出检测信号

5. **无人机投放降解菌** — 中控系统接收信号，无人机飞抵目标水域投放降解菌

6. **精准降解** — 降解菌将MC\-LR降解为无毒产物，完成后自杀清除

7. **无人机回收与替换** — 检测装置菌液耗尽后，无人机回收旧装置并投放新装置

## 三、检测菌——基因线路设计（本项目核心）



检测菌为大肠杆菌（E\. coli）底盘细胞（DAP营养缺陷型），搭载**START核糖开关双质粒感应模块**、**LuxI/LuxR群体感应信号放大与双荧光定量检测模块**和**YF1\-FixJ光控自杀安全模块**。



### 3\.1 靶标感应模块部分验证——START人工核糖开关双质粒响应系统



本研究以大肠杆菌为工程底盘，构建**双质粒核糖开关系统**实现MC\-LR特异性识别。



**质粒一：触发RNA质粒（pACYC104骨架）**



利用组成型启动子 **P104** 持续转录 **Apta\-trigger RNA**，该RNA两端为trigger序列，中间整合MC\-LR特异性适配体。Apta\-trigger RNA在无MC\-LR时处于游离态，等待靶标结合。



**质粒二：开关质粒（pColADuet2载体）**



由 **T7启动子** 调控 **Toehold Switch** 元件，下游串联 **luxI** 基因。无MC\-LR存在时，Toehold开关形成发夹结构遮蔽RBS，核糖体无法结合，阻断sfGFP蛋白翻译。



**工作机理：**



- **无MC\-LR时：** Toehold开关维持发夹构象，RBS被封闭，sfGFP基因沉默。

- **有MC\-LR时：** 毒素与适配体特异性结合 → Apta\-trigger RNA形成稳定二级结构 → 两端trigger序列与开关RNA互补结合（Toehold链置换反应） → 开关构象改变，RBS释放 → 核糖体顺利启动luxI基因表达，完成靶标信号初步感应。

    

**设计优化：** 利用NUPACK等核酸热力学软件，精确模拟trigger序列构型对自由能景观的影响，筛选毒素结合前后能量差值最大的最优序列。该平台实验室验证的最大感应倍数可达**67倍以上**。



### 3\.2 信号放大与双荧光定量检测模块——Lux群体感应回路



环境样本中MC\-LR浓度往往处于极低水平，单一初级传感器难以产生足够强的信号。因此接入**LuxI/LuxR群体感应（Quorum Sensing）正反馈放大回路**，将微弱的初级输入转化为指数式的次级信号输出，并通过双色比例荧光实现精确定量。



#### 3\.2\.1 内参荧光标定



将 **TurboRFP红色荧光蛋白基因****插入**至与sfGFP同一个质粒，依靠组成型启动子持续稳定表达红色荧光。避免了质粒拷贝数波动的影响，作为实验校正内参，可消除菌体浓度、表达差异、激发光强度等系统误差。



#### 3\.2\.2 群体感应放大机制



1. 体系中由 **P104组成型启动子** 持续表达 **LuxR** 蛋白。

2. 感应模块诱导产生的 **LuxI** 蛋白催化合成 **AHL**（酰基高丝氨酸内酯）群体感应信号分子。

3. AHL在菌群内扩散富集，达到阈值浓度后与LuxR结合形成 **LuxR\-AHL复合物**。

4. 该复合物强效激活 **Plux启动子**。

    

#### 3\.2\.3 定量检测原理



被激活的Plux启动子驱动 **sfGFP绿色荧光蛋白** 高效表达，输出靶标特异性荧光信号；同时Plux再次促进 **luxI** 表达，形成**自我维持的正反馈闭环**，实现绿色荧光信号指数级放大。



系统呈现"开关"式响应特性——一旦MC\-LR浓度超过预设阈值（1 μg/L），荧光信号呈指数级增长，特别适合作为环境毒素的早期预警系统。



#### 3\.2\.4 浓度量化逻辑



通过检测菌体 **sfGFP特异性绿色荧光** 与 **TurboRFP组成型红色荧光** 的荧光强度比值（sfGFP/turboRFP），即可精准校正误差，实现对微囊藻毒素MC\-LR浓度的定量分析。该比例校准策略自动抵消细胞体积差异和表达水平波动，显著改善实验数据重复性。



### 3\.3 生物安全模块——YF1\-FixJ光控自杀开关（DAP营养缺陷型底盘）



实验选用 **DAP营养缺陷型大肠杆菌菌株**（缺失DAP合成关键基因），构建**光控可控灭活系统**，从根本上杜绝基因工程菌扩散定植、基因漂移等生物安全隐患。



**核心机制：**



|环境条件|YF1状态|FixJ状态|PfixK2启动子|DAP合成|菌株命运|
|---|---|---|---|---|---|
|黑暗（装置内部）|激活|磷酸化|激活|开启|正常存活|
|蓝光/自然光（外界）|失活|无法磷酸化|关闭|关闭|凋亡|



**装置内（黑暗环境）：** YF1蛋白处于激活状态，介导FixJ蛋白磷酸化 → 磷酸化FixJ结合luxbox序列激活 **PfixK2启动子** → 启动DAP合成基因表达，供给菌株生长必需营养，保障检测体系正常工作。



**自然外界环境（含蓝光）：** 自然环境普遍存在自然光与蓝光 → 蓝光直接诱导YF1蛋白失活 → 无法介导FixJ磷酸化 → PfixK2启动子无法激活 → DAP合成通路彻底关闭 → 大肠杆菌缺失必需营养，无法正常增殖存活，发生**自主凋亡**。



**设计优势：** 该设计无需人工干预，工程菌一旦泄露至自然环境，依靠环境固有蓝光即可触发自杀程序，环境适配性与安全性极强。相比于化学诱导自杀系统，光控开关无化学试剂残留风险，且响应速度更快。

## 四、降解菌——无人机投放执行



使用市面上成熟的降解菌为工程菌，搭载**降解模块**与**安全模块**：



- **mlr酶基因簇（mlrA/B/C/D） \+ Adda转氨酶基因：** 将MC\-LR毒素逐步降解为无毒产物。

- 仅在检测系统发出预警后，由无人机携带并精准投放到污染水域。

- 降解完成后同样通过YF1\-FixJ光控自杀机制自我清除。

## 五、检测装置设计



检测装置为**漂浮式**结构，浮于水面，内部包含密封的**反应舱**，检测菌在反应舱内培养。核心设计要点：



- **定时抽水采样：** 装置定时从水体中抽取水样注入反应舱，使检测菌与水体充分接触。

- **滤膜物理隔离：** 反应舱出水口设有**滤膜**，允许水和小分子物质通过，但工程菌无法穿透，从物理层面杜绝泄漏。

- **荧光检测窗口：** 反应舱透明，内置微型荧光检测模块，实时读取sfGFP/turboRFP比值信号。

- **多点组网：** 根据水域面积布设多个检测装置，形成监测网络，实现大面积水域实时覆盖。

- **无人机回收与替换：** 装置内菌液耗尽后，由无人机回收旧装置并投放新装置，实现无人化轮换值守。

## 七、创新点



1. **START双质粒核糖开关感应：** 触发RNA质粒（pACYC104）与开关质粒（pColADuet2）双组件协同，通过Toehold链置换反应实现MC\-LR特异性识别，模块化设计可灵活更换适配体以识别不同靶标，实验室验证最大感应倍数达67倍以上。

2. **群体感应指数放大：** LuxI/LuxR正反馈回路将微弱毒素信号转化为"开关"式指数荧光响应，Plux启动子同时驱动sfGFP和luxI，形成自我维持的正反馈闭环，实现超灵敏检测。

3. **整合内参 \+ 比例荧光校准：** TurboRFP消除拷贝数波动；sfGFP/TurboRFP双色比值法自动校正系统误差，确保复杂水质

4. 中的定量准确性。

4. **"监测\-降解"两级联动：** 检测菌 \+ 降解菌双菌分工，配合漂浮装置 \+ 无人机投放回收，形成全链条无人化闭环。

5. **YF1\-FixJ光控自杀安全保障：** DAP营养缺陷型底盘 \+ 蓝光响应YF1\-FixJ自杀开关，工程菌一旦泄露至自然环境，依靠环境固有蓝光即可触发自杀程序，无需人工干预，从根本上杜绝基因漂移风险。
