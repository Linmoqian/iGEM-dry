# trigger4/5/6/7 响应 MCLR 的统计分析报告

## 1. 实验与数据结构

本次数据来自 `tig4567` 文件夹中的 9 张酶标仪截图，时间点为 0h、1h、2h、3h、4h、5h、6h、12h、24h。孔板列映射为：1-3 列 trigger4，4-6 列 trigger5，7-9 列 trigger6，10-12 列 trigger7。行 A-H 的 MCLR 浓度沿用前一批实验：0、0.05、0.1、0.25、0.5、1、2、5 μg/L。每个 trigger 在每个浓度下有 3 个技术重复。

主要分析指标为 `Δsignal = 当前时间点读数 - 同 trigger、同浓度、同重复的 0h 读数`。这样可以减少不同 trigger 和不同孔位初始读数差异造成的影响。

## 2. 统计学方法

每个 trigger 分别进行统计分析：双因素 ANOVA 检验 MCLR 浓度、时间和浓度×时间交互；每个时间点进行 one-way ANOVA；各浓度与 0 μg/L 对照进行 Welch t 检验，并在同一 trigger、同一时间点内做 BH 多重比较校正。由于目前是技术重复，结果应作为初筛证据，后续需要生物学重复复核。

## 3. 主要统计结果

### 3.1 双因素 ANOVA

| trigger | MCLR P | time P | MCLR×time P |
|---|---:|---:|---:|
| trigger4 | 0.0891 | 0 | 0.427 |
| trigger5 | 0.0102 | 0 | 1.22e-09 |
| trigger6 | 6.78e-08 | 0 | 0.000381 |
| trigger7 | 0.659 | 5.57e-06 | 8.99e-06 |

解释：若 MCLR×time 显著，说明该 trigger 对 MCLR 的响应不是固定不变的，而是随时间窗口改变。

### 3.2 24h 响应概览

|---|---:|---:|---:|
| trigger4 | 0.998 | 2.205 | 0.538 |
| trigger5 | 0.030 | 1.300 | -0.257 |

## 5. 可行性判断

综合这批数据，trigger6 是信号幅度最强的候选元件，但存在明显异常点和非单调剂量响应，暂时更适合称为“强响应候选”，不宜直接作为定量检测模块。trigger4 和 trigger5 的信号幅度较低，但曲线相对温和，可能更适合作为后续优化对象。trigger7 的背景较低，但稳定性和异常点问题较明显。

当前最重要的下一步不是只看显著性，而是确认三个问题：第一，是否能用 GFP/OD600 或扣背景后改善剂量关系；第二，异常 A 行是否来自孔位、气泡、边缘效应或截图/录入问题；第三，加入生物学重复后响应是否仍然存在。

## 6. 建议

- 优先复核 trigger6 和 trigger7 的 A 行异常读数，尤其 4h、5h、6h、12h、24h。

- 下一轮实验同步测 OD600，使用 `signal/OD600` 和 `Δ(signal/OD600)` 作为主指标。

- 每个 trigger 至少做 3 批独立生物学重复。

- 若目标是定量检测 MCLR，应重点评估 4PL/线性区间拟合、LOD、LOQ 和重复间 CV，而不是只看 ANOVA 显著性。
