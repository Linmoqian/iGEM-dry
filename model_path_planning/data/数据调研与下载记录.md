# 路径规划模型可用数据集调研与下载记录

> **课题**: 无人机应急投放降解菌 —— 任务级路径规划模型（MD-MUAV-VRPTWP）
> **下载位置**: `model_path_planning/data/raw/`（均已下载并核对；受限项见"下载情况"列）
> **调研日期**: 2026 年 7 月

---

## 0. 数据需求分析（先讲清楚"要什么数据"）

本模型需要四类数据：

| 数据类别 | 用途 | 关键字段 |
|---|---|---|
| **A. 任务点几何/路由基准** | 训练与评估路径规划模型的**实例配方**（坐标、需求、时间窗、车场） | 节点坐标、需求量、时间窗、车辆容量/数量、车场坐标、最优解(基准) |
| **B. 真实场景环境**（东湖） | 把"欧氏空间"升级为"真实水域/风场/停机坪" | 湖面多边形、岸边停机坪坐标、风场时间序列 |
| **C. 风险/警报演化** | 任务点优先级、时间窗来源 | 上游 MC-LR 浓度预测、警报时序 |
| **D. 无人机物理参数** | 能量/速度/载荷约束 | 速度-能耗曲线、最大载荷、续航 |

>A = 公开基准可直接复用；B/C/D 需要**公开数据 + 自建仿真**组合（下文逐项说明）。

## 1. 路由基准类数据集（A 类）

### 1.1 Solomon VRPTW 标准实例（本课题"时间窗"类问题最经典基准）—— ✅ 已下载

- **来源/链接**: https://github.com/CervEdin/solomon-vrptw-benchmarks （官方实例的 JSON/文本转换，源自 SINTEF / M. Solomon 1987 原始集）
- **官方出处**: Solomon Problem Set（clustered / random / random-clustered，各含 100 客户版本）
- **包含内容**: `c/` `r/` `rc/` 三组 × 1(100客户)/2(200客户)；每个实例含：客户坐标、需求量、**服务时间窗**（ready time / due date）、车辆容量、车辆数；附 `results/` 已知最优结果与获取脚本。
- **适配程度**: ★★★★★（高）。时间窗正是"**风险点有效投放窗口**"的抽象；容量对应"无人机载荷"；客户数 100 与东湖预警点规模匹配；JSON 格式可直接读取。
- **下载情况**: ✅ `solomon-vrptw-benchmarks.zip` (232 KB) 已下载并解压；已抽样核对 c101 内容无误。

### 1.2 PyVRP Instances —— 多车场/异构/时间窗/容量全家桶 —— ✅ 已下载

- **来源/链接**: https://github.com/PyVRP/Instances （PyVRP 官方实例库，含 best-known 解）
- **包含内容**: CVRP（含 XXL 大实例）、**MDVRPTW（多车场带时间窗）**、**HFVRP（异构车队）**、VRPTW（GH 系列）、PDPTW、SDVRPTW、TSP（TSPLIB 钻孔/城市集）等，全部为 TSPLIB 风格 `.vrp` / `.sol`（坐标 + 需求 + 时间窗 + 最优解）。
- **适配程度**: ★★★★★（高）。**MDVRPTW ⇔ 多停机坪多无人机带时间窗**，**HFVRP ⇔ 异构无人机队**，与我们问题结构完全同构，且带最优解可做"离线黄金基准（golden benchmark）"。
- **下载情况**: ✅ `PyVRP-Instances.zip` (15.2 MB) 已下载并解压（`Instances-main/`）；已核对 VRPTW/MDVRPTW/HFVRP/TSP 子目录与文件首行格式。

### 1.3 CVRPLIB（Uchoa et al. X-实例 / A-E-P 集）—— 下载受阻（已说明）

- **来源/链接**: http://vrp.atd-lab.inf.puc-rio.br/index.php/en/ （PUC-Rio CVRPLIB 官方库，含 X 系列 100 实例 BKS）
- **包含内容**: 大规模 CVRP 实例（100-1000 客户），坐标 + 需求 + 容量 + 已知最优解。
- **适配程度**: ★★★★（较高）。容量约束评估；但无时间窗、无多车场。
- **下载情况**: ⚠️ 直接下载 3 个实例（X-n101-k25 等）均返回 **502**（该站点经当前网络代理不可达）；**替代方案已落地**：PyVRP/Instances 中的 CVRP 子目录覆盖同类数据（含 X 系列多数字实例），实测可用，因此不阻塞。

### 1.4 TSPLIB95（经典 TSP 公共库）—— 下载受阻（已说明）

### 1.5 SVRPBench —— 随机/鲁棒 VRP 基准 —— ✅ 论文已下载

- **来源/链接**: https://github.com/yehias21/svrpbench ；论文 arXiv:2505.21887（PDF 已下载到 `report/references/`）
- **包含内容**: 500+ 随机 VRP 实例（≤1000 客户）：**时变拥堵、对数正态延迟、随机事故、经验时间窗、多车场多车**；含训练/验证/测试划分与评估协议。
- **适配程度**: ★★★★★（高）。"毒素扩散/风扰动的随机性" ⇔ "时变拥堵/随机延迟"；**多车场多车** ⇔ 多停机坪多无人机；是目前与我们"不确定环境 + 时效"最贴近的公开基准。
- **下载情况**: ✅ 论文 PDF 已下载；实例集由 GitHub 仓库提供，本次未全量拉取 → 已安排为**泛化性压力测试集**（使用其数据生成协议，不阻塞主流程）。

## 2. 真实场景环境类数据集（B 类）

### 2.1 Open-Meteo 历史气象（东湖夏季风场）—— ✅ 已下载

- **来源/链接**: https://open-meteo.com/en/docs/historical-weather-api （免费无 Key；数据源 ECMWF/ERA5 再分析）
- **包含内容**: 东湖（30.556°N, 114.403°E）2024-06-01 ~ 2024-09-30（蓝藻高发季）逐小时：10m 风速、阵风、风向、温度、降水。117 KB CSV。
- **适配程度**: ★★★★★（高）。直接驱动**风修正时间模型**（t = d / |v_air + v_wind|）、**能量鲁棒预算**、以及**随机 wind scenario 训练**。
- **下载情况**: ✅ `openmeteo_eastlake_2024_bloom.csv`（117,211 字节）；已验证首尾行与字段数。

### 2.2 OpenStreetMap 东湖水系多边形 —— ✅ 已下载

- **来源/链接**: Overpass API https://overpass-api.de/api/interpreter （OpenStreetMap 数据，ODbL 许可）
- **查询**: bbox (30.50,114.30)-(30.63,114.55)，`natural=water` ways + relations，out geom。
- **包含内容**: 920 个水方式 + 39 个水系关系，17,394 个几何点（覆盖东湖水系、周边湖泊/塘/港渠；含中文名称标签）。
- **适配程度**: ★★★★★（高）。① 生成"可达水面"空间（无人机只能在水面上空投放）；② 多边形化后做**风险热点聚类**；③ 岸边停机坪选址的底图（岸线 = 非水区域邻域）。
- **下载情况**: ✅ `osm_eastlake_water.json`（2.56 MB）；已核对 elements 数量与命名。⚠️ 注意本查询只含水多边形，**没有**路网/建筑（路径规划不需要路网——无人机直飞湖面，故这是**充分**信息）。

### 2.5 机实飞能耗/风场标定数据 —— 未发现公开对口数据

## 5. 数据集使用规划（如何喂给模型）

```
训练/评估 数据管线
├─ 公共基准（A类）
│   ├─ Solomon VRPTW  → 与"软时间窗/优先级"结合做消融
│   ├─ PyVRP MDVRPTW / HFVRP → 多车场/异构 gold benchmark（含BKS）
│   └─ SVRPBench / olist / HF-real  → OOD/真实成本矩阵压力测试
├─ 场景自建（B+C+D）
│   ├─ OSM 东湖水多边形 → 可达空间/聚类/停机坪
│   ├─ Open-Meteo 风场 → 风修正成本 + 随机场景
│   ├─ 14 检测装置坐标 + 警报流 → 任务实例（风险权重/时间窗）
│   └─ 物理参数 → 容量/能量/时间约束
└─ 输出
    ├─ train/valid/test 实例划分（按"警报事件"分层，防止泄漏）
    └─ 评估指标: 风险加权投放时间、makespan、惩罚项、约束违反率
```
