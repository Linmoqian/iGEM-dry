> **项目**: iGEM Dry Lab — 蓝藻水华智能监测系统（无人机投放工程菌降解节点闭环）
> **课题**: 任务级路径规划模型 — 通过路径规划使无人机**最快投放**降解菌（在 MC-LR 超阈值风险点执行应急降解任务）

## 0. 检索策略

| 检索维度 | 检索关键词（举例） |
|---|---|
| 应用场景 | UAV water sampling, water quality monitoring drone, cyanobacteria bloom UAV monitoring, lake monitoring |
| 组合路由 | multi-UAV task allocation, multi-drone routing, drone delivery VRP, UAV-USV collaboration |
| 求解方法 | vehicle routing problem (VRP / VRPTW / CVRP), attention model, reinforcement learning routing, POMO, multi-agent RL, predict-then-optimize |
| 不确定性 | stochastic VRP, wind uncertainty, dynamic requests, real-time replanning |
| 数据集 | VRP benchmark, TSPLIB, CVRPLIB, Solomon VRPTW, VrpBench, SVRPBench, OSM, Open-Meteo |
| 中文语境 | 无人机 水质监测 路径规划 多无人机任务分配 东湖 蓝藻 应急响应 |

**检索结论（三条主线）**：

1. **"无人机 + 水质采样/监测"** 已有多篇工程化实现（采样装置、协同系统、覆盖路径规划），但基本是"采样任务"而非"**应急投放任务**"；
2. **"无人机 + 应急投放/配送"** 在学术上可归结为 **多车场/多车 VRP 家族**（尤其带时间窗、容量、能量约束的 VRPTW/CVRP/HEVRPTW/多访问 VRP），并有大量**深度强化学习（NCO/DL-based）**求解器（Kool AM、POMO、RRNCO 等）；
3. **"实时动态任务重规划"** 主流范式是 **滚动时域（receding horizon）+ 学习型构造启发式/经典精确式（OR-Tools/CP-SAT）** 的组合，以及**先预测后优化（Predict-then-Optimize）** 把风险预测与路径优化耦合。

本项目"最快投放"问题本质上是：**带风险权重/时间窗的多车场多无人机路由问题（Multi-Depot Multi-UAV VRP with Time Windows & Priority, 记为 MD-MUAV-VRPTWP）+ 动态重规划**，同时叠加**风/能量不确定性与水体约束**。以下文献逐一评述。

## 1. 核心方法类文献（按与本课题的相关度排序）

### 1.1 Kool, van Hoof, Welling — *Attention, Learn to Solve Routing Problems!*（ICLR 2019, arXiv:1803.08475）

- **链接**: https://arxiv.org/abs/1803.08475 （PDF 已下载）
- **简要介绍**: 首次将 **Transformer encoder-decoder 注意力架构**用于组合优化（TSP/CVRP/SDVRP/OP/PCTSP）的端到端学习（原文问题集不含 VRPTW——经核查更正）。模型由"编码器（多头注意力层叠）→解码器（节点选择注意力 + 上下文注意力）"构成，输出解（逐点构造路径）；用 **REINFORCE + 贪心 rollout baseline** 训练，击败当时所有学习型方法并逼近最优启发式。
- **方法与思路**（可直接借鉴）:
  - ① 组合优化可以**端到端学习**：把解序列化，用网络直接输出"下一步去哪个客户/风险点"；
  - ② 训练目标即**自定义成本函数**（本课题即"最小化到达时间/风险加权时间"），不需要标签；
  - ③ 通过**实例增强（instance augmentation）**与**多起点（rollout）**提高解质量；
  - ④ 可扩展处理 VRPTW（时间窗作为节点属性嵌入，解码时用 mask 禁止不可行访问）。
- **对本项目**: 这是**首选基线骨架**。我们的"尽快投放"成本函数可直接替换其 CVRP 成本；时间窗（风险点优先级）、容量（无人机载荷）均可作为约束嵌入。缺点：纯欧氏距离假设，无法处理风场/非对称成本，需要改造（见 1.3 RRNCO）。

### 1.2 Kwon et al. — *POMO: Policy Optimization with Multiple Optima for Reinforcement Learning*（NeurIPS 2020, arXiv:2010.16011）

- **链接**: https://arxiv.org/abs/2010.16011 （PDF 已下载）
- **简要介绍**: 针对 NCO 中"同一最优解在多起点下对称 & 多个相同最优解"的结构，提出**多起点策略优化**：训练时**强制从每个起点都学同样的最优策略**（symmetry exploitation），推理时对**所有起点 + 8 种实例变换（镜像/旋转）**采样并取最佳。实现公开，在 CVRP/PCTSP 上大幅超越 AM。
- **方法与思路**（可直接借鉴）:
  - 为每个节点都构造一次"从该点出发"的 episode，**增加样本多样性、降低方差**；
  - 推理时**多次采样取最优**（sampling × augmentation），几乎零成本提升解质量——非常适合"应急时刻要又快又好"的场景。
- **对本项目**: 与 AM 结合，作为我们**主策略网络训练/推理的增强技术**。多无人机相当于"多车场"，可把每架无人机视为一个起点，天然契合 POMO 的多起点设计。

### 1.3 Son et al. — *RRNCO: Towards Real-World Routing with Neural Combinatorial Optimization*（2025, arXiv:2503.16159；ICLR 2026）

- **链接**: https://arxiv.org/abs/2503.16159 （PDF 已下载）
- **简要介绍**: 直指 NCO 的 **sim-to-real 差距**：①训练数据是理想化欧氏距离；②节点式架构无法处理**节点-边共同特征**与**非对称成本矩阵**（真实路网/时变行驶时间）。RRNCO 提出 **Adaptive Node Embedding (ANE)** 高效融合边特征，并结合 **NAB（Neural Adaptive Bias）——把非对称距离/时长/方向角三模态经门控融合为可学习注意力偏置矩阵**（原稿误记为 "AdaSparse Attention"，经原文全文核查更正，该词在原文出现 0 次），在真实城市路由基准上显著缩小差距。
- **方法与思路**（可直接借鉴）:
  - **边特征建模**：把风场/水流导致的"点到点飞行时间不对称"作为边特征融入图神经网络；
  - **图结构输入**：把水体/禁飞区/障碍图也作为图信息编码。
- **对本项目**: 这是把"几何空间"改造为"**物理约束空间（风、能量、禁飞）**"的关键架构参考。本项目的一个核心特质是："1 号点 → 2 号点"与"2 号点 → 1 号点"耗时不同（逆风/顺风），RRNCO 提供现成做法。

### 1.4 Iklassov et al. — *Reinforcement Learning for Solving Stochastic Vehicle Routing Problem with Time Windows*（2024, arXiv:2402.09765）

- **链接**: https://arxiv.org/abs/2402.09765 （PDF 已下载）
- **简要介绍**: 把**不确定行驶时间/需求 + 时间窗**（SVRPTW）用注意力网络 + RL 求解，训练时从分布中抽样不确定性实现（scenario sampling），模型学会"期望成本最小"的决策，比 ACO 等传统方法成本更低且推理可并行。
- **方法与思路**（可直接借鉴）:
  - **随机场景采样训练**：运行时间按 log-normal / 指数分布随机化，训练策略对扰动鲁棒；
  - 时间窗处理成"软/硬"两种：硬窗用 mask，软窗（优先级衰减）用惩罚项加进目标。
- **对本项目**: 毒素扩散/风力波动使"飞行时间"和"风险等级"本身就是随机的；其**场景采样训练**正是我们训练鲁棒策略的手段；软时间窗惩罚的设计可直接用于"**风险加权迟到惩罚**"（越晚投放损失越大）。

### 1.5 Heakl et al. — *SVRPBench: A Realistic Benchmark for Stochastic Vehicle Routing Problem*（2025, arXiv:2505.21887）

- **链接**: https://arxiv.org/abs/2505.21887 （PDF 已下载，GitHub: yehias21/svrpbench）
- **简要介绍**: 首个**城市尺度高保真随机 VRP 开源基准**：>500 个实例，最多 1000 客户，含**时变拥堵、对数正态延迟、随机事故、经验时间窗、多车场/多车**等。附训练-验证-测试划分与评估脚本。
- **方法与思路**（可直接借鉴）:
  - 多车场（multi-depot）+ 多车辆 → 我们多无人机 + 多停机坪；
  - **状态转移含随机延迟** → 用于测我们策略在"毒素漂移、通信延迟、风扰动"下的鲁棒性；
  - 提供了**训练/测试划分协议** → 我们复用做标准化评估。
- **对本项目**: 最佳**鲁棒性测试基准**；其"多车场"设置与我们"多停机坪/多无人机"完全同构。实际训练仍用自建"东湖仿真"，SVRPBench 用于***泛化性压力测试***。

### 1.6 Elmachtoub & Grigas — *Smart "Predict, then Optimize"（SPO）*（Management Science 2022, arXiv:1710.08005）

- **链接**: https://arxiv.org/abs/1710.08005 （PDF 已下载）
- **简要介绍**: 经典"预测→优化"两步法存在次优（预测误差被放大进下游优化）；SPO 用**决策感知损失**（SPO loss）训练预测器，使预测的目标函数（含优化器敏感度）直接最小化。
- **方法与思路**（可直接借鉴）:
  - 将**预测器（MC-LR 风险扩散预测 / 未来警报预测）与路径优化器联合校准**；
  - 用「预测导致的目标值差距」作为损失（或 surrogate convex 形式）。
- **对本项目**: 我们的上游由另一模块给出风险预测（浓度/时间/地点）；用 SPO 思想把"预测误差对投放及时性的代价"显式化：**预测偏乐观导致投放迟缓的损失**（假阴性代价）与**偏保守导致浪费航次的损失**（假阳性代价），可做成**不对称损失**——应急系统中假阴性代价远大于假阳性。

### 1.7 Mozhdehi et al. — *Edge-DIRECT: Deep RL for Heterogeneous Electric Vehicle Routing with Time Window*（2024, arXiv:2407.01615）

- **链接**: https://arxiv.org/abs/2407.01615 （PDF 已下载）
- **简要介绍**: 针对**异构电动车辆 + 时间窗**（HEVRPTW，车辆容量/能耗不同）提出 DRL 方法，特点是**异构嵌入（车辆特征参与编码）**与针对能源/时间窗的**可行域掩码**。
- **方法与思路**（可直接借鉴）:
  - **异构车辆**嵌入：各无人机（型号/载荷/续航/电池不同）作为独立 token 参与注意力；
  - 能量约束处理：把"到达某点后剩余电量/载荷"作为**状态特征 + 可行性 mask** 双重保障。
- **对本项目**: 我们的无人机编队很可能异构（大载重长航时 vs 快速轻量），且**载荷限制**（一架无人机仅带 N 包降解菌，多访问 depot 补货/多访问风险点）正是 Edge-DIRECT 的对应场景；它给出了"**异构 + 时间窗 + 能量**"三类约束同时存在的 DRL 解法参考。

### 1.8 *Multi-visit Vehicle Routing Problem with Multiple Heterogeneous Drones*（Transportation Research Part C, vol 172, 2025-03——经 Crossref 核查补全作者/期卷信息）

- **链接**: https://www.mendeley.com/catalogue/d93b0727-208c-30ca-a9b1-b99281bd64c4/ （PDF 已下载：Multi-visit Vehicle Routing Problem with Multiple Heterogeneous Drones.pdf，26.6 MB 扫描版）
- **简要介绍**: 多无人机**多次访问**（往返补荷/补货）的异构 VRP，研究无人机从移动/固定枢纽多次出航的调度。
- **方法与思路**（可直接借鉴）:
  - **多访问**建模：一架无人机可以 = 出航 → 投放若干点 → 回枢纽补货 → 再出航，一个班次内有多个 trip；
  - 枢纽（基地/充电站）作为时序上的"重置点"。
- **对本项目**: 当单机载荷 < 风险点数量时，**多访问 + 补给**是最贴合业务的模型（"快速投放"不等于"一架机全包"），也是与"无人机回收替换检测装置"结合的设计依据。

### 1.9 *Robust Energy-Aware Routing for Air-Ground Cooperative Multi-UAV Delivery in Wind-Uncertain Environments*（arXiv:2604.13441, 2026）

- **链接**: https://arxiv.org/abs/2604.13441 （PDF 已下载）
- **简要介绍**: 空-地协同多无人机配送，**风不确定**下的**能量感知鲁棒路由**；以风不确定下的**能量感知在线鲁棒路由**为目标：在时间依赖能量图上逐决策点做"返航可行性门 + 风险感知边评分"（**BER 在线风险敏感规划框架**；原稿误记为 box/ellipsoid 鲁棒优化+MILP，经原文核查更正——原文无此二组件），并给出**风场修正的飞行时间/功率模型**。
- **方法与思路**（可直接借鉴）:
  - 飞行时间 = f(几何距离, 风速/风向, 无人机空速)，用**前地速（ground speed）矢量叠加**修正：`t = d / |v_air + v_wind|`（或近似线性化）；
  - **鲁棒能量预算**：按最坏风况预留 20-30% 储备能量；
  - 空-地协同：地面可在枢纽预置电池/菌液补给。
- **对本项目**: 东湖湖面风直接影响无人机续航与投放精度；该文的**风场修正时间模型 + 鲁棒能耗**可以直接并入我们的成本矩阵（这是把"欧氏 VRP"变成"真实 VRP"的最关键物理修正之一）。

### 1.10 *Energy-Aware Wind-Resilient Routing for Truck-Assisted Multi-UAV Delivery under Wind Uncertainty*（arXiv:2608.11641, 2026）

- **链接**: https://arxiv.org/abs/2608.11641 （PDF 已下载）
- **简要介绍**: 与 1.9 同源问题（卡车+无人机），进一步强调**风敏感度**：给出 **EWR 在线风险敏感规划**——延迟带噪风估计 + 置信半径 ε_W 不确定边界 + 保守可达性滤波 + 自适应安全余量（原稿误记为两阶段随机规划，经原文核查更正——原文全文无两阶段随机规划组件）。
- **方法与思路**（可直接借鉴）:
  - **在线风险敏感机制**：每决策点计算边成本 c_t(e)=E_t(e)+λ·U_t(e)（U 为风估计不可靠度/信息陈旧度/风突变三项加权）；执行期能量安全指标 M_min 时序化。
  - 卡车的"移动枢纽"概念可类比我们的**临时投放点/移动补给船**。
- **对本项目**: 其"移动枢纽"思想若应用在东湖（如部署补给船作为移动停机坪），我们的车场（depot）数量与位置也变成决策变量，可被纳入后续扩展（见未来方向）。

### 1.11 *Survey on Mission Planning of Multiple Unmanned Aerial Vehicles*（Aerospace 2023, 10(3):208, MDPI——原稿期刊名误写为 Drones，经 DOI 核查更正；URL 路径 2226-4310 即 Aerospace ISSN）

- **链接**: https://www.mdpi.com/2226-4310/10/3/208 （PDF 已下载：Survey on Mission Planning of Multiple Unmanned Aerial Vehicles.pdf）
- **简要介绍**: 多无人机任务规划综述：**任务分配（经典指派/拍卖/博弈/进化/RL）+ 航迹规划（覆盖/避障）**两层的统一综述，梳理了分层架构、协同与故障模式。
- **方法与思路**（可直接借鉴）:
  - **分层规划架构**（任务层 → 航迹层）的普适性论证；
  - **任务分配算法谱系**：集中式（MIP/ILP）→ 分布式（共识拍卖 CBBA）→ 学习式（MARL）。
- **对本项目**: 支撑我们把系统设计为"**任务级（分配+排序）+ 轨迹级（避障/风修正）**"两层；并给出在通信/失效情形下的**鲁棒分配**备选（CBBA 类分布式）。

### 1.12 Balampanis et al. — *Spiral-like Coverage Path Planning for Multiple Heterogeneous UAS Operating in Coastal Regions*（ICUAS 2017）

- **链接**: https://personal.us.es/imaza/papers/conferences/balampanis_icuas17_web.pdf （PDF 已下载）
- **简要介绍**: 面向大面积水面（海岸区）的**螺旋式覆盖路径规划**，将水域分解为多边形并生成多 UAS 均衡覆盖航迹，兼顾异构 UAS 与任务均衡。
- **方法与思路**（可直接借鉴）:
  - 水域多边形化（concave polygon / 分割）+ 螺旋扫描覆盖；
  - **均衡负载**分配（各机覆盖面积相当，避免电量浪费）。
- **对本项目**: ①当风险扩散面大、点多而密时，退化为**区域覆盖**问题的兜底方案；②其"多边形分割"思想可用于**风险热点聚类 → 区域级任务单元**的预处理。

### 1.13 *Hexacopter-Based Cyber-Physical System for Water Sampling with Adaptive Path Planning and Multi-Drone Coordination*（KPI, 2025）

- **链接**: https://itvisnyk.kpi.ua/article/view/333426 （真 PDF 已下载：HEXACOPTER-BASED CYBER-PHYSICAL SYSTEM …pdf；旧 46KB HTML 改名件保留备查）
- **简要介绍**: 六旋翼**水质采样 CPS**：自适应路径规划（基于实时传感器反馈调整采样点顺序）+ 多无人机协调，强调端到端"感知-规划-执行"闭环。
- **方法与思路**（可直接借鉴）:
  - **在线自适应路径规划**：任务点序列不一次定死，而是边飞边根据新数据重排（滚动时域思想）；
  - 多机协调的最小化总时间/总能耗目标。
- **对本项目**: 与我们的"实时警报驱动重规划"完全同构，可作为**工程实现流程**（飞行控制层接口、在线重规划触发条件）的参考。

### 1.14 *Development of a UAV-assisted autonomous water sampling device*（Discover Applied Sciences, Springer 2025）

- **链接**: https://link.springer.com/article/10.1007/s42452-025-06544-x （PDF 已下载）
- **简要介绍**: 无人机辅助自主采水装置（含取水机构、定位、自动作业流程），面向湖泊/水库**多点采样**。
- **方法与思路**（可直接借鉴）:
  - 采样/投送装置的机械与自动化工装经验（投放重物、悬停精度）；
  - 多点作业的**任务编排**与**现场安全控制**。
- **对本项目**: 器械级参考：降解菌**投放包**的挂载、释放、定位容差（悬停精度对投放有效半径的约束，会反过来影响"到点即投放"的可行性判定）。

### 1.15 *Automatic collaborative water surface coverage and cleaning strategy of UAV and USVs*（Digital Communications and Networks, vol 11(2), 2025-04（在线 2022-12；原稿年份误为 2023，经 Crossref 核查更正））

- **方法与思路**（可直接借鉴）:

- **对本项目**: 直接支撑"**无人机 + 漂浮检测节点 + 补给船**"协同体系的顶层调度设计（USV 可承担检测节点布设/回收与菌液补给）。

### 1.16 *MAML-Integrated Multi-Agent RL for Adaptive Coalition-based UAV Coordination in Disaster Scenarios*（2026, ScienceDirect）

- **链接**: https://www.sciencedirect.com/science/article/pii/S2542660526000600 （PDF 已下载：MAML-Integrated Multi-Agent RL …pdf）
- **简要介绍**: 灾害场景下用 **MAML（元学习）+ MARL** 做自适应**联盟式多无人机协调**：面对未知/新任务分布时，用元学习快速适配策略。
- **方法与思路**（可直接借鉴）:
  - **联盟（coalition）式任务分配**：无人机按能力/位置结成临时小组，组内协作完成大任务；
  - **元学习快速适应**：不同湖泊/不同水华形态（跨场景分布）之间的迁移。
- **对本项目**: ①"分组协作"适用于**高优先级热点群**的多机协同（多机同时降毒 vs 单机串行）；②元学习用于**跨水域迁移**（东湖 → 太湖/洱海等）——这正是我们"泛化性"需求的最前沿解法。

### 1.17 *Dynamic Task Allocation and Path Planning for Multi-UAV Disaster Search Using Multi-Agent RL*（IEEE 2026 Cloud Summit，DOI 10.1109/cloudsummit68932.2026.00036）

- **链接**: https://ieeexplore.ieee.org/document/11627339 （IEEE 付费；见附录 B）
- **简要介绍**: 多无人机灾难搜救的**动态任务分配 + 路径规划**联合 MARL：任务随时间出现（动态请求），用集中训练/分散执行（CTDE）框架（算法为 MATD3；原稿"注意力通信"无摘要支撑，经核查更正）。
- **方法与思路**（可直接借鉴）:
  - **CTDE（集中训练-分散执行）**：训练时用全局信息，部署时只用局部观测——适合我们"实时警报 → 每架无人机自主决策"的架构；
  - 动态请求处理：新警报到达时，不重启优化，而是**增量修正**当前解。
- **对本项目**: 动态性核心范式。我们的"警报经常性陆续到达"场景与灾难搜救同构，CTDE 是可选的**分布式部署版**（相比集中式 OR 求解更贴近真实机载算力）。

  - "风险演化"驱动的**风险-时间双目标**。
- **对本项目**: 火灾 ⇔ 水华毒素扩散在"时间敏感性"上高度相似（都是快速演化事件）；其"**学习初解 + 局部搜索精修**"是我们主推架构（见最终模型报告 §决策管线）的重要佐证。

### 1.20 *Deep RL-Based Multirestricted Dynamic-Request Transportation Framework*（IEEE TNNLS 2025）

## 3. 尚未检索到（或缺失）的空白点 —— 也是本模型的创新空间

1. **"毒素降解时效"与路径优化的直接耦合**：现有文献以"配送效率"为目标，没有把"**MC-LR 浓度随时间演化 → 投放窗口（窗口内投放可避免毒性峰值）**"纳入路由目标；这需要与上游风险预测模型联动的动力学约束（本课题特有的"时效-风险"成本设计）。
2. **湖面航行（水面机场/补给点）约束**：文献多为公路/城市地理；湖面监测需处理**水域可达性（只能在水面上空飞行）与岸边停机坪**的混合空间，以及**漂浮装置（检测节点）作为动态"任务点"**的特殊性。
3. **"投放一组可自降解生物制剂"的多次访问时序优化**：降解是过程而非瞬时（多机协同覆盖同一热点以加速降毒），现有文献未把"降解动力学 + 多机协同覆盖量"写入模型。
4. **中国湖泊应急场景的公开数据**：东湖/太湖等水域的实时应急数据几乎不公开（见数据调研文档），因此**仿真器（digital twin）驱动的数据合成**是必选路线（这一点在设计中已落实）。
