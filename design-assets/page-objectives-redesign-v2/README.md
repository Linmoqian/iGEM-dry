# 水体藻毒素监测平台 V2 页面目标图规格

## 设计结论

V2 不增加五个独立模型页面，也不改变现有四项主导航。新增能力集中到“地图监视”，将其从单纯的设备热力图升级为“风险识别—水流推演—剂量决策—路径执行—效果复核”的闭环工作台。

现有页面的改动范围：

| 页面 | 改动级别 | V2 改动 |
|---|---|---|
| 总览 | 轻微 | “系统状态”增加“模型链路”；“告警摘要”增加“待治理任务”；最高风险卡片可跳转地图治理方案 |
| 地图监视 | 主要 | 统一图层、时序推演、风险斑块、投放覆盖、剂量/时限、无人机路线、任务下发 |
| 数据分析 | 轻微 | “AI 预测”改为“风险估计”，明确当前是 nowcast；增加区间、超阈概率和 OOD 标记；可切换 total MC / MC-LR |
| 设备配对 | 不改结构 | 节点详情补充“暗基线/校准状态/有效反应时间窗”；无人机作为执行资源而非传感器卡片 |

## 五模型在界面中的上下游映射

```text
检测节点读数 ──→ 浓度标定 ──┐
                            ├─→ 风险融合 ──┬─→ 二维浅水流 ──┐
水质与环境 ────→ 风险估计 ──┘              └─→ 降解动力学 ─┤
                                                             ├─→ 任务生成
                                                             └─→ 路径规划
                                                                  ↓
                                                            无人机投放
                                                                  ↓
                                                            节点复测闭环
```

- 浓度标定输出节点侧 MC-LR 区间、`P(C≥1)` 与质量旗标。
- 风险估计输出环境侧 total MC / MC-LR 当前风险面与 OOD，不冒充节点实测。
- 二者在界面层融合成风险斑块；二维水流与降解动力学分别补充空间覆盖和时效/剂量约束。
- 路径规划消费统一任务契约，输出多机分配、访问顺序和预计治理生效时间。

地图页只展示对操作有用的输出，不暴露模型内部参数。所有未完成现场标定的数字必须带“原型参数”或“不确定性区间”，不能显示成确定结论。

## 地图监视页：三个连续状态

### 01 态势总览

- 保留现有页头、侧栏、东湖地图和右侧栏。
- 地图上方使用一行图层胶囊：`MC-LR风险`、`预测风险`、`设备`、`水流场`、`风场`、`投放覆盖`。
- 风场和水流场采用稀疏箭头/流线，避免遮挡风险热力图；二者颜色和图例必须区分。
- 点击设备显示原有设备信息；点击风险斑块显示浓度区间、超阈概率、数据来源、域内/域外和预计漂移。
- 主操作是“生成治理方案”，次操作是“查看节点证据”。

交付图：`地图监视页-v2-态势总览.png`

### 02 治理任务规划

- 仍是同一个地图页，不新增路由。
- 地图切换为“投放覆盖 + 无人机路线”主视图：候选点用 1/2/3 编号，覆盖范围用半透明椭圆，路线按无人机分色，风险斑块保留轮廓。
- 右侧栏标题为“治理任务方案”，显示推荐包数、预计达标时间（中位数 + 90% 区间）、光控存活窗口、是否需要二次投放、三架无人机的任务摘要。
- 主操作是“下发任务”，同时保留“返回推演”和“参数来源”。
- 显著标注：当前降解参数和单包剂量若尚未完成湿实验锚定，应显示“原型参数”。

交付图：`地图监视页-v2-治理规划.png`

### 03 下滑分析区

- 用户向下滚动或展开底部抽屉后显示，地图缩为顶部概览条。
- 第一行是闭环步骤条：`检测` → `校准` → `风险估计` → `水流推演` → `剂量决策` → `路径执行` → `复测关闭`。
- 左侧主图：MC-LR 浓度随时间下降的中位线和 90% 区间，标出 1 μg/L 安全线及预计达标时间。
- 右侧主图：三架无人机的任务甘特图，区分飞行、投放、返航、治理时滞。
- 底部卡片：覆盖率、最晚治理生效时间、敏感性最高参数、模型可信边界。

交付图：`地图监视页-v2-闭环推演.png`

## 数据分析页：必要纠偏

- 保留原页面的筛选器、趋势图、节点列表与右侧证据卡结构。
- `AI 预测（未来 7 天）` 改为 `当前风险估计（非未来预报）`，历史曲线只延伸到当前日期。
- 增加 MC-LR / total MC 分析物切换，并同时呈现中位数、80% 区间、超限概率与 OOD。
- 删除无法由当前 nowcast 模型支持的“下一高风险时间”和单一“模型置信度”百分比。

交付图：`数据分析页-v2-当前风险估计.png`

## 图层语义

| 图层 | 来源 | 视觉编码 | 默认 |
|---|---|---|---|
| MC-LR 风险 | 节点标定融合 | 绿—黄—橙—红连续热力 | 开 |
| 预测风险 | CMADRE v2 nowcast | 蓝紫等值面 + 虚线边缘 | 关 |
| 设备 | 漂浮检测节点 | 状态色定位针 | 开 |
| 水流场 | 二维浅水流 | 青色流线/箭头，附 m/s 比例 | 开 |
| 风场 | 气象输入 | 深蓝稀疏箭头，附 m/s | 关 |
| 投放覆盖 | 粒子输运 + 降解阈值 | 半透明青绿色椭圆 | 关 |
| 无人机路线 | 路径规划 | 每架机固定一种高对比线色 | 任务态开 |

## 关键文案规则

- 使用“风险估计”或“当前状态估计”，不使用“未来 7 天预测”，除非后续模型确实加入了时间序列预报。
- 浓度必须同时显示区间；1 μg/L 决策同时显示 `P(C≥1)`。
- total MC 与 MC-LR 不合并为一个指标，筛选器中明确区分。
- OOD 显示为“模型域：域内 / 域外”，域外时建议复测。
- 单次覆盖面积和降解时间在正式标定前显示“原型参数”。

## imagegen 生成提示词摘要

四张图均使用内置 `imagegen` 的 `ui-mockup` 路线；前两张直接继承现有地图页参考图，后两张沿用已确定的品牌、布局和组件规范，所有结果均以新文件保存。

2. 治理任务规划：同一构图；显示 4 个推荐投放点、覆盖椭圆和两架无人机路线；右侧显示投放包数、达标时间区间、二次投放建议和任务发布按钮。
3. 推演与任务详情：同一品牌与侧栏；页面处于下滑位置；展示并行输入的闭环工作流、带区间的趋势图、剂量—时间决策图、执行时间轴和可信边界卡片。
4. 数据分析：保留原页面的信息层级；只把未来预测纠正为当前状态估计，并增加分析物切换、区间、超限概率和 OOD 证据卡。

共同约束：高保真可实现 UI；中文横排清晰；不增加主导航；不使用暗色/科幻风；保留海洋浅蓝视觉和吉祥物；无水印。
