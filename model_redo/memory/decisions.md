## Decision 003

日期：2026-06-04
阶段：阶段 3 — 外部数据源检索 + GPT 审查
问题：MC-LR 数据不足，如何调整任务定义？

### 选项

1. 坚持 MC-LR 回归为主任务，用 EMLS 369 行硬撑。
2. 放弃 MC-LR，只做总 MC。
3. 拆分为多层任务：总 MC 为主，MC-LR 为受限验证，中国场景为迁移分析。
4. 暂停建模，等待更多数据。

### 决定

选择 3：拆分为三层任务。

### 理由

- 本地数据仅 EMLS 有 MC-LR（369 行），样本量和地理覆盖不足
- 总 MC 数据充足（EPA NLA 3,027+ 行，Lake Erie 3,074+ 行，GLERL-CIGLR 多年周采样）
- GPT 审查明确建议拆分，Claude 独立审计也得出相同结论
- 不应把总 MC 模型包装成 MC-LR 模型

### 任务定义

- **任务 A（主任务）**：总 microcystins / cyanotoxin 浓度回归与风险分类。数据来源：EPA NLA + Lake Erie + GLERL-CIGLR + WQP
- **任务 B（受限验证）**：MC-LR 专属小样本模型。数据来源：EMLS Europe 369 行。仅用于探索和不确定性分析，不作为主模型
- **任务 C（场景迁移）**：中国/东湖场景适配。数据来源：CNEMC、NESDC 东湖站、中国湖库水质数据。仅做协变量分布比较，不用于 toxin 标签训练

### GPT 意见

GPT 建议此拆分方案（阶段 3 审查，采纳）。

### 最终采纳情况

采纳。

### 后续验证方式

1. 下载 EPA NLA 数据，确认总 MC 样本量
2. 下载 GLERL-CIGLR 数据，确认环境变量完整性
3. 尝试 WQP API 查询 MC-LR 精确匹配
4. 建立统一数据字典后进入阶段 6
