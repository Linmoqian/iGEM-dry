# 模型创新探索方案

> 阶段 9 — 基于 baseline 和迭代结果的创新性探索方向
> 生成日期：2026-06-08

---

## 1. 已完成的探索

### 1.1 扩展特征集 ✅

- 浮游植物分类叶绿素：Erie R² 0.063→0.430（大幅改善）
- 土地利用+气候+N/P 预算：HABs R² 0.205→0.229（小幅改善）
- 浮游植物色素标记：EMLS R² 0.195→0.110（更差，过拟合）

### 1.2 信息泄漏分析 ✅

- 蓝藻叶绿素贡献约 0.15-0.26 R²
- 去掉后 R² 降至 0.17（RF）或 0.28（XGBoost）
- 需确认实际部署时该特征的可用性

### 1.3 跨数据集泛化 ✅

- 失败：HABs→Erie R²=0.06，Erie→HABs R²=-19M
- 两个数据集的 MC-环境关系不可迁移

### 1.4 时间稳定性 ✅

- Erie：R² 在 0.35-0.44 之间（不同时间划分）
- 模型在时间维度上相对稳定

## 2. 未完成但值得探索的方向

### 2.1 分湖区模型 vs 统一模型（优先级：中）

**假设**：不同湖区/生态系统的 MC-环境关系不同，分组建模可能更优。

**实验设计**：
- 按 Erie 的站点分组（东部/西部/中部）
- 每组训练独立模型
- 比较分组模型 vs 统一模型的测试集性能

**风险**：每组样本量更小，可能过拟合。

### 2.2 分位数回归 / 不确定性估计（优先级：高）

**假设**：MC 浓度预测的核心需求是识别高风险事件，点估计不足以支持决策。

**实验设计**：
- 使用 GradientBoostingRegressor 的 quantile loss
- 输出 10%、50%、90% 分位数预测
- 评估高浓度样本的预测区间覆盖率

**风险**：分位数回归在小样本上可能不稳定。

### 2.3 残差驱动的数据质量分析（优先级：中）

**假设**：大残差样本可能代表数据质量问题或特殊生态事件。

**实验设计**：
- 分析残差最大的 10% 样本
- 检查是否集中在特定年份、站点或数据源
- 识别可能的异常值或数据录入错误

**风险**：低。纯分析性质，不修改数据。

### 2.4 HABs GroupKFold by DSGN_CYCLE（优先级：高）

**假设**：当前随机划分高估了 HABs 模型的泛化能力。按调查周期分组可给出更诚实的评估。

**实验设计**：
- DSGN_CYCLE 有 2007、2012、2017 三个值
- Leave-one-cycle-out 交叉验证
- 比较 GroupKFold vs 随机划分的 R²

**风险**：如果不同周期的 MC 分布差异大，R² 可能更低。

### 2.5 EPA NLA 2017 数据整合（优先级：高）

**假设**：NLA 2017 有独立的藻毒素数据和水质化学数据，整合后可增加 HABs 训练样本。

**实验设计**：
- 解压 NLA_2017_Report_Data_Files.zip
- 读取藻毒素数据和水质化学数据
- 与 HABs 训练数据合并（去重）
- 重新训练并比较

**风险**：NLA 2017 可能与已有 HABs 数据重叠。

### 2.6 MC-LR 零值 sensitivity 分析（优先级：中）

**假设**：EMLS MC-LR 的 54% 零值处理策略影响模型结果。

**实验设计**：
- 方案 1：零值保持为 0
- 方案 2：零值替换为 LOD/2（假设 LOD=0.05）
- 方案 3：零值替换为 LOD（假设 LOD=0.10）
- 比较三种方案的 Ridge R²

**风险**：LOD 值不确定，需要文献确认。

## 3. 不建议探索的方向

1. **深度学习**：样本量不足（Erie 3k, HABs 1k, EMLS 369），过拟合风险极高
2. **大规模自动调参**：当前模型的主要瓶颈是数据质量和特征，不是超参数
3. **跨数据集集成**：已证明跨数据集泛化失败，集成无意义
4. **更多外部数据下载**：已有的 EPA NLA 2017 尚未整合，应先利用已有数据

## 4. 建议优先级

| 优先级 | 方向 | 预期收益 | 工作量 |
|--------|------|---------|-------|
| 高 | EPA NLA 2017 整合 | 增加样本量 | 中 |
| 高 | HABs GroupKFold | 更诚实的评估 | 低 |
| 高 | 分位数回归 | 不确定性估计 | 低 |
| 中 | 残差分析 | 数据质量洞察 | 低 |
| 中 | MC-LR sensitivity | 零值处理优化 | 低 |
| 中 | 分湖区模型 | 可能提升 Erie | 中 |
