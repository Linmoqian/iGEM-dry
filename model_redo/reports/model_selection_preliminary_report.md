## 2. 最可信模型

### 2.1 任务 A（总 MC 回归）— Lake Erie

- **模型**：RandomForestRegressor（n_estimators=300, max_depth=10, min_samples_leaf=5）
- **特征**：17-18 个（水温、总 Chla、浮游植物分类 Chla × 4、TN、TP、透明度、深度、氨氮、硝酸盐、月份编码、经纬度、TN:TP、TSS）
- **R²**：0.43-0.44
- **Spearman**：0.74-0.76
- **WF2**：62%
- **时间稳定性**：R² 在 0.35-0.44 之间（不同时间划分）
- **注意事项**：
  - 蓝藻叶绿素（Bluegreen algae-chla）是第一重要特征（39%），存在信息泄漏风险
  - 去掉蓝藻叶绿素后 R² 降至 0.17
  - 跨数据集泛化失败（HABs→Erie R²=0.06）

### 2.2 任务 A（总 MC 回归）— HABs NLA

- **模型**：XGBRegressor（n_estimators=300, max_depth=6, lr=0.05）
- **特征**：26 个（水质 + 土地利用 + 气候 + N/P 预算）
- **R²**：0.23
- **Spearman**：0.55
- **WF2**：38%
- **注意事项**：
  - TN 是最重要特征（14%）
  - 特征工程改善有限（0.205→0.229）
  - 随机划分可能高估泛化能力

### 2.3 任务 B（MC-LR）— EMLS

- **模型**：Ridge（alpha=1.0）
- **特征**：10 个基础水质特征
- **R²**：0.20
- **Spearman**：0.45
- **WF2**：12%
- **注意事项**：
  - 测试集仅 17 行，结果高度不确定
  - 54% 零值处理策略影响大
  - 树模型均严重过拟合
  - 不应将此结果泛化到其他地区

## 3. 不可信指标

1. **Erie RF R²=0.43 含泄漏风险**：蓝藻叶绿素可能与 MC 同步测量，实际部署时不可用
2. **HABs R²=0.23 基于随机划分**：无时间外推验证，可能高估泛化
3. **EMLS R²=0.20 基于 17 行测试**：置信区间极宽，结果不稳定
4. **跨数据集负 R²**：证明两个数据集的 MC-环境变量关系不同
5. **任何单次随机划分的 R²**：应通过交叉验证确认

## 4. 关键科学发现

### 4.1 浮游植物分类叶绿素是 Erie MC 的最强预测因子

- 蓝藻叶绿素（39%）+ 总叶绿素（28%）+ 硅藻叶绿素（6%）= 73%
- 这在生态学上合理：MC 由蓝藻产生，蓝藻密度直接相关
- 但实际部署时，浮游植物分类数据通常来自与 MC 同步的采样分析

### 4.2 营养盐是 HABs MC 的主要驱动因子

- TN（14-31%）是 HABs 最重要特征
- 浊度（9-17%）和 pH（7-10%）次之
- 与 Erie 的浮游植物主导不同，HABs 的 MC 更受营养状态驱动

### 4.3 跨数据集不可迁移

- 两个数据集的 MC-环境关系不同
- 可能原因：
  - 不同 MC 亚型组成
  - 不同检测方法（ELISA vs 混合方法）
  - 不同生态背景（单湖 vs 全国）
  - 不同时间尺度（周监测 vs 5 年调查）

### 4.4 MC-LR 小样本限制

- EMLS 369 行（测试 17 行）不足以建立可靠模型
- EPA NCCA 2015 无环境变量，无法独立训练
- MC-LR 预测需要更多包含 MC-LR 亚型 + 环境变量的数据

## 5. 下一步建议

1. **确认蓝藻叶绿素的测量时间**：如果先于 MC 采样，则不是泄漏，可安全使用
2. **整合 EPA NLA 2017 数据**：增加 HABs 训练样本量和特征多样性
3. **对 HABs 做 GroupKFold by DSGN_CYCLE**：验证跨调查周期的泛化
4. **MC-LR 零值 sensitivity 分析**：比较 0/LOD/2/LOD 三种处理
5. **寻找更多 MC-LR 数据**：WQP API 查询、Figshare 全球数据集
6. **用户确认任务重定义**：接受总 MC 为主任务还是坚持 MC-LR
