# 数据清洗方案草案

> 阶段 6 — 基于统一数据字典的清洗流程设计
> 生成日期：2026-06-04

---

## 1. 清洗目标

将原始数据转换为统一格式的建模表，满足：
1. 统一字段名（按统一数据字典）
2. 统一单位（mg/L、µg/L、°C、m）
3. 正确处理检测限和未检出值
4. 记录所有删除和转换操作
5. 输出清洗报告

## 2. 数据源与清洗策略

### 2.1 Lake Erie（任务 A 主训练）

**输入**：`data/raw/数据汇总v2(clf)/1.数据汇总/01_Lake_Erie_采样/Lake_Erie_全湖采样数据_2013-2025.csv`

**清洗步骤**：
1. 读取 CSV（encoding=latin1）
2. 删除空列（Unnamed 系列）
3. 处理 MC 检测限：`< 0.15` → 0.075
4. 单位转换：
   - TN: µmol/L × 0.014 → mg/L
   - TP: µmol/L × 0.031 → mg/L
   - 营养盐: µmol/L → mg/L（按元素原子量）
5. Chla 负值 clip 到 0
6. 解析日期
7. 重命名字段为标准名
8. 添加 `data_source = "erie"`
9. 输出 `data/cleaned/erie_clean.parquet`

### 2.2 HABs Training（任务 A 主训练）

**输入**：`data/raw/数据汇总v2(clf)/1.数据汇总/02_HABs_驱动因子模型/HABs_模型训练数据.csv`

**清洗步骤**：
1. 读取 CSV
2. P_Legacy_P 极端值标记
3. 解析日期
4. Chla 单位转换：mg/L × 1000 → µg/L
5. 重命名字段为标准名
6. 添加 `data_source = "habs_nla"`
7. 输出 `data/cleaned/habs_nla_clean.parquet`

### 2.3 EMLS Europe（任务 B 主训练）

**输入**：`data/raw/1.测试数据-第一版本/欧洲地区性数据/edi.176.5/EMLSdata_10Aug_afterRev_dateformated.csv`

**清洗步骤**：
1. 读取 CSV（encoding=utf-8-sig）
2. 国家名修正（FR→France, Lithouania→Lithuania）
3. MC-LR 零值处理：0 → sensitivity 分析（0 / 假设 LOD）
4. 解析日期
5. 重命名字段为标准名
6. 添加 `data_source = "emls"`
7. 输出 `data/cleaned/emls_clean.parquet`

### 2.4 EPA NCCA 2015（任务 B 验证）

**输入**：`data/external_raw/EPA_NCCA_2015_GreatLakes/NCCA_2015_Great_Lakes_LCMSMS_Data.xlsx`

**清洗步骤**：
1. 读取 Excel
2. MC-LR 值 0.10 视为 <LOD（LOD = 0.10 µg/L）
3. 解析日期（YYYYMMDD 格式）
4. 重命名字段为标准名
5. 添加 `data_source = "ncca2015"`
6. 输出 `data/cleaned/ncca2015_clean.parquet`
