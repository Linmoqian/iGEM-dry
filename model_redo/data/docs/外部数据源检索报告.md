# 外部数据源检索报告

> 阶段 3 — 外部开放数据源检索结果  
> 生成日期：2026-06-04  
> 检索方式：Web 搜索（NOAA GLERL、USGS ScienceBase、EPA WQP、Zenodo 等）

---

## 1. 检索结果总览

共找到 **17 个相关公开数据集**，其中：

- **1 个包含 MC-LR 亚型专属数据**（EPA NCCA 2015 Great Lakes LC/MS/MS）
- **16 个包含总微囊藻毒素数据**（ELISA 或 LC-MS/MS 总 MC）

## 2. 最高优先级数据集

### 2.1 EPA NCCA 2015 Great Lakes LC/MS/MS（最高优先级）

| 属性 | 值 |
|------|-----|
| 名称 | 2015 National Coastal Conditions Assessment: Algal Toxins and Cyanotoxins in United States Great Lakes Samples Detected by LC/MS/MS |
| 来源 | EPA / USGS via ScienceBase |
| 链接 | https://www.sciencebase.gov/catalog/item/600740a0d34e162231fb1a5d |
| 格式 | Excel (.xlsx), 142.6 KB |
| 样本量 | **542 个五大湖样本** |
| MC-LR | **是 — LC/MS/MS 测量 10 种 MC 异构体（含 MC-LR）** |
| 额外毒素 | Anatoxin-a, Cylindrospermopsin, Domoic acid, Nodularin, Okadaic acid |
| 环境变量 | NCCA 标准水质参数 |
| 时间 | 2015 年 |
| 空间 | 美国五大湖 |

**关键价值**：这是搜索到的**唯一**包含 MC-LR 亚型专属浓度且使用 LC/MS/MS 金标准方法的数据集。542 个样本量显著大于 EMLS（369 行）。

## 3. 下载计划

基于优先级，建议下载顺序：

1. **EPA NCCA 2015**（最高 — 唯一 MC-LR 专属，542 行）
2. **USGS Lake Ontario 2023**（高 — 最新，五大湖，有详细生态数据）
3. **USGS Great Lakes/MS River ELISA**（高 — 五大湖总 MC）
4. **EPA Water Quality Portal API 查询**（可筛选 MC-LR 参数）

## 4. 检索局限性

1. 未找到中国湖泊的公开 MC-LR 数据集
2. 未找到武汉东湖相关的公开 MC-LR 数据
3. 大多数数据集为总 MC 而非 MC-LR 专属
4. 部分链接可能需要进一步验证可访问性
5. Zenodo/Figshare/Dryad 上未找到大规模水质-MC 监测数据集（仅找到 Clear Lake 70 年数据）
