## 3. 单位风险

- **磷单位混用**：EMLS 用 mg/L，Lake Erie 用 µmol/L，HABs 用 mg/L。以 P 计：1 µmol/L = 0.031 mg/L
- **氮单位混用**：同理，以 N 计：1 µmol/L = 0.014 mg/L
- **叶绿素 a 单位混用**：EMLS 用 µg/L，HABs 用 mg/L（差 1000 倍）
- **检测下限不统一**：Lake Erie `<0.15` µg/L，ESP `<LLOD`（值未知），SB Weekly `bdl`
- **MC-LR 零值含义不确定**：EMLS MC_LR_ugL 中大量 0 值，可能为 <LOD 或真实零值

## 4. 跨数据集单位统一方案

若要合并 EMLS Europe 和 Lake Erie 数据：

1. 磷：Lake Erie µmol/L × 0.031 → mg/L
2. 氮：Lake Erie µmol/L × 0.014 → mg/L
3. 叶绿素 a：HABs mg/L × 1000 → µg/L
4. 不合并 MC 目标变量（MC-LR ≠ 总 MC）
