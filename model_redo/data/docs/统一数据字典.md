## 1. 目标变量定义

### 1.1 任务 A：总 Microcystins 回归（主任务）

| 标准字段名 | 说明 | 单位 | 变换 | 来源 |
|-----------|------|------|------|------|
| `total_mc_ugL` | 总微囊藻毒素浓度 | µg/L | 原始值 | Lake Erie / HABs Training / EPA NLA |
| `total_mc_log1p` | log1p 变换后的总 MC | - | `log1p(total_mc_ugL)` | 派生 |
| `mc_detected` | 是否检出（辅助分类） | 0/1 | `total_mc_ugL > LOD` | 派生 |

### 1.2 任务 B：MC-LR 小样本验证

| 标准字段名 | 说明 | 单位 | 变换 | 来源 |
|-----------|------|------|------|------|
| `mclr_ugL` | MC-LR 浓度 | µg/L | 原始值 | EMLS Europe / EPA NCCA 2015 |
| `mclr_log1p` | log1p 变换后的 MC-LR | - | `log1p(mclr_ugL)` | 派生 |
| `mclr_detected` | MC-LR 是否检出 | 0/1 | `mclr_ugL > LOD` | 派生 |

### 1.3 检测限处理

| 数据集 | 目标变量 | LOD | 未检出标记 | 处理策略 |
|--------|---------|-----|-----------|---------|
| EMLS Europe | MC_LR_ugL | 不明确（0 值可能为 <LOD） | 值为 0 | sensitivity: 0 / LOD/2 / LOD |
| EPA NCCA 2015 | MCLR_(µg/L) | 0.10 µg/L | 值为 0.10 | 0.10 视为 <LOD，sensitivity 分析 |
| Lake Erie | Total Microcystins | 0.15 µg/L | `< 0.15` 标记 | 半检测限 0.075 |
| HABs Training | MICX | 0.1 µg/L | 未检出=缺失 | 仅用 MICX>0 样本做回归 |
| EPA NLA | Total MC | 需查元数据 | 需查元数据 | 待确认 |

## 3. 数据泄漏字段（禁止用于预测）

以下字段与目标变量同步测量或为 MC 的替代测量，**不得作为特征**：

| 字段 | 来源 | 泄漏原因 |
|------|------|---------|
| MC_LR_ugL | EMLS | 目标变量本身 |
| MC_YR/RR/dmLR/LY/LW/LF_ugL | EMLS | MC 同系物，与 MC-LR 高度相关 |
| NOD_ugL / CYN_ugL / ATX_ugL | EMLS | 其他蓝藻毒素，同步测量 |
| Extracellular Microcystin | Lake Erie | MC 的另一种形式 |
| Bluegreen algae-chla | Lake Erie | 需确认测量时间是否先于 MC |
| ucd.qpcr.toxin.MIC | SF Estuary | qPCR 蓝藻毒素基因定量 |
| bryte.amb.Chla | SF Estuary | 需确认测量时间 |

## 4. 预测时可获得特征

以下特征在实际部署时可实时或提前获取，适合作为预测特征：

- 水温、pH、溶解氧、浊度 — 实时传感器
- 叶绿素 a — 荧光探头（需确认是否先于 MC 测量）
- 总氮、总磷 — 实验室分析（有延迟）
- 透明度 — Secchi 盘
- 月份、经纬度 — 已知
- 湖泊形态（深度、面积） — 已知
- 土地利用比例 — 已知（静态）
