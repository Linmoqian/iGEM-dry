# 目标变量定义说明

> 生成日期：2026-06-04

---

## 1. 任务 A：总 Microcystins 浓度

### 1.1 定义

- **原始字段**：
  - Lake Erie: `Total Microcystins (µg/L)`
  - HABs Training: `MICX` (µg/L)
  - EPA NLA: 待确认（可能是 `MICX` 或 `MCYST_TOT`）
- **单位**：µg/L（全部统一）
- **范围**：
  - Lake Erie: 0.075 ~ 数百 µg/L（<0.15 标记替换为 0.075）
  - HABs Training: 0.1 ~ 225 µg/L（仅 MICX>0 样本）

### 1.2 变换

- **原始值**：用于报告和实际浓度解读
- **log1p 变换**：`log1p(total_mc_ugL)` — 用于模型训练
  - 理由：MC 浓度跨越多个数量级，log 变换可降低偏度
  - log1p 处理零值（log1p(0) = 0）

### 1.3 未检出处理

| 情况 | 处理 | 理由 |
|------|------|------|
| 明确 <LOD 标记 | 替换为 LOD/2（主方案） | 统计学惯例 |
| 明确 <LOD 标记 | sensitivity: 0 或 LOD | 不确定性分析 |
| MICX 缺失 + MICX_DET=0 | 排除出回归训练集 | 无浓度信息 |
| MICX 缺失 + MICX_DET=1 | 异常，需人工检查 | 逻辑矛盾 |
| 值为 0 无标记 | 视为 <LOD，sensitivity 分析 | 保守假设 |

### 1.4 辅助分类目标

- **定义**：`mc_detected = (total_mc_ugL > LOD).astype(int)`
- **阈值**：Lake Erie 0.15 µg/L，HABs Training 0.1 µg/L
- **用途**：辅助风险分类，不替代回归

## 2. 任务 B：MC-LR 浓度

### 2.1 定义

- **原始字段**：
  - EMLS: `MC_LR_ugL`
  - EPA NCCA 2015: `MCLR_(µg/L)`
- **单位**：µg/L
- **范围**：
  - EMLS: 0 ~ 3.97 µg/L（mean 0.107，多数为 0）
  - EPA NCCA: 0.10 ~ 1.04 µg/L（mean 0.264，91% 为 0.10）

### 2.2 特殊问题

- **EMLS 零值**：369 行中大量为 0，缺少 LOD 文档
  - 可能是真实未检出（<LOD）
  - 也可能是仪器灵敏度足够测到 0
  - **策略**：假设 0 = <LOD，做 sensitivity 分析
- **EPA NCCA 0.10 值**：592 行中 91% 为 0.10
  - 几乎确定是检测限
  - **策略**：将 0.10 视为 <LOD = 0.10 µg/L

### 2.3 变换

- 与任务 A 相同：`log1p(mclr_ugL)`
- 但需注意：大量 <LOD 值经 log1p 后变为 `log1p(LOD/2)` 或 `log1p(0)=0`

## 3. 任务 C：中国场景（无目标变量）

- 仅使用环境变量，不涉及 MC 标签
- 目标是验证训练数据的环境变量分布是否覆盖中国湖泊

## 4. 关键风险

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 总 MC ≠ MC-LR | 任务 A 模型不能直接用于 MC-LR 预测 | 明确区分任务 A/B，不混淆 |
| <LOD 处理不当 | 低估或高估浓度 | sensitivity 分析（0/LOD/2/LOD） |
| ELISA vs LC/MS/MS | 不同方法测量值不可直接比较 | 记录检测方法，按方法分层分析 |
| 0 值含义不确定 | 可能是真实零值或 <LOD | 假设 <LOD，sensitivity 分析 |
